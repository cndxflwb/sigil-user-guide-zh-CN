插件管理

— 扩展 Sigil 的功能 —

Python 3 插件提供了一种扩展 Sigil 功能的强大方式。在 Windows 和 macOS 上，Sigil 已经自带了一个内嵌的 Python 3 解释器以及若干为 Sigil 优化的 Python 库，因此你无需在系统中安装 Python 3。只需下载插件、将其添加到 Sigil，即可开始使用。

在 Linux 上，用户应安装在 Sigil 中使用插件所需的相关 python 3 软件包。通常这些是你的发行版软件仓库中为 Sigil 推荐的（而非必需的）软件包。具体信息请咨询你所用发行版的 Sigil 维护者。

支持 Sigil 的完整插件列表可以在 MobileRead 上的Sigil 插件索引中找到。其中的亮点包括：

  • Access-Aide：改进 EPUB 的可访问性，帮助满足 ACE（Accessibility Checker for EPUB，EPUB 可访问性检查器）要求。
  • ACE：一个简单的 DAISY ACE封装。
  • cssRemoveUnusedSelectors：一个用于移除未使用 CSS 选择器的强大工具。
  • CSS Validator 插件：使用离线版 W3C CSS Validator 验证 CSS 文件。
  • cssUndefinedClasses：移除所有未在样式表或其他地方被引用的类和 ID。
  • DOCXImport：将 DOCX 文档导入 Sigil 并转为 EPUB。
  • ePub3-itizer：将有效的 EPUB2 转换为 EPUB3。
  • EPUBCheck：一个简单的 EPUBCheck 封装，用于验证 EPUB2 和 EPUB3。
  • FlightCrew：一个用于 EPUB2 的验证器插件。
  • KindleGen：一个简单的 kindlegen 封装，用于从 EPUB 生成主文件格式的 mobi、azw3、mobi7 或 KFX。
  • KindleImport：将 Kindle KF8/azw3 和老式的纯 mobi 文件导入 Sigil 并转为 EPUB。
  • LanguageTool：一个简单的 LanguageTool 封装，用于检查语法。
  • MarkdownImport：将 Markdown 文件和无标记的纯文本文件导入 Sigil 并转为 EPUB。
  • ODTImport：将 OpenOffice ODT 文件导入 Sigil 并转为 EPUB。
  • PunctuationSmarten：将引号、撇号、破折号和省略号转换为相应的印刷排版字符。
  • TagMechanic：移除 span、div 以及其他一些标签；更改其属性；或将它们转换为不同的 HTML 元素。

……以及更多！

安装插件

要安装插件：

  1. 下载所需的插件 .zip 文件。
  2. 转到 插件=>插件管理=>添加/移除，然后单击添加插件按钮。
  3. 选择该插件的 .zip 文件并单击确定（在 Mac 上，单击打开）。
  4. 如果尚未启用使用内置 Python，请启用它。
    （如果无法选择 使用内置 Python，请单击自动或设置，选择一个外部 Python 解释器。）

不要解包或重命名插件的 .zip 文件！如果 .zip 文件不是原来的名称，你在尝试添加插件时会看到错误信息。如果你的浏览器设置为在下载后自动解压 zip 文件，请在下载插件之前关闭该功能。

要移除插件：

  1. 转到 插件=>插件管理=>添加/移除。
  2. 选择要移除的插件并单击移除插件。
    你也可以单击全部移除，一次性移除所有插件。

将插件分配给工具栏按钮

要想快速方便地使用插件，请转到 插件=>插件管理=>快捷方式，使用下拉菜单将最常用的插件分配到十个工具栏按钮上，然后单击确定。如果某个插件有自定义图标，就会显示该图标；否则将使用通用图标。

工具栏按钮：

要显示或隐藏插件工具栏，请转到菜单项 视图=>工具栏=>插件组 1（对应插件 1-5）和 视图=>工具栏=>插件组 2（对应插件 6-10）。

如果某个插件没有自定义图标，或者你更喜欢其他图标，可以将其更换。首先你需要创建一个 SVG 图标或一个 48x48 像素的 PNG 图标。最重要的是，图标必须命名为 plugin.svg 或 plugin.png，如果两者同时存在，则优先使用 SVG 版本。

然后转到 插件=>插件管理，并单击左下角的打开首选项文件夹。最后，打开“plugins_prefs”文件夹，把新图标放入该插件对应的文件夹中。如果该插件还没有首选项文件夹，请在“plugins”文件夹中使用与插件完全相同的名称创建一个。

运行插件

插件安装完成后，运行它就像从 插件 菜单中选择该插件或单击其工具栏按钮一样简单。

例如，要运行 EPUBCheck 插件，请选择 插件=>有效性=>EPUBCheck，或单击。

如果你认不出某个工具栏按钮，将鼠标悬停在其上即可查看插件名称。

问题排查

Error: Interpreter python3.4 has no path set

如果 使用内置 Python 被禁用，且 ≥Python 3.4 文本框为空或包含无效路径，通常会显示此错误信息。请单击自动或设置，选择外部 Python 解释器，或启用 使用内置 Python 被禁用。

Error: Plugin is not a valid Sigil plugin

如果插件的 .zip 文件无效、已被解压或已被重命名，通常会显示此错误信息。如果你重命名过插件的 .zip 文件，请重新下载并重试安装。

如果你仍然遇到问题，请安装并运行 Sigil 测试插件，并在 MobileRead 的 Sigil 插件论坛上发布结果。

编写你自己的插件

得益于一个完备的 Python 框架，为 Sigil 编写插件相对容易。如果你有兴趣编写自己的 Python 3 Sigil 插件，请查阅 Sigil 插件框架指南。
