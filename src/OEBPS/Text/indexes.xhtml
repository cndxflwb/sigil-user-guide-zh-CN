索引

— 为你的书创建索引 —

如果你想为书创建索引，可以使用 Sigil 确定要索引的内容，然后自动创建一个包含索引的新 HTML 页面。

你可以在文本中标记单个单词加入索引，也可以使用索引编辑器来确保该单词的每一次出现都被索引。

标记索引条目

确定要纳入索引的条目的第一种方法是在文本中标记特定的单词或短语。只有你标记的那个单词或短语的出现才会被纳入索引——如果你需要所有出现，请使用索引编辑器。

在代码视图中高亮显示一个单词或短语，然后选择菜单项 工具=>索引=>标记为索引 或其键盘快捷键（可以更改）。这将打开一个提示，让你输入希望这些单词在索引中的显示方式：

你输入的在索引中使用的名称文本将在索引中显示如下：

  • [空白]：如果你将名称留空，则索引中将使用你高亮显示的确切单词。
  • 单词：如果你输入一个单词或短语，则将使用该单词或短语（例如使用 Oak 而不是 oak）。
  • 标题/单词：如果在名称中使用“/”，则会创建一个层级分组（例如 Forest/Tree/Oak 会创建一个条目 Oak，该条目归档在 Tree 下，而 Tree 归档在 Forest 下）。
  • 条目a;条目b：如果使用“;”，则会为该单词或短语创建多个条目。

当您将文本标记为索引后，它只是添加了一些 Sigil 特定的 HTML 代码，告诉 Sigil 在创建索引时包含这些词语。在代码视图中，它可能显示如下：

<a class="sigil_index_marker" title="Character/Alice">Alice</a>

如果你不再希望某个单词或短语被 Sigil 索引，你需要删除该单词周围的特殊 HTML 标签。

要找到已索引的单词，你可以在代码视图中搜索。或者，你可以将以下 CSS 临时添加到样式表中，从而在预览中以颜色高亮显示它们：

[class="sigil_index_marker"] { color:#335500; }

将条目添加到索引编辑器

识别要索引的单词的第二种方法是将单词添加到列表中。这样，在你创建索引时，该单词的每一次出现都会被自动纳入索引。你可以同时使用标记为索引的单词和要索引的单词列表。

要将特定单词添加到索引列表，请高亮显示该单词或短语，然后选择菜单项 工具=>索引=>添加到索引编辑器。如果所选文本包含任何 HTML 标签，应将其移除。

这将打开索引编辑器，并将该单词添加到要索引的条目列表中。你也可以按下面所述在索引编辑器中直接输入单词。

创建索引

在标记单词或将它们添加到列表之后，要实际创建索引，只需选择菜单项 工具=>索引=>创建索引。

这将创建或更新一个名为 Index.xhtml 的 HTML 页面。该页面会被标记为语义类型“index”。条目按字母顺序排列，使用默认样式时看起来像这样：

自定义索引样式表

索引页面使用一个单独的 CSS 文件（sgc-index.css）来格式化索引。如果该文件已经存在于你的书中，它不会被覆盖（因此你可以在不丢失更改的情况下自定义它）。但如果它不存在，则会到你的首选项文件夹中查找sgc-index.css，并将其用作默认文件。如果你的首选项文件夹中没有该文件，那么 Sigil 会为索引创建一个默认的样式表。

索引编辑器

索引编辑器用于管理将纳入索引的条目列表。它不包含你标记为索引的单词——那些单词会被自动纳入。

要打开索引编辑器，请选择菜单项 工具=>索引=>索引编辑器 或其键盘快捷键：

要包含的文本

“要包含的文本”列是你希望 Sigil 在文本中搜索的模式列表，然后使用“索引条目”列中的格式为其创建索引条目。“要包含的文本”列中的条目可以使用以下格式：

  • 单词：书中的单词必须与列出的单词完全匹配（区分大小写）。不要包含任何 HTML 标签，只要预览中显示的那些单词即可。
  • 正则表达式：你可以输入大多数正则表达式模式——它们将按段落逐个匹配。例如，要在忽略大小写敏感性的情况下匹配单词，可以使用“[Gg]utenberg”或“(?i)Gutenberg”。

你可以将文本粘贴到 要包含的文本 字段中——例如从包含单词列表的文件中粘贴——该文本会自动按行拆分为单独的条目。

你也可以使用 打开 来打开一个单词（以及用制表符分隔的条目）文本文件。

索引条目

“索引条目”列是与“要包含的文本”列匹配的单词实际显示在索引中的内容。

“索引条目”列中的条目可以使用以下格式：

  • 空白：如果你将条目留空，则 要包含的文本 列中输入的单词将用于该条目的名称。
  • 单词：如果你输入一个单词或短语，则将使用该单词或短语（例如使用 Oak 而不是 oak）。
  • 标题/单词：如果在名称中使用“/”，则会创建一个层级分组（例如 Forest/Tree/Oak 会创建一个条目 Oak，该条目归档在 Tree 下，而 Tree 归档在 Forest 下）。
  • 标题/：如果在条目名称末尾使用“/”，则会创建一个层级分组，且 要包含的文本 列中的单词将用作子条目。

上下文菜单

大多数与编辑条目相关的操作都可以通过使用上下文菜单来完成。

选择一个或多个条目，然后在所选内容上右键单击，可获得以下选项：

  • 添加条目：在你单击的条目下方添加一个空白条目。
  • 编辑：编辑该条目。
  • 剪切：删除一个或多个以后可以粘贴的条目。
  • 复制：复制一个或多个以后可以粘贴的条目。
  • 粘贴：粘贴任何已剪切/复制的条目。
  • 删除：删除条目。
  • 打开：用文件中的条目（索引文件或文本文件）替换当前的索引列表。
  • 重新加载：从上次保存的状态恢复列表。
  • 另存为：将所有条目保存到一个文件，以保存每本书各自的索引条目列表。
  • 自动填充：自动将书中的每个单词填充为索引条目。
  • 全选：选择所有条目（便于删除）。

保存

要将条目保存到磁盘，请单击保存。

要退出而不保存条目，只需关闭窗口即可（使用关闭按钮或Esc键）。你也可以使用上下文菜单 重新加载 从磁盘重新加载条目——这会删除你当前的条目。

如果你保存时正在运行多个 Sigil 实例，其他 Sigil 实例会自动重新加载新保存的索引条目，以保持所有实例同步。

过滤

你可以使用过滤文本框来限制显示的条目列表，以便更容易找到某个条目。

打开或导入文本文件

上下文菜单项 打开 可用于打开已保存的索引文件，也可以打开文本文件。

你可以在文本文件中只列出 要包含的文本 单词——每行一个。或者，你可以用制表符分隔同时包含 要包含的文本 和 索引条目 值——每行一个。

索引工具栏

为了让更快捷地创建索引，用户可以使用 视图=>工具栏=>索引 菜单来显示索引工具栏。

  • 打开索引编辑器
  • 将单词添加到索引编辑器
  • 标记要纳入索引的文本
  • 生成索引 HTML 文件。
