图像、视频与音频

— 向你的图书插入媒体文件 —

点击 插入文件 按钮，或选择菜单项 插入=>文件 或其快捷键，即可将任何图像、视频或音频文件插入你的图书。如果该文件尚未添加到 EPUB 中，您可以从计算机中选择它。

EPUB 2 和大多数墨水屏阅读器仅支持图像，但在需要时也可以插入视频和音频。EPUB 3 原生支持视频和音频。

将媒体文件插入图书时，文件会先添加到 EPUB 中，再创建指向它的链接。因此文件只需添加一次，即可多次链接；也可一次性添加多个文件，之后再为它们创建链接。

向你的 EPUB 添加媒体文件

您可以通过多种方式为图书添加图像、视频或音频文件：

  • 点击 Add 添加现有文件 按钮。
  • 选择菜单项 文件=>添加=>现有文件。
  • 在书籍浏览器中右键单击某个文件，然后选择 添加现有文件。

以上所有方式都会显示一个标准文件对话框，允许您从计算机中选择一个或多个文件。您可以选择任意媒体文件。如果其中任何文件已存在于书中，会提示您确认是否替换。

这些文件会根据扩展名添加到书籍浏览器中相应的文件夹。不过，它们尚未在书中的任何位置实际使用——只是处于可用状态。要使用它们，需在书中链接或插入。

实际上，添加文件与插入进图书可以一步完成：

  • 选择菜单项 插入=>文件，然后点击 其他文件...。

将文件插入你的图书里

要将图像、视频或音频文件插入图书，请先在代码视图中点击想要放置该文件的位置，然后点击 插入文件 按钮：

系统会显示您图书中的文件列表。选择一个或多个要插入的文件并点击 确定，或者双击所需文件即可自动选择并插入它。

点击 其他文件... 按钮，您可以从计算机而不是从 EPUB 中选择文件。这些文件会被添加到书中，然后自动插入。

您可以通过在左侧选择文件类型，或在 过滤 文本框中输入部分文件名，来筛选显示的文件。

您可以在 插入文件 对话框中点击左下角的缩放按钮来选择缩略图的大小，从而为图像启用缩略图。启用缩略图会使对话框变慢，因此您可以不断缩小缩略图直到其消失，从而取消它们。

要查看图像、视频或音频文件的详细信息，请在书籍浏览器中双击其文件名。

编辑媒体文件

图像、视频或音频文件加入 EPUB 后，即可在 Sigil 中轻松编辑。

只需在书籍浏览器中右键单击其文件名，并选择菜单项 打开方式。这会在您选择的外部编辑器中打开该文件。

详情请参阅外部编辑器一章。

删除未使用的媒体文件

选择菜单项 工具=>删除未使用的媒体文件，即可自动删除所有未使用的图像、视频和音频文件。Sigil 会列出没有任何 HTML 或 CSS 文件链接的文件，供您确认要删除哪些——或取消删除。

要更精细地控制单个文件的删除，可使用报告查看每个文件的使用次数，再确认想要删除的文件——详见报告一章。

您可以双击某个文件，在标签页中显示该文件。

封面图片

您可以使用添加封面快速添加封面图片。

但如果您想手动添加封面，请注意封面图片具有特殊性：必须告诉 EPUB 哪张图片用作封面。不同电子书阅读器识别封面的方法不同，因此应同时使用以下两种方法：

  • 在图书开头创建一个 cover.xhtml 文件，然后将你的图片插入其中。
  • 通过在书籍浏览器的 Text 文件夹中右键单击 cover.xhtml 文件、选择 添加语义 并选择 Cover（封面），将该文件标记为封面文件。
  • 通过在书籍浏览器的 Images 文件夹中右键单击实际的封面图片文件、选择 添加语义 并选择 Cover（封面），将其标记为封面。

请确保您有权使用书中的图片，因为大多数图片受版权保护，使用可能需要获得许可。
