EPUB 入门

如果你打算创建一本 EPUB 电子书，先了解一下 EPUB 是什么、Sigil 能提供哪些帮助，大概是个不错的主意。

EPUB 是一种为展示图书而创建的标准文件格式，Sigil 可以帮你创建 EPUB。Sigil 的设计目标是：把你在文字处理软件中创作的书稿，转换为可以在电子书阅读器上发布和阅读的标准 EPUB 文件。它也可以用来清理和重新排版 EPUB。

你想把 EPUB “清理”到什么程度，取决于你自己。如果你只是为自己排版一本书，可能不必在意太多细节，只需把 Sigil 用到足够让它在你的阅读器上看起来正常即可。但如果你是为了出版而排版，你会发现 Sigil 让你很容易查看并修改书中任何一处细节。

在典型的文字处理软件中编辑文档时，最终通常会得到一个文件，例如 mybook.doc。这个文件包含该文档的全部信息。EPUB 略有不同：它不是只用一个文件来存储信息，而是用多个独立的文件分别存储构成文档的各个部分——章节、图片、目录等等。但由于把许多零散文件分享给别人很不方便，这些独立文件实际上被存放进了一个扩展名为 .epub 的单一压缩 zip 文件，例如 mybook.epub。EPUB 文件本质上就是一个 zip 文件，其中包含了你的书所需要的全部文件。

Sigil 可以打开和创建 EPUB 文件，并允许你编辑、重新排列以及排版 EPUB 中的各个文件（比如正文和目录）。

一旦你把文档复制或导入到 Sigil 中，它就成为 EPUB 文件的一部分。当你在 Sigil 中保存这本书时，你的文档就会被保存到 EPUB 文件里。

请注意，Sigil 的设计使其对旧的 EPUB 2 标准和更新的 EPUB 3 标准同样适用。许多旧款电子书阅读器只支持 EPUB 2，不过通过为较新的 EPUB 3 版本添加 Guide 和 NCX，并将其限制为只使用 EPUB 2 特性，就可以生成一个完全向后兼容的 EPUB 3，它应该能在所有阅读器上正常工作。

EPUB 3 正在迅速成为国际出版标准，因为它既支持从右向左（RTL）也支持从左向右（LTR）的文本布局，支持音频、视频、内部与外部资源，并且更好地支持无障碍功能——允许多媒体叠加、改进语义角色标注，甚至支持有限的 JavaScript 用于实现交互功能。
