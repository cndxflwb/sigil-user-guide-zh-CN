预览

— 显示代码视图中的更改 —

预览是可移动的窗口，提供代码视图内容的动态更新只读视图。可点击预览底部工具栏中的 检查页面 按钮（ 图标）检查代码和样式。

可用预览展示代码更改的结果（包括即时反馈的错误），也可打开 CSS 样式表进行修改，效果同样显示在预览中。

选择菜单项 视图=>预览 或其键盘快捷键来激活预览窗口：

可使用快捷键打开或关闭预览窗口，有第二台显示器时，甚至可将该窗口移过去。

当您在代码视图中点击某个位置时，预览窗口会立即更新。当您停止输入一小段时间后，它也会更新。

如果您在预览中点击，代码视图标签页会同步到相同的位置。

预览窗口的工具栏

预览窗口拥有自己的专用工具栏，位于预览窗口左下角、加载进度条区域之前。从左到右，每个工具的功能如下：

  • 打开/关闭预览的检查器（见后文说明）

  • 选择页面上的全部内容

  • 将选区内容复制到剪贴板

  • 重新加载/更新预览

  • 在预览的自定义 CSS 文件之间循环切换。更多信息请参阅“高级主题”一章中关于 custom_preview_style.css 和 custom_preview_style_alt.css 文件的讨论——这些文件可创建并保存在 Sigil 的用户首选项文件夹中。

  • 打印/打印预览中的内容

检查器

点击预览底部工具栏上的 按钮可打开/关闭检查器部件。可按喜好调整其大小和位置，Sigil 会记住设置

检查器窗口是 HTML 开发者工具，可详细检查图书外观背后的代码。用它可了解图书中特定部分为何以某种方式显示，并对样式和文本做临时更改，观察其对文本的影响。

在检查器窗口中所做的任何更改都只是临时的，不会保存！

有关使用内置于预览中的检查器的更多信息，特别是如何用它确定任何特定标签正在使用的确切 CSS，请参阅此教程。

循环切换自定义 CSS

循环切换自定义 CSS 工具允许用户更改控制预览面板外观的 CSS 样式表。更改方式是在预览底部的工具栏上点击该按钮。

若首选项文件夹中不存在以下任何 CSS 样式表，该部件将被禁用：

  1. custom_preview_style.css
  2. custom_preview_style_alt.css

出现这种情况时，预览工具栏上的 循环自定义 CSS 文件 按钮将变灰（即被禁用）：

完全可以在 Sigil 打开之后再创建 custom_preview_style.css 或 custom_preview_style_alt.css 文件，但此时须打开一个新的主窗口，才能在预览中激活新的 CSS 文件。

当 Sigil 处于深色模式且用户选择了 使预览在深色模式下模拟一个深色的外观 选项时，此功能特别有用。在这种情况下，黑色边框、表格布局、深色等在预览中无法正常显示。但借助合适的自定义预览样式表，可以克服这一困难。

现在，若在首选项文件夹中添加一个名为 custom_preview_style.css 的文件，写入以下选择器和属性：

body {
    background: initial !important;
    color: initial !important;
    filter: invert(1);
}

svg, img {
    filter: invert(1);
}

在关闭并重新打开 Sigil 之后，我们会看到该按钮已启用。此时打开 Dark mode case.epub 并按下该按钮，预览面板这次看起来将是这样：

所有颜色都反转了，对比度大大提升，文本、边框和表格布局都能正常显示。

再次关闭 Sigil，在首选项文件夹中添加一个名为 custom_preview_style_alt.css 的文件，写入以下代码：

html {
    background: white !important;
    color: black !important;
}

模拟墨水屏

循环切换自定义 CSS 部件不仅适用于 Sigil 的深色模式；在浅色模式下同样有用。

一本 EPUB 中包含许多彩色图片是很常见的，EPUB 中的某些标题和文本使用彩色也很常见。但是，这些图片和文本在墨水屏（e-ink）上会是什么样子？在只有 16 级灰度的屏幕上它们还能清晰可读吗？

如果我们有如下页面：

它在墨水屏设备上会是什么样子？

使用一个包含以下代码的 custom_preview_style.css（或 custom_preview_style_alt.css），即可轻松回答上述问题：

body {
    background: initial !important;
    color: initial !important;
    filter: url('data:image/svg+xml,\
    <svg xmlns="http://www.w3.org/2000/svg">\
      <filter id="posterize">\
        <feComponentTransfer>\
    	   <feFuncR type="discrete" tableValues="0 .0625 .125 .1875 .25 .3125 .375 .4375 .5 .5625 .625 .6875 .75 .8125 .875 .9375 1"/>\
		   <feFuncG type="discrete" tableValues="0 .0625 .125 .1875 .25 .3125 .375 .4375 .5 .5625 .625 .6875 .75 .8125 .875 .9375 1"/>\
		   <feFuncB type="discrete" tableValues="0 .0625 .125 .1875 .25 .3125 .375 .4375 .5 .5625 .625 .6875 .75 .8125 .875 .9375 1"/>\
		   <feFuncA type="discrete" tableValues="0 .0625 .125 .1875 .25 .3125 .375 .4375 .5 .5625 .625 .6875 .75 .8125 .875 .9375 1"/>\
  	    </feComponentTransfer>\
      </filter>\
    </svg>#posterize') grayscale(1);
}

（注意：上述代码的解释超出了本指南的范围。该代码混合使用了 svg 滤镜和 css 滤镜，展示了 EPUB3 与 CSS3 最强大的特性之一。）
