使用查找与替换编辑

在 Sigil 中，查找与替换可以用来查找任何文件中的任意文字。更重要的是，它还可以用来修改文字——但只能在代码视图中使用。

要打开查找与替换，请使用菜单项 搜索=>查找与替换 或其快捷键。查找与替换窗口会在编辑窗口正下方打开，并一直保持显示，直到关闭。

“查找”和“替换”文本框分别用于输入要查找的内容和要替换成的内容。右侧的按钮（查找、替换、重新开始、替换/查找、替换所有和计数所有）用于执行搜索。底部的模式下拉框可以更改搜索内容、搜索位置以及搜索方向。

每个下拉框和按钮都有包含更多详情的工具提示。

使用查找与替换

要进行简单的修改，请在查找框中输入要搜索的文字，并在替换框中输入用来替换的新文字：

点击计数所有 ，显示查找框中文字的匹配数量（统计和查找会忽略替换框中的内容）：

你会发现，如果之前不在代码视图，现在已经自动切换过去了！这是因为主要搜索都在代码视图中完成。本教程中请一直留在代码视图。

注意，匹配数量会显示在右下角。

现在点击查找 。查找框中文字的下一处出现位置将高亮显示：

点击替换 ——这会把文字改成替换框中的内容，并保持新文字处于高亮状态：

为了更轻松地逐个查找并替换，你可以使用替换/查找 按钮。点击该按钮时，如果选中的文字匹配，Sigil 就会替换它，然后查找并高亮显示下一个匹配项。

如果你确认替换功能工作正常，可以使用替换所有 ，一次性更新文档中所有匹配的文字，而不必逐个替换。

在使用全部替换之前，务必先用全部统计，并可能执行几次替换——以确保查找与替换字符串输入正确。

你可能注意到了包含“当前文件”的选择框。如果把“当前文件”改成“所有 HTML 文件”，查找或替换将在 EPUB 中的每个 HTML 文件中执行：

这就是为什么在 Sigil 中编辑可以如此快速。

查找与替换最后一个主要功能是支持使用正则表达式——更多细节请参阅高级查找与替换一章。
