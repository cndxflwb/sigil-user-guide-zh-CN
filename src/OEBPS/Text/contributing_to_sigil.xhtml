翻译 Sigil

非常鼓励将 Sigil 翻译成其他语言。目前已有一个活跃的志愿者社区在翻译 Sigil，随时可以添加新语言。

翻译 Sigil 的最佳方式是使用 Transifex 提供的基于网页的翻译系统。使用 Transifex 完成的翻译会在新版本发布前下载：

  • Sigil 翻译 @ Transifex

或者，你也可以使用本地桌面工具进行翻译。Sigil 使用 Qt 的 Linguist 工具来创建和编辑翻译。你可以下载 Qt 并手动编译这些工具，也可以使用预编译好的软件包：

使用桌面工具更新和创建新翻译文件的流程相同：

  • 打开终端并切换到 src/Sigil/Resource_Files/ts 目录。这里存放着所有原始翻译文件。
  • 运行 lupdate ../../* -ts out.ts 生成新的翻译文件，或用新添加的字符串更新现有翻译文件。
  • 使用 Linguist 为指定 ts 文件中的字符串编写翻译。

所有翻译文件都应采用 sigil_lang.ts 的形式。其中 lang 是两位语言代码。例如波兰语翻译的文件名为 sigil_pl.ts。
