代码视图

— 直接编辑 XHTML 与 CSS —

代码视图允许您直接编辑 EPUB 中包含的 XHTML 和 CSS 代码，是高级用户最常用的编辑方式。

使用预览窗口，可自动更新并显示代码视图中正在编辑页面的只读、类网页浏览器版本。

代码视图功能非常强大，但在其中编辑时必须小心，确保输入的是有效的 XHTML 或 CSS 代码。

代码视图不仅会原样显示 EPUB 中的 XHTML 和 CSS 代码，还会用不同颜色高亮显示标签和元素，使其更易于阅读和发现问题。

可在首选项的“外观”中，更改代码视图高亮所使用的颜色。

格式

格式工具栏上的所有按钮都可供您使用。

上下文菜单

右键单击文本可看到上下文菜单，编辑 XHTML 时包含以下选项：

  • 剪贴板：从您定义的任何文本剪贴板条目中选择。
  • 添加到剪贴板：将选中的文本保存到你的剪贴板中。
  • 跳转到链接或样式：与 搜索=>跳转到链接或样式 相同。
  • 标记选中文本：与 搜索=>标记选中文本 相同。也可能显示 取消标记已标记文本。
  • Reformat XHTML:|→XHTML 重新格式化：←|
    • 修复并美化代码：修复当前文件，并做美观的格式化。
    • 修复并美化——全部 HTML 文件：修复并美化所有 HTML 文件。
    • 修复代码：若当前文件还不是有效的 XHTML，则将其修改为有效。
    • 修复代码——全部 HTML 文件：若 HTML 文件还不是有效的 XHTML，则将其修改为有效。

右键单击拼错的单词可看到以下选项：

  • 建议：从建议的替代词中选择。
  • 添加到默认词典：将该单词保存到首选项中选定的默认词典。
  • 添加到词典：将该单词保存到您在子菜单中选定的词典。
  • 忽略：在 Sigil 重启之前跳过对该单词的拼写检查。

右键单击图像可看到以下选项：

  • 查看图像：在可调整大小的窗口中显示图像。也可按住 Ctrl 键点击文件名，或使用 跳转到链接或样式 快捷键。图像会缩放至适合窗口，编辑时可保持打开。
  • 在新标签页打开图像：在标签页中以完整分辨率打开图像文件。

编辑 CSS 时，上下文菜单包含以下选项：

  • 重命名选中的类：选中某个类名后，可同时在该样式表和所有受影响的 XHTML 文件中重命名。
  • 重排 CSS：将 CSS 重新格式化为单行或多行。

此外还有常规选项：

  • 撤销
  • 重做
  • 剪切
  • 复制
  • 粘贴
  • 删除
  • 全选
