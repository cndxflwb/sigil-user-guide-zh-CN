书籍浏览器

—管理 EPUB 中的文件—

构成 EPUB 的所有文件都可以在书籍浏览器中查看和访问。

默认用户界面中，书籍浏览器停靠在左侧。可通过菜单项 视图=>书籍浏览器 控制其显示或隐藏，也可将其拖到其他位置。

单击文件夹名称左侧的小箭头或加号，或双击文件夹，即可展开或折叠。

双击文件会在代码视图窗口的标签页中打开它。若已打开，视图会切换到该文件所在的标签页。书籍浏览器始终会高亮显示代码视图窗口中当前活动的文件/标签页。

右键单击文件名或文件夹会显示上下文菜单选项。

文件夹与文件

书籍浏览器按文件类型（文档、样式表、图像、字体等）把文件组织到若干虚拟文件夹中。需要注意的是，从 Sigil 1.0 开始，为了便于编辑/多选，文件夹及其内容都以这种方式显示。文件夹的名称并不反映 EPUB 内部实际文件夹的真实名称。例如，nav.xhtml 文件会与所有其他 XHTML 文件一起显示在虚拟的 Text 文件夹中，即使它在 EPUB 内位于另一个实际文件夹里。

要查看完整文件路径和实际文件夹名称，把鼠标悬停在文件上即可。如果该文件带有 guide 语义类型或 manifest 属性，也会一并显示。

将鼠标悬停在文件夹上会显示实际文件夹名称、完整文件路径以及该虚拟文件夹中的文件数量。

要在书籍浏览器中始终显示完整文件路径，请进入 编辑=>首选项=>外观=>主用户界面，并勾选“书籍浏览器应显示完整路径”。

各虚拟文件夹及其包含的文件类型如下：

  • Text:（文本）构成书籍正文的 XHTML、HTML 和 HTM 文件。

  • Styles:（样式）控制书籍排版的 CSS 样式表。

  • Images:（图像）书中的 PNG、JPEG、GIF、SVG 及所有图像文件。

  • Fonts:（字体）书中的 TTF、OTF 及任何其他内嵌字体。

  • Audio:（音频）书中的 MP3、AAC、MPG、MPEG、M4A 及任何其他内嵌音频文件。

  • Video:（视频）书中的 MP4、OGG、WEBM、M4V 及任何其他内嵌视频文件。

  • Misc:（杂项）通常由 EPUB 阅读器使用并随书存储的其他文件，例如 javascript（JS）文件、SMIL 文件以及其他纯 XML 文件。

  • No virtual folder:（无虚拟文件夹）NCX（.ncx）和 OPF（.opf）文件不放在虚拟文件夹中。NCX 包含 EPUB2 可读的书籍目录（EPUB2 必需，EPUB3 可选）。OPF 包含书中的文件清单，还保存书籍元数据，并决定顶层文档显示顺序及部分语义数据。OPF 基本上是 EPUB 的控制文档。

在 1.0 版本之前，Sigil 会自动把每个 EPUB 重构为标准的 Sigil 结构，因此书籍浏览器中的文件夹名称始终与实际使用的文件夹一致。Sigil 1.0 不再这样做：它按原样加载 EPUB，不移动文件、不重命名文件夹，你可以自由组织 EPUB 结构和命名文件夹。不过，若更喜欢旧的标准 Sigil 结构，可使用菜单项 工具=>按 Sigil 规范重建EPUB 来重构 EPUB。

选择多个文件

要选择文件夹中多个连续的文件，先单击第一个想要的文件，然后按住Shift键单击最后一个文件，从第一个到最后一个之间（含两端）的所有文件都会选中。要选择（或追加）不连续的文件，按住Ctrl键（Mac 上为Cmd键）逐个单击文件。你也可以右键调出上下文菜单，选择 选择所有 一次性选中文件夹中的所有文件。（注意：只能在同一文件夹内，即同类型文件之间多选。）

选好文件后，可用右键上下文菜单对选中文件执行操作。

重新排序文件

Text 文件夹中文件的顺序很重要，因为它就是文件在 OPF（.opf）中的排列顺序，也就是向读者显示时的顺序。

Text 文件夹中的文件可以上下拖动，便于快速重新排序。在书籍浏览器中改变这些文件的顺序时，OPF 会自动更新，但 NCX 或 EPUB3 NAV（nav.xhtml）不会自动更新。关于更新目录文件的更多信息，请参见目录一章。

也可使用上下文菜单重命名文件。

所有其他文件夹中的文件按字母顺序自动排序，无法重新排列。这些文件的顺序不影响书籍的显示方式。

上下文菜单

在书籍浏览器中右键单击一个或多个项目会弹出包含相关操作的上下文菜单。根据单击对象是文档、样式表、图像还是文件夹等，会出现不同的上下文菜单。

可用的上下文菜单命令包括：

删除

删除选中的文件。（不能删除最后一个剩余的 HTML 文件。）

由于该操作无法撤销，删除前会提示你确认。

如果被删除的文件包含在目录中，请记得更新或重新生成目录。

重命名

若只选中一个文件重命名，文件名会高亮显示，直接输入新名称即可。默认情况下扩展名不高亮，以便更轻松重命名，但必要时也可修改扩展名。

如果选中多个文件，会弹出一个对话框询问你想如何重命名这些文件：

为第一个文件输入新名称，并在名称末尾包含一个起始编号。Sigil 会使用你提供的名称、从你提供的编号开始依次为每个文件重命名。若重命名会导致书中出现重复文件名，该文件不会重命名。也可重命名扩展名。

例如，如果原始文件名为：Section0001.html, Section002.html, Section0003.html……那么：

chapter_01
会把文件重命名为：chapter_01, chapter_02, chapter_03 …，并保留 .html 文件扩展名。
Section_0099
会把文件重命名为：Section_0099, Section_0100, Section_0101 …，并保留 .html 文件扩展名。
Part2-Chapter08
会把文件重命名为：Part2-Chapter08, Part2-Chapter09, Part2-Chapter10 …，并保留 .html 文件扩展名。
.xhtml
只会把所有文件的扩展名重命名为.xhtml，不改变基本文件名。
chap01.xhtml
会把文件重命名为：chap01.xhtml, chap02.xhtml, chap03.xhtml …。

重命名文件时，EPUB 中指向该文件的所有链接都会自动更新。

正则重命名

正则重命名是更强大的重命名工具，允许你使用正则表达式查找并替换文件名中的文本。

选中要重命名的文件，右键选择 ReGex （正则）重命名，会弹出 正则文件重命名 对话框。输入要查找的正则表达式和要替换成的文本，然后单击确定。

重命名表会显示新旧文件名。如果新名称可以接受，单击确定即可重命名文件。

移动

把选中的文件移动到其他文件夹。

执行 移动 时会打开一个对话框，提供现有文件夹的下拉菜单供选择。

你也可以直接在文本框中输入新名称，创建一个新文件夹来存放移动的文件。

按确定执行移动。

合并

如果选中单个 HTML 文件，该文件会被合并到列表中它前面的 HTML 文件里。

如果选中多个 HTML 文件，所有文件都会被合并到你选中的第一个 HTML 文件中。

也可使用合并快捷键。详见拆分与合并一章。

排序

按字母数字顺序对选中的 HTML 文件排序。这意味着包含数字的文件名按预期的数字顺序排序，例如“1, 3, 2, 10”将重新排列为“1, 2, 3, 10”，而不是“1, 10, 2, 3”。

链接样式表

为选中的 HTML 文件链接样式表。在对话框中选择样式表：只有带勾选标记的样式表会被链接，未勾选的样式表会被取消链接。

首次打开对话框时，只有当所有选中文件都链接了某个样式表，该样式表才会显示勾选标记。

渲染文档时，样式表按列表中的顺序应用。

链接到Javascript

为选中的 HTML 文件链接已有的 javascript 文件（仅限 EPUB3）。在对话框中选择 javascript 文件：只有带勾选标记的 javascript 会被链接，未勾选的 javascript 文件会被取消链接。

添加语义

添加语义允许你从滚动列表中为选中的文件指定语义类型。EPUB 阅读器可能会使用这一信息（在 EPUB2 中存储于 .opf 文件，在 EPUB3 中存储于 .opf 和 nav 文件）来决定如何向读者呈现这些文件。每个文件只能有一个语义类型。

应使用Text（文本，EPUB2）或Body Matter（正文，EPUB3）来指示打开书籍时首先显示的页面，但并非所有阅读器都遵循这一约定。

打开方式

在外部应用程序中打开文件，例如图片编辑程序或你喜欢的 HTML 编辑器。更多信息请参见外部编辑器一章。

另存为

把选中的文件保存到你的计算机上。如果你需要在 EPUB 之外访问这些文件，这会很有用。

添加空白 HTML 文件/样式表/SVG 图像

给相应文件夹添加一个空白 HTML 文件、CSS 样式表或 SVG 图像文件。对于 HTML，新文件会添加在你右键单击的文件正下方；如果右键单击的是文件夹名称，则添加到文件夹底部。对于其他文件夹，新文件按字母顺序插入。

新文件会从0001开始使用最小的可用编号命名（例如Section0001.html），之后你可以重命名它。

该上下文菜单命令与主菜单项 文件=>添加 相同。

要使用自定义的 HTML 文件或 CSS 样式表，只需创建文件并按如下命名：EPUB2 使用 user-template2.xthml 和 user-template2.css，EPUB3 使用 user-template3.xhtml 和 user-template3.css。然后把文件放入 Sigil 首选项文件夹（Windows 上：编辑=>首选项；Mac 上：Sigil=>首选项，然后单击打开首选项文件夹按钮，把文件复制到该文件夹中）。这样，每次添加空白 HTML 文件或添加空白样式表时，都会插入你的自定义模板。

添加副本

给选中的 HTML 或 CSS 文件创建副本，并添加到文件夹中。

添加现有文件

添加位于计算机上、EPUB 之外的文件。

会打开一个对话框，让你从计算机中选择一个或多个文件导入 EPUB。文件会根据扩展名添加到相应的虚拟文件夹中，与你右键单击的文件或文件夹无关。

这与主菜单项 文件=>添加=>现有文件 以及工具栏上的添加现有文件按钮相同。

选择所有

快速选中当前文件夹中的所有文件，以便一次性对它们执行重命名、链接等操作。

使用 W3C 验证（仅限 CSS 样式表）

如果右键单击 CSS 样式表并选择 使用 W3C 验证，Sigil 会打开浏览器窗口并把样式表数据发送到 W3C 验证服务，该服务会显示所选样式表的验证结果。（如果打开的是 HTML 编辑器，请在浏览器中打开生成的 HTML 文件。如果你设置了 HTML 文件用编辑器而不是浏览器打开，就可能出现这种情况。）

封面图片（仅限图像文件）

为选中的图像添加“cover”（封面）语义标识。

字体混淆（仅限字体文件）

如果你在电子书中使用自定义字体，右键单击字体文件可以定义内嵌字体在 EPUB 中的存储方式。通常向 EPUB 添加字体时，字体以可读形式存储。某些情况下你可能不希望读者直接获取字体，此时可以混淆或干扰电子书中的字体。混淆后读者无法直接访问字体，但 EPUB 阅读器仍能正常使用。混淆的细节及其影响超出本指南范围，但网上有很多相关资料。

混淆选项包括：

  • 无
  • 使用 Adobe 方法
  • 使用 IDPF 方法
The method will have a checkmark next to it if all selected fonts use that method.|→如果所有选中的字体都使用某种方法，该方法旁边会显示勾选标记。←|

重新编排目录项（仅限 .ncx 文件）

从 1 开始，对.ncx文件中目录条目的 playOrder 和 navPoint id 进行顺序重编号。该功能用于在你手动添加或删除目录条目后整理目录编号。

你也可以使用菜单项 工具=>目录=>编辑目录 或编辑目录按钮。只需保存目录，id 就会自动重新编号。

文件中的任何 navList 或 pageList 项目都不会被保存——重新编号后只保存目录条目。
