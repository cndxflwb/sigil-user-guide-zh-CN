新特性

最新版本的 Sigil 包含数百项更改、缺陷修复和新功能，同时仍保留了早期版本中大部分相同的易用界面。Sigil 几乎更新和改进了全部代码，特别聚焦以下几个方面：

  • 稳定性：先前版本所有已知崩溃及相关缺陷均已定位并修复，更新 EPUB 时 Sigil 完全稳定。

  • 健壮性：Sigil 读取文件时能自动修正常见问题，打开无效 EPUB 时不再退出。保存功能已增强，可执行更多完整性检查。拆分与合并可精确地在指定位置进行，不会丢失数据。光标位置在代码视图与预览之间正确同步，查找与替换在单个文件或所有文件上均一致、准确。

  • 性能：Sigil 现在在打开与切换标签页、生成目录、合并文件、批量重命名、替换文本等许多方面提速显著。

  • 灵活性：添加了更多首选项、选项和功能，可按需使用 Sigil。

对 Sigil 所做的全部更改详细列表，请参阅 变更日志。

Sigil 近期的主要变更包括：

  • 从 QtWebKit 切换到 QtWebEngine QtWebEngine 减少了内存增长，堵住了许多重大内存泄漏，并持续获得来自 Qt/Google/Chromium 的安全与支持补丁

  • 从 Qt 5.15.X 更新到 Qt6.7.X

  • 移除书籍视图 因为它允许用户错误地创建出在 EPUB 中不可接受的、严重损坏的 xhtml。为替代其部分功能，我们创建了一个名为 PageEdit 的新外部程序，它更适合基本的所见即所得（WYSIWYG）校对和简单编辑。完全不了解 xhtml 或 css 的用户可能想继续使用 Sigil 0.9.14，因为那是最后一个支持书籍视图的版本。关于 PageEdit 及其与 Sigil 的集成，可在首选外部 Xhtml 编辑器一章中找到更多信息。

  • 支持 Python 插件 允许用户自定义 Sigil 的使用方式并将其融入自己的工作流，还能独立于 Sigil 添加自己需要或想要的工具。可以下载并安装这些插件来为 Sigil 添加扩展支持，包括 EPUBCheck、Access-Aide、KindleImport、Kindlegen、FlightCrew、ePub3-itizer、DOCX Import 等插件。关于插件的更多信息、下载地址和安装方法将在后面的章节中介绍。

  • 支持保留用户指定的实体字符

  • Sigil 内置了自己的 Python 解释器（撰写本文时为 v3.11.9），用来支持基于 Python 3 的插件

  • Sigil 使用 Google Gumbo Parser 的特别修改版，按照 HTML5 和 xhtml 规范自动修正 xhtml 解析错误

  • Sigil 现已完全支持编辑和创建流式排版的 EPUB2 与 EPUB3 电子书。

  • Sigil 已移除其对 EPUB 布局的长期限制。完全支持自定义 EPUB 布局。

  • Sigil 在 EPUB3 下添加 Aria 角色和剪贴板变得更加容易。

  • Sigil 新增了正则 Python 函数替换功能。
