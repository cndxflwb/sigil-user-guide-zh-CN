准备好 Sigil 可处理的文件

如果已经有 EPUB 或 HTML 文件，或者打算在 Sigil 中从零开始写作，可以跳过这一步。

如果从文字处理软件创建的文档入手，第一步是把文档转换为 HTML，这样才能导入 Sigil。有些程序可以直接生成 EPUB 文件，有些程序则提供了清理 HTML 输出的附加组件或功能。该用这些程序的 HTML 输出还是 EPUB 输出（甚至是纯文本输出），取决于具体的程序——可以多试几种方式，看哪种效果最好。

HTML 文件越“干净”，转换成 EPUB 就越容易，在多种设备上正确显示的可能性也越大。也就是说，应当使用样式排版，而不是使用过多花哨的格式和布局。

不要指望 EPUB 看起来像纸质书——EPUB 的设计理念就是让读者能够自行控制书籍的显示方式。

虽然格式转换不属于 Sigil 的功能范围，但这里有一些关于转换文件以便导入 Sigil 的建议。

Word 文档

使用 MS Word 菜单项 文件=>另存为筛选过的 HTML，或使用 MS Word Macro @ MobileRead。

这两种方法都力求减少 MS Word 导出的多余代码，让 HTML 文件更干净，在 Sigil 中更容易编辑。应尽量保持代码干净，因为 Word 会添加大量多余的 HTML 标签，这些标签迟早需要删除。

使用 Word 或任何文字处理软件时，都应当尽量使用样式排版，而不是简单地让某些文字加粗、某些文字变大等。为 EPUB 排版时，样式同样是重要概念。

互联网上有许多网站专门讲解如何将 MS Word 文件转换后用于 EPUB。这里只举几个例子：

  • https://www.epubble.com/word-to-epub-tutorial
  • https://justpublishingadvice.com/how-to-convert-word-to-epub/

微软和苹果也都提供了免费应用，可以自动完成这一过程。

LibreOffice ODF/ODT

在将 ODT 文件保存为 html 方面，LibreOffice 文字处理软件具备与 MS Word 相同的能力——文件=>保存副本（将筛选器设为 HTML Document (Writer) (.html)）或 文件=>导出（将筛选器设为 XHTML (.html;.xhtml)）

用于 EPUB 时，最好使用“保存副本”，因为它的输出比“导出”更干净，文档中的格式数据更少。“保存副本”还会链接到各图片，而“导出”会把图片数据嵌入文件。

虽然并非专门针对 EPUB，但在 LibreOffice 在线文档中可以找到一些与此主题相关的信息——将文档另存为 HTML

DOCXImport 插件

要直接从 MS Word 文件创建新的 EPUB，可使用 DiapDealer 开发的 DOCXImport 插件。添加该插件后，可将 docx 直接作为 html 导入 Sigil。

DOCXImport 插件（关于如何安装插件，请参阅插件管理一章）。

注意：该插件会创建全新的 EPUB。如果 Sigil 中已打开现有 EPUB，该文件将被替换，所有未保存的修改都会丢失。

点击 插件=>输入=>DOCXImport 即可运行该插件。

点击 DOCX 文件开始导入，然后选择要导入的文件。

纯文本文件

严格来说，无需把纯文本文件转换成 HTML。Sigil 可以直接打开 .txt 文件。

纯文本文件的段落之间必须有空行，Sigil 才能将其拆分成独立的段落。

纯文本文件并不是理想的源格式，但可能比某些格式更好，因为它不会产生多余的 HTML 标签。如果使用其他格式遇到很多问题，纯文本文件值得一试。有时，给干净的文档添加样式，比费力清理转换出来的文件更快。

其他格式

许多其他文字处理软件（如 LibreOffice）也有另存为或导出为 HTML、甚至另存为 EPUB 的功能，都可以尝试。与 MS Word 一样，可以在互联网上找到关于这一过程的实用建议。

也可使用其他软件把其他格式转换为 HTML 或 EPUB，例如 Calibre——能处理绝大多数电子书格式，可在所有平台上运行，并内置电子书库；还有 Pandoc——一款专门的文档转换应用，支持大量文档格式，包括 EPUB2、EPUB3、docx、odt 以及大多数 Markdown 变体。Pandoc 免费、开源、跨平台，采用 Haskell（GHC）编写。

请注意，任何自动转换都会引入大量多余的代码。如果只是为个人用途排版，可能无需在意这一点。但如果是为专业目的排版图书，或者希望 EPUB 中尽量少出现多余代码，就应当避免使用自动转换。

除了 EPUB 格式，Sigil 主要支持导入 HTML（连同其中链接的图片、css 和媒体文件）以及纯文本文件。从其他格式转换可能相当专业，通常最好交给插件和外部工具处理。已有免费的 Sigil 导入插件，可以直接读入 MarkDown、Kindle、docx 和 odt 格式。
