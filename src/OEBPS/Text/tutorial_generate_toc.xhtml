生成目录

标识你的章节：要让 Sigil 为你生成目录，你必须已经标识了章节名称。如果还没有做这一步，请参阅前面的教程。

标记完所有章节标题后，你可以点击生成目录按钮 ，或使用菜单项 工具=>目录=>生成目录来打开一个新对话框：

该对话框允许你标记哪些标题要包含进目录、哪些不包含。

把某个标题标记为排除在目录之外，这个设置是持久有效的。下次生成目录时，该标题仍然会被排除在外。更多细节请参阅目录一章。

完成后点击确定。

目录窗口会被更新，显示你当前的目录——其中包含你所选的标题：

点击目录窗口中的某个条目，你会跳转到它在书中的位置。

每次修改标题之后，你都应当重新生成目录。

如果你还要生成 HTML 目录，应当在生成 EPUB 目录之后再做，因为 HTML 目录的信息来自 EPUB 目录，而不是直接来自 HTML 文件。

如果还没有保存，请保存 你的书。

更多细节请参阅目录一章。
