验证

— 确保你的 EPUB 没有错误 —

要制作有效的 EPUB，电子书必须符合为 EPUB 定义的标准。这意味着必须包含某些文件和信息，且不含 EPUB 规范所定义的任何错误。为帮助检查 EPUB 是否有效，可使用以下工具，它们均可作为 Sigil 插件免费获取。

使用 EPUBCheck 验证 EPUB（EPUB2 与 EPUB3）

验证 EPUB 时应通过 EPUBCheck 程序运行。可在线使用，也可下载该程序的本地版本：

  • IDPF EPUB 验证器

但在 Sigil 中使用 EPUBCheck 的最佳方式，是下载最新版本的 EPUBCheck 插件并安装它。

EPUBCheck 的开发工作在 https://github.com/w3c/epubcheck（EPUBCheck Github 仓库）进行。

EPUBCheck 使用您机器上的 Java 以及最新版本的 epubcheck.jar 来验证你的 EPUB 是否符合 EPUB 规范。

当 EPUBCheck 作为插件安装并使用时，它会在验证窗口中返回错误和警告，使用户更容易定位并修复错误。

要运行 EPUBCheck，请选择 插件=>有效性=>EPUBCheck。

运行 EPUBCheck 生成报告后，逐条查看列出的问题，然后编辑你的文档来修正它们。

大多数条目都可以双击，直接跳转到书中的相关位置。

每次修改文档后都应重新验证，确认不再存在错误。

常见验证问题：

请注意，错误以粉红色高亮显示，警告以黄色高亮显示。

  • This resource is present in the OPF <manifest>, but it's not reachable (it's unused).（该资源存在于 OPF 的 <manifest> 中，但无法访问（未被使用）。——EPUBCheck 验证信息以英文显示，此处提供中文翻译。下同。译者注）
    • 此警告表示您在 EPUB 中包含了所列文件，但书中并未使用它。若计划打算使用，应建立指向它的链接；否则可删除该文件。可在所有文件或 toc.ncx 中搜索文件名——搜索时省略路径名，例如错误位于 Text/Chapter1.html 时，只需搜索 Chapter1.html。
  • This OPS document is reachable but not present in the OPF <manifest or spine>. "Reachable" means that a reference of some kind that points to this resource exists in the EPUB.（此OPS文档可访问，但未出现在OPF的<manifest> 或 <spine>中。“可访问”意指EPUB中存在某种指向该资源的引用。）
    • 此错误表示你的 EPUB 中存在对某个文件或图像的引用或链接，但该文件并未包含在 EPUB 中。需将该文件添加到 EPUB，或更正文本中使用的文件名。通常可在所有 HTML 文件中搜索所列文件名来找到这些引用。可能还需要重新生成或更新目录。
  • ID value 'SOMEIDNAME' is not unique（ID值“SOMEIDNAME”不是唯一的。）
    • 此错误表示你的 EPUB 中存在名为 SOMEIDNAME 的 ID，且被定义了多次。这类问题通常出现在标题或脚注中，可能由复制粘贴或合并引起。可在所有 HTML 文件中搜索所列的 ID 名称并修改，使所有 ID 互不相同。若问题出现在标题中，且标题为自动生成，可删除该 ID，下次创建目录时会重新生成。
  • attribute 'INVALIDATTRIBUTE' is not declared for element 'SOMEELEMENT'（元素“SOMEELEMENT”未声明属性“INVALIDATTRIBUTE”。）
    • 此错误表示名为 SOMEELEMENT 的 HTML 标签中包含属性 INVALIDATTRIBUTE，但该属性对该标签无效。例如 <h2 invalidattribute="test">。这可能由拼写错误或旧版 HTML 造成。需在所有 HTML 文件中搜索 INVALIDATTRIBUTE，移除、更正或替换每一处此属性。
  • no declaration found for element 'INVALIDELEMENT'（元素“INVALIDELEMENT”未找到声明。）
    • 此错误表示名为 INVALIDELEMENT 的 HTML 标签未被定义。通常只是因为它无效，属于需要更新的旧 HTML 语法。需在所有 HTML 文件中搜索 INVALIDELEMENT，移除、更正或替换为有效的 HTML。
  • element 'INVALIDELEMENT' is not allowed for content model '(p|d|h2|h3|h4|h5|h6|div|ul|ol|...'（“INVALIDELEMENT”这个元素不能出现在此处，根据内容模型，只允许 p、d、h2、h3、h4、h5、h6、div、ul、ol 等元素。）
    • 此错误表示名为 INVALIDELEMENT 的 HTML 标签在 EPUB 中不是有效的 HTML。这通常是旧 HTML 语法，需要更新（例如 <center> 标签应改用样式实现）。需在所有 HTML 文件中搜索 INVALIDELEMENT，将每一处移除、更正或替换为有效的 HTML。
  • value 'SOMENAME' is invalid NCName（“SOMENAME”这个值不是合法的NCName。）
    • 此错误表示存在无效的 ID 名称，可能包含空格或其他无效字符。需搜索 SOMENAME 并修改。

使用 W3C 验证 CSS

也可选择菜单项 工具=>验证样式表，轻松地通过 W3C 网站验证 CSS 样式表文件。

这会将您所有样式表的内容发送给 W3C 服务，由它生成各种问题的报告。

也可在书籍浏览器中右键单击某个样式表并选择验证选项，单独验证该样式表。

验证所使用的 W3C 样式表验证级别，是在首选项菜单中选择的（即 编辑=>首选项=>一般设定=>EPUB2/3 W3C 样式表验证级别）。

CSSValidator 插件

还有一个 CSS Validator 插件，可用于验证您所有的 CSS 样式表文件。使用 插件=>插件管理 安装。

在设备上验证 EPUB

再次提醒（以防您遗漏）：您应始终在尽可能多的设备或程序上测试你的 EPUB。
