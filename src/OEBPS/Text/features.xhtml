功能

— 深入指南 —

本节快速概览 Sigil 的全部功能，其后各章节将详细介绍 Sigil 中的一切可用内容。

您也可以阅读“教程”部分，获取在 Sigil 中完成常见任务的分步说明，然后再回到这里查阅更多细节。

编辑

可使用代码视图编辑图书。代码视图编辑器可直接编辑文件的 XHTML 格式，并编辑对应的 CSS 样式表，让您完全掌控图书，并使用 Sigil 的全部高级功能。将 Sigil 的实时预览窗口与代码视图配合使用，输入时即可即时查看页面显示效果。

*注意*：书籍视图及其所见即所得编辑功能已在 0.9.15 版本中从 Sigil 移除。请参阅“将 PageEdit 与 Sigil 集成”一章，将其作为替代的所见即所得编辑方式。

查找与替换

搜索或替换文本是 Sigil 最强大的功能之一。可在单个文件或全部文件中一次完成搜索或替换；既可搜索简单文本，也可用正则表达式更改或修正文本与格式。搜索模板可保存搜索条件，便于重复使用。

管理文件

书籍浏览器按类型组织 EPUB 中的所有文件，便于快速打开或修改文件。双击文件即可在编辑窗口中打开；右键单击选中的文件，可看到重命名、移动、删除、合并、添加、链接样式表等选项。XHTML 文件按图书中的出现顺序列出——拖放文件即可调整顺序。向图书中添加或插入文件也很方便。

目录

目录（Table of Contents，TOC）窗口精确显示目录的最终样子；点击章节名称即可跳转到对应章节。可随时根据书中的标题生成新目录、直接编辑目录，或创建目录的 HTML 版本。

请注意，在 EPUB3 图书中，为了符合 EPUB3 规范，目录窗口将显示 nav.xhtml（NAV）的内容，而不是 toc.ncx。

修改图书详细信息

元数据编辑器可快速更新书名、作者、语言等图书详细信息。可添加数百种标准 EPUB 元数据条目中的任意一种，例如出版日期、合著者、版权信息等。

首选项

Sigil 的许多设置可在首选项窗口中自定义。例如用户界面语言、键盘快捷键、代码中要保留的实体、文本外观、词典、自动格式化和清理的级别，以及用户界面选项、图标尺寸和插件管理。

验证

Sigil 内置了一项基本健全性检查，至少确保你的代码格式完整、可以解析。需要更高级的检查时，可安装 FlightCrew 插件或 EPUBCheck 插件，从而更完整地验证 EPUB。Sigil 还内置了轻松验证 CSS 的能力：通过在线 CSS 验证网站服务，或通过新的 CSSValidator 插件。

报告

生成报告显示文件详细信息，包括大小、字数、图像是否正在使用、使用了哪些样式、书中的字符等。

拼写检查

使用功能强大的拼写检查对话框检查文本拼写：它会列出所有拼错的单词，可将其保存到词典或直接更正。可创建多个用户词典，并同时使用一个或多个词典。

高级工具

Sigil 提供许多自定义工具协助创作电子书——包括保存了查找与替换条件的搜索模板，以及用于保存和粘贴文本或样式的剪贴板。可自动移除未使用的图像和样式，可用外部程序编辑文件，也可直接跳转到 HTML 代码所使用的样式。

语言支持

Sigil 已翻译成 20 多种语言，可方便地按需更改用户界面语言。它用 C++ 编写，性能出色，并完整支持 Unicode UTF-8 和 UTF-16。
