首选外部 XHTML 编辑器

— 将 PageEdit 所见即所得编辑器集成到 Sigil —

所见即所得编辑模式——旧版 Sigil 用户指南称之为 书籍视图——已在 0.9.15 版本中移除。该模式基于 QtWebEngine/Chromium 浏览器引擎实时编辑 HTML，常导致 XHTML 出错或损坏。由于该引擎内嵌于 Qt 中，这一行为无法更改或修复。损坏的 XHTML 常常无法通过 EPUBCheck 校验，因此大多数出版商不予接受。Sigil 0.9.14 是最后一个保留 书籍视图 编辑模式的版本。

如果仍需在所见即所得环境中进行少量编辑和校对，可以使用 Sigil 维护者开发的独立应用 PageEdit。在 Sigil 的首选项（编辑=>首选项=>一般设定=>设置首选外部 XHTML 编辑器）中设置外部编辑器可执行文件路径后，即可通过 Sigil 的“首选外部 XHTML 编辑器”工具启动 PageEdit。

单击 Sigil 工具栏上的图标，即可在 PageEdit 中打开当前代码视图标签页中的文件/章节。也可以为该按钮使用或指定键盘快捷键来启动编辑器（默认为 F2）。

在 PageEdit 中完成编辑后，改动会保存回 Sigil 并显示在代码视图中，必要时可进行验证和修正。

PageEdit 的编辑界面与旧版 书籍视图 界面非常相似，同样提供工具栏和菜单，可用于格式化文本、设置段落对齐、剪切粘贴、插入现有图像、插入指向现有 XHTML 文件的链接、按章节前后跳转等。PageEdit 有两种模式：预览模式 通过单击链接导航；编辑模式 用于编辑内容。PageEdit 始终以编辑模式打开，单击 PageEdit 中的铅笔图标即可切换。

如需在 Sigil 中同时编辑多个 XHTML 文件，可先在书籍浏览器中选中并打开 OPF（即 content.opf），再单击外部编辑器图标。这样即可编辑 OPF spine 元素列出的所有章节/文件。PageEdit 提供简单的下拉菜单，供用户选择要处理的文件。所有改动均可写回 Sigil。这样，按章节顺序校对整本 EPUB 会更轻松，可随时进行少量编辑或修正。

与使用 Sigil 的“打开方式”功能一样，文件正在 PageEdit 中编辑时，若同时在 Sigil 中修改，可能会丢失数据。请始终先在外部打开文件编辑，完成修改后在 PageEdit 中保存并关闭文件，然后回到 Sigil 中修改该文件。

PageEdit 支持 Linux、Windows 和 macOS 三大主要平台，免费提供，可从Sigil-Ebook 的 PageEdit GitHub 仓库下载。Linux 用户可在本地软件仓库中查找 PageEdit，途径与获取 Sigil 相同。
