用户界面

— 窗口、菜单与工具栏 —

Sigil 的用户界面由以下部分组成：

  • 窗口：用于显示信息的区域，如代码视图、书籍浏览器、预览和目录。
  • 主菜单：主菜单栏位于界面顶部，大多数命令如 文件=>打开 都可在此访问。
  • 键盘快捷键：所有菜单项的快捷键都可自定义，例如用 Ctrl+S 保存文件。
  • 工具栏按钮：可移动的按钮，用于快速访问许多菜单项。
  • 上下文菜单：右键点击文件名或窗口等对象时显示的命令。

用户指南中的截图可能与你在计算机上看到的略有不同，具体效果取决于操作系统。

Sigil 主界面通过多个窗口呈现信息：书籍浏览器显示书中文件，代码视图用于编辑书籍，预览窗口显示实时预览，此外还有目录窗口、验证结果窗口等。

主菜单

以下是始终位于 Sigil 窗口或屏幕顶部的菜单项列表：

文件

  • 新建：创建空白的 EPUB2 或 EPUB3。
  • 打开：从计算机打开 EPUB、HTML 文件或文本文件。
  • Add:|→添加：←|
    • 现有文件：从计算机添加 HTML 文件、图像等。
    • 空白 HTML 文件：在书中新建 HTML 文件。
    • 空白样式表：在书中新建 CSS 样式表。
    • 空白 javascript：在书中新建空白的 javascript（js）文件。
    • 空白 SVG 图像文件：在书中新建 SVG 图像文件。
  • 保存：保存文件（建议经常保存！）。
  • 另存为：以其他名称保存文件。
  • 保存副本：以其他名称保存文件副本，当前文件不改名（适合备份）。
  • 打印预览：预览当前选项卡的打印效果。
  • 打印：打印当前选项卡。
  • 最近打开的文件列表。
  • 退出：退出 Sigil。若文件尚未保存，会先提示是否保存。（在 Mac 上，“退出”在 Sigil 菜单下。）

编辑

  • 撤销：撤销上一步操作，恢复刚删除、插入或替换的文本。
  • 重做：反转上一次撤销。
  • 剪切：删除选中的文本并将其存入剪贴板以便粘贴。
  • 复制：复制选中的文本并将其存入剪贴板以便粘贴。
  • 粘贴：将之前剪切或复制到剪贴板的文本插入文档。
  • 编辑/从剪贴板历史粘贴：查看并编辑已剪切或复制到剪贴板的文本片段列表，选中片段后粘贴（插入）到文档。保存的片段数量可在首选项中设置。
  • 删除行：删除代码视图中的当前行。
  • Change Case:|→更改大小写：←|
    • 全部小写：将选中的文本改为小写。
    • 全部大写：将选中的文本改为大写。
    • 每个单词首字母大写：将选中的每个单词的首字母改为大写。
    • 句首字母大写：将选中内容的首字母改为大写。
  • 在光标处拆分：立即将当前文件拆分为两个文件。
  • 在标记处拆分：在先前插入的所有拆分标记处拆分文件。
  • 首选项：打开首选项窗口以更改选项。（在 Mac 上，“首选项”在 Sigil 菜单下。）

插入

  • 拆分标记：插入供“在标记处拆分”使用的标记（见 编辑 菜单）。
  • 文件：从书或计算机插入图像、音频或视频文件。
  • 特殊字符：从字符表中插入特殊字符。
  • ID：插入可用于链接的锚点名称。
  • Aria 片段：插入 Aria 专用的建议剪贴板，以提升无障碍支持（仅限 EPUB3）。
  • 角色：插入语义 epub:type 及对应的 Aria role，增强无障碍语义（仅限 EPUB3）。
  • 链接：插入指向文档中某处或其他位置的链接。
  • 结束标签：插入标签，关闭最后一个未关闭的标签。
  • 剪贴板：从第一个剪贴板选择要插入的剪贴。
  • 剪贴板2：从第二个剪切板栏选择要插入的剪贴。

格式

  • Heading:|→标题：←|
    • 标题 1：将段落格式化为 1 级标题。
    • 标题 2：将段落格式化为 2 级标题。
    • 标题 3：将段落格式化为 3 级标题。
    • 标题 4：将段落格式化为 4 级标题。
    • 标题 5：将段落格式化为 5 级标题。
    • 标题 6：将段落格式化为 6 级标题。
    • 正文：将段落格式化为普通文本。
    • 保留现有属性：格式化时保留 class 等属性。
  • 粗体：将文本设为粗体。
  • 斜体：将文本设为斜体。
  • 下划线：为文本添加下划线。
  • 删除线：为文本添加删除线。
  • 下标：将文本设为下标。
  • 上标：将文本设为上标。
  • 左对齐：将文本对齐到左边距（使用“移除格式”恢复默认）。
  • 居中：将文本在屏幕上居中对齐。
  • 右对齐：将文本对齐到右边距。
  • 两端对齐：将文本同时对齐到左右边距。
  • 项目符号列表：将文本转换为带项目符号的列表。
  • 编号列表：将文本转换为带编号的列表。
  • 减少缩进：减少文本的缩进。
  • 增加缩进：增加文本的缩进。
  • 文本方向—左到右：将文本方向设置为从左到右。
  • 文本方向—右到左：将文本方向设置为从右到左。
  • 文本方向—默认：将文本方向设置为默认。
  • 移除格式：删除选中文本内的标签。
  • 移除标签对：移除成对的开始和结束标签（需将光标置于标签内部以选中）。

在标签内按住 Shift 双击，可仅选中该标签的内容；按住 Alt 双击，则选中标签本身及其内容。配合“移除格式”使用十分方便。

搜索

  • 查找与替换：打开“查找与替换”窗口。
  • 查找下一个：向前搜索，定位下一处匹配文本。
  • 查找上一个：向后搜索，定位上一处匹配文本。
  • 替换：替换匹配文本。
  • 替换/查找下一个：替换匹配文本，然后向前搜索下一处匹配。
  • 替换/查找上一个：替换匹配文本，然后向后搜索上一处匹配。
  • 全部替换：按“查找与替换”设置替换所有匹配文本。
  • 全部计数：按“查找与替换”设置统计匹配文本的总数。
  • 试运行全部替换：预演“全部替换”的结果，按“查找与替换”设置显示每一处匹配文本及其替换内容，不会实际替换。
  • 过滤替换：生成一张表格，按“查找与替换”设置列出所有匹配文本及候选替换内容。应用更改前，可先删除不需要的替换。
  • Current File:|→当前文件：←|
    • 在文件中查找下一个：无论“查找与替换”模式如何，仅在当前文件中搜索。
    • 在文件中替换下一个：无论“查找与替换”模式如何，仅在当前文件中替换后查找下一个。
    • 在文件中全部替换：无论“查找与替换”模式如何，仅在当前文件中全部替换。
    • 在文件中全部计数：无论“查找与替换”模式如何，仅在当前文件中全部计数。
  • 书签位置：在代码视图中标记当前位置。
  • 转到链接或样式：转到选中的链接，或转到此标签的 CSS 样式。
  • 返回：返回到设置书签、点击链接或使用“转到链接或样式”的位置。
  • 标记选中文本：标记选中文本供“查找与替换”使用，搜索范围仅限该文本。
  • 跳转到指定行：跳转到代码视图中的指定行号位置。

工具

  • 添加封面：选择一张图片作为封面。
  • 元数据编辑器：打开元数据编辑器，编辑图书信息。
  • Table Of Contents:|→目录：←|
    • 生成目录：使用预定义标题生成目录。
    • 编辑目录：手动编辑目录。
    • 创建 HTML 目录：以 HTML 文件形式创建目录。

  • 按 Sigil 规范重构 EPUB：从 Sigil 1.0.0 开始，载入 Sigil 的 EPUB 保持原样，文件和文件夹均不移动、不改名。这与 Sigil 0.9.18 及更早版本不同：早期版本会自动把每个 EPUB 重构为标准的 Sigil 结构（一个 OEBPS 文件夹、OPF 与 NCX 使用特定名称、文本和图片各只有一个文件夹）。若偏好标准结构，可使用“按 Sigil 规范重构 EPUB”，将 EPUB 手动重构为旧的 Sigil 标准。

  • 基于当前文件名重建 OPF 清单 ID：旧版 Sigil 曾根据文件名生成 OPF 清单 ID，以保证唯一性。文件改名后，清单 ID 仍沿用旧文件名，手动编辑 OPF 时容易混淆。此工具基于当前文件名重建整套清单 ID，同时维护和更新 OPF 中对这些 ID 的所有引用，包括 spine、封面元数据、smil 元数据、其他元数据细化、媒体叠加层、回退 ID 和 spine 属性。

  • 创建自定义空白 EPUB：设计自定义的 EPUB 布局，供新建 EPUB 时使用。
  • Index:|→索引：←|
    • 索引编辑器：管理索引条目。
    • 添加到索引编辑器：将选中文本添加到索引编辑器列表。
    • 标记为索引：创建索引时，将选中文本一并写入索引。
    • 创建索引：生成包含索引列表的 HTML 文件。
  • Spellcheck:|→拼写检查：←|
    • 拼写检查：打开对话框，一次性检查所有单词。
    • 高亮拼写错误的单词：切换是否在代码视图中高亮拼写错误的单词。
    • 下一个拼写错误的单词：在代码视图中查找下一个拼写错误的单词。
    • 添加拼写错误的单词：将拼写错误的单词添加到默认词典。
    • 忽略拼写错误的单词：在 Sigil 运行期间暂时忽略该单词。打开新书时，忽略列表也会一并清除。
    • 清除忽略的单词：清除暂时忽略的单词列表。
  • Reformat HTML:|→HTML 重新格式化：←|
    • 修复并美化所有 HTML 文件：修复所有 HTML 文件中的语法错误并美化格式。
    • 修复所有 HTML 文件：修复所有 HTML 文件中的语法错误。
  • Epub3 Tools (EPUB3 Only):|→EPUB3 工具（仅限 EPUB3）：←|
    • 更新清单属性：添加或更新必需的清单属性。
    • 为 EPUB2 阅读器生成 NCX/Guide：用 NAV 文件中的目录条目填充 NCX 文件（EPUB3 无需 NCX，故不会自动更新，可用此工具手动更新）。同时用 NAV 文件中的 Landmarks 条目填充 Guide。
    • 移除 NCX 和 Guide：移除 NCX 和 Guide。这两者在 EPUB3 中并非必需，但有时为兼容 EPUB2 阅读系统而保留。
  • EPUB格式良好性检查：简单的验证工具，用于检查 EPUB 是否良好。
  • 使用 W3C 验证样式表：通过 W3C 网络服务检查 CSS 文件是否有效。
  • 报告：显示 HTML 文件、图片、CSS 样式等详细信息。
  • 剪贴板编辑器：创建并编辑文本和样式片段，粘贴到文档中。
  • 搜索模板：创建、编辑并运行已保存的查找与替换搜索。
  • 删除未使用的媒体文件：从书中移除未被使用的图片、视频和音频文件。
  • 删除未使用的样式表选择器：从 CSS 文件中移除未被引用的选择器。

  • 下一个文件：打开书籍浏览器中所选文件下方的文件。

工具栏

工具栏是一排排按钮，为常用命令提供快捷方式。默认位于窗口顶部；如需调整，可按住并拖动按钮组，使其沿窗口左侧、右侧或底部排列，也可分离为浮动面板。

下图是一个示例：工具栏按钮沿窗口四边排列，另有若干按钮和剪贴板窗口以分离状态浮动：

要移动工具栏，请按住每组按钮左侧的小条，拖动到目标位置。

右键点击工具栏可快速选择要显示哪些按钮或窗口，也可使用 视图=>工具栏 菜单。

将鼠标悬停在按钮上，可查看该按钮功能的工具说明。

剪贴板

有两个剪贴板项：剪贴板和剪贴板2。会为不在编组中的前 60 个剪贴板创建按钮。第一个剪贴板包含前 30 个剪贴，第二个剪贴板包含后 30 个剪贴。要创建、编辑和管理剪贴板，请到 工具=>剪贴板编辑器。

文本方向、剪贴板和剪贴板2 默认不可见。请通过 视图=>工具栏隐藏/显示这些按钮组。

上下文菜单

右键点击文本、标签、窗口、选项卡、标题、文本框等对象时会弹出上下文菜单，方便快速执行各种操作。各菜单项将在相关章节中介绍。

拿不准的时候，右键点击某处看看是否有其他可用操作！

缩放

主窗口右下角有缩放控件，可分别缩小或放大代码视图和预览窗口中的文本与图片。先点击要缩放的窗口，再点击 + 或 − 图标调整缩放级别。百分比显示当前缩放级别。（注意：仅当预览窗口处于聚焦状态时，更改预览缩放级别才会生效。）

状态栏

主窗口左下角偶尔会在操作完成时显示状态信息，例如“EPUB 已保存”或“目录已编辑”。

主窗口右下角附近（缩放滑块之前）显示当前打开文件的信息，例如代码视图中的行号和列号。
