搜索模板

—已保存的查找与替换搜索模板—

如果你有一些经常运行的查找与替换搜索——或者偶尔运行但不想每次重新创建的复杂搜索——可以把它们保存在“搜索模板”对话框中。保存后，你可以使用该对话框来编辑和运行这些搜索。

要打开“搜索模板”对话框，请选择菜单项 工具=>搜索模板、其键盘快捷键，或工具栏按钮。

上下文菜单命令

创建和编辑搜索模板的大多数操作都通过右键上下文菜单完成：

选中一个或多个历史搜索条目，然后右键单击所选内容，会显示以下选项：

  • 添加条目：在你单击的条目下方添加一个新的空白搜索。
  • 添加组：在你单击的条目下方添加一个新组。
  • 编辑：编辑或重命名该条目（与双击相同）。
  • 剪切：删除一个或多个条目，之后可以粘贴。
  • 复制：复制一个或多个条目，之后可以粘贴。
  • 粘贴：粘贴任何已剪切/复制的条目。
  • 删除：删除选中的条目或组。
  • 导入：从文件中读取已导出的条目列表并加入列表。
  • 重新加载：将列表恢复到最后一次保存的状态。
  • 导出：把选中的条目保存到文件中，用于共享或备份。
  • 导出所有：把所有条目保存到文件中。
  • 全部折叠：折叠所有组的显示。
  • 全部展开：展开所有组的显示。
  • 填充控制项：把第一个 控制项 值复制到通过按下 Shift 键单击选中（高亮显示）的所有其他条目。也就是说，如果你想让已保存搜索组中的多个条目使用相同的 控制项，先为第一个条目输入 控制项，用 Shift 单击选中（高亮显示）其余应使用相同 控制项 的条目，然后选择 填充控制项。（需要 Sigil 1.6.0 或更高版本。）

选择 导入…… 可以从 csv 文件、之前保存的 Sigil ini 文件或简单的文本文件中读入新的搜索组。

要移动搜索条目或组，请使用方向键或拖放。

要创建一个搜索组，请先创建组，然后把搜索条目移动到该组中。

运行搜索

“搜索模板”对话框既可以管理搜索，也可以运行搜索。所有查找与替换操作按钮都可以在该对话框中使用，因此无需打开查找与替换窗口即可运行已保存的搜索。

使用控制项——Sigil 1.6.0 新增

控制项 列允许你设置搜索模式、搜索方向、各种搜索选项以及搜索目标（要搜索的文件）。

控制项由双字符代码表示，可以按任意顺序排列，用逗号或空格分隔：

  • NL——模式：正常
  • RX——模式：正则表达式
  • CS——模式：区分大小写
  • UP——方向：向前
  • DN——方向：向后
  • CF——目标：当前文件
  • AH——目标：所有 HTML 文件
  • SH——目标：选中的 HTML 文件
  • TH——目标：标签页中的 HTML 文件
  • AC——目标：所有 CSS 文件
  • SC——目标：选中的 CSS 文件
  • TC——目标：标签页中的 CSS 文件
  • OP——目标：OPF 文件
  • NX——目标：NCX 文件
  • SV——目标：选中的 SVG 文件
  • SJ——目标：选中的 javascript 文件
  • SX——目标：选中的 Misc XML 文件
  • DA——正则选项：覆盖全部
  • MM——正则选项：懒惰匹配
  • AT——正则选项：自动转义
  • UN——正则选项：Unicode 属性
  • WR——选项：循环
  • TO——选项：文本

要编辑控制项，双击搜索条目所在行的 控制项 列，会显示一个类似查找与替换的界面，用于设置 模式、选项、方向和 目标。界面提供了工具提示，便于快速查看现有的控制项设置。

如果 控制项 字段留空，将使用当前查找与替换窗口中的搜索设置。如有疑问，请打开查找与替换窗口查看你最后设置的模式和选项，因为运行任何已保存的搜索时都会使用这些设置。

要运行搜索，选中一个条目并单击右侧的操作按钮：查找、替换、替换/查找、全部替换、计算全部匹配。状态消息会显示在“搜索模板”对话框的左下角；如果你打开了查找与替换窗口，状态消息也会显示在其右下角。

所有已保存的搜索都使用 控制项 列中设置的模式、选项、方向和目标来运行。

要只在当前文件中运行搜索（无论模式如何设置），请在单击操作按钮时按住Ctrl键（Mac 上：Cmd键）。

一次运行多个搜索

只需单击一次按钮即可运行多个搜索，方法是：

  1. 选择组名而不是单个条目，
    或者
  2. 按住Ctrl键（Mac 上：Cmd键）逐个单击多个单独条目，以选中多个非编组条目。

选中后，单击全部替换，组中或所选内容中的每个搜索会依次逐个运行。在组中运行多个搜索时，如果某个搜索的 控制项 值为空，它会继承该搜索分组中前一个搜索的值。因此，只需为任何搜索分组的第一个搜索设置 控制项 即可。

保存

完成搜索的创建和编辑后，请务必单击保存。

要不保存条目直接退出，请使用关闭按钮或Esc键关闭窗口，然后在提示时确认不保存。你也可以使用上下文菜单 重新加载 从磁盘重新加载条目，这会删除当前未保存的条目。

使用 导出 上下文菜单项保存搜索的副本，以便与他人共享（对方可以使用 导入 把它们添加到自己的 Sigil 中）。

如果你保存了搜索，且正在运行多个 Sigil 实例，其他 Sigil 实例会自动重新加载新保存的搜索，以保持所有实例同步。

计数报告（Sigil 1.9.10 新增）

此功能可针对用户选定的任意已保存搜索组生成报告，统计组内每个搜索的所有匹配数量。用户借此可以统计任何能用正则表达式定义的功能或标签（例如列表、表格、图像）的使用次数，创建自定义报表。

弹出式上下文菜单允许用户将计数报告导出为 CSV 文件，以便在电子表格中进一步处理。

过滤器

使用过滤器文本框可以限制显示的条目列表，便于找到想要的搜索。

加载搜索

如果你更喜欢在查找与替换窗口中运行搜索，请在“搜索模板”对话框中选中该搜索，然后单击加载搜索。搜索会被加载到查找与替换窗口中。你也可以直接在查找与替换文本框中右键单击，从上下文菜单中选择一个已保存的搜索条目（详见下文）。

加载搜索后并不会运行——它只是填充查找与替换窗口各字段的一种方式。

如果你是从“搜索模板”对话框运行搜索，则不需要使用加载搜索按钮。

仅用键盘也可以加载搜索：使用快捷键打开“搜索模板”，在过滤框中输入搜索名称并按回车（如果想关闭窗口，接着按 Esc）。

从查找与替换框使用已保存的搜索

你可以直接在查找与替换窗口中访问已保存的搜索（无需打开“搜索模板”对话框）：在 查找 或 替换 文本框中右键单击，调出上下文菜单即可。

已保存的搜索会显示在上下文菜单的顶部。选择其中一项即可将其加载到查找与替换窗口中。

如果你在查找与替换窗口中想保存搜索，供下次使用，请在 查找 或 替换 文本框中右键单击调出上下文菜单，然后选择 保存搜索。
