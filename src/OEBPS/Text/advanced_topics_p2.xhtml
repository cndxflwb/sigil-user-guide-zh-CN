高级主题：Python 函数替换

配合 Python 函数替换使用正则搜索

常规的正则表达式查找与替换功能已经非常强大，足以应付用户所需的绝大多数情形。话虽如此，有些情况下仍需要更进一步的能力，例如：

  1. 统计匹配次数，并将该计数用作替换内容的一部分

  2. 让替换内容根据查找正则表达式所捕获的内容而动态变化

  3. 让某次替换以某种方式依赖于先前的替换结果

  4. 根据捕获的上下文对替换内容进行某种“加工处理”

  5. 等等……

对于上述许多情况，Sigil 已有 Python 插件可以提供帮助，但自行创建 Sigil Python 插件需要具备一定的 Python 技能，并且要花时间理解插件 API，还要编写和测试你的插件。

对于较简单的情况，配合 Python 函数替换的正则搜索会是一个实用工具，而且开发和部署起来更快。此外，Python 替换函数还可以轻松地分享给他人——即使是不懂 Python 编程的用户也能使用——因此它对每个人来说都是有用的工具。

创建你自己的 Python 函数替换确实需要进阶的正则表达式查找与替换知识，还需要具备一定的 Python 编程能力。

下面这个 Python 代码块展示了一个什么都不做的空 Python 函数替换函数（即返回与匹配内容完全相同的东西）：

 def replace (match, number, file_name, metadata, data) : if match: return match.group(0)
The parameters passed to the replace function are important to understand:|→需要理解传递给 replace 函数的各个参数：←| 
 match: the current python match object|→当前的 Python 匹配对象←| number: number starts at 1 and is incremented after each match|→编号从 1 开始，每匹配一次递增 1←| (only when using replace all)|→（仅在使用“全部替换”时生效）←| file_name: the book path from the ebook's root to this file|→从电子书根目录到该文件的书籍内路径←| data: a python dict object used to store any data across matches|→一个 Python dict 对象，用于在多次匹配之间存储任意数据←|

为了更贴切地说明如何在自己的 Python 函数替换例程中使用这些参数，下面给出一个递增 id 的 Python 函数版本，它只会统计并修改每个文件中找到的第一个 h1 标签。

查找内容为：<h1[^>]*>。

模式为：正则表达式。

目标为：所有 HTML 文件或选定的 HTML 文件（取决于你希望函数只作用于实际章节还是所有 html 文件）。

以下是该 Python 代码的副本，方便复制粘贴使用：

 # add_ids_to_first_h1 def replace(match, number, file_name, metadata, data): # Find: <h1[^>]*> if number == 1: data["old_file_name"] = "" data["mycount"] = 1 old_file_name = data["old_file_name"] mycnt = data["mycount"] result = match.group(0) replace_debug_log("filename: " + file_name + '\n') replace_debug_log("old file name: " + old_file_name + '\n') replace_debug_log("mycount: " + str(mycnt) +'\n') if match: if file_name != old_file_name: result = match.group(0)[0:-1] + ' id="heading_' + str(mycnt) + '">' data["old_file_name"] = file_name mycnt = mycnt + 1 data["mycount"] = mycnt return result

这段 “add_ids_to_first_h1” 代码展示了如何利用 number 参数来判断何时初始化你自己的数据变量，还展示了如何利用传入的 data 字典参数来保存和读取跨多次调用持续存在的状态信息，同时也展示了如何利用 file_name 参数来检测何时进入了一个新文件。

这个 Python 函数还展示了如何使用 replace_debug_log 函数从你的函数生成调试输出，该函数会把 utf-8 字符串输出追加写入你所设置并控制的一个环境变量所指向的文件，这个环境变量名为 SIGIL_FUNCTION_REPLACE_LOGFILE。

设置此环境变量时，其值应为一个文本文件的完整路径（包括文件名），来自你的函数调试输出将被追加写入该文件。

 def replace_debug_log(message): logfile = os.environ.get('SIGIL_FUNCTION_REPLACE_LOGFILE', None); if logfile: with open(logfile, "a", encoding="utf-8") as f: f.write(message)

Sigil 内置了一个带语法高亮的 Python 函数替换编辑器，只需点击查找与替换窗口左侧的 图标即可轻松打开它。

如上图所示，使用 Python 函数替换时，替换框要以转义字符串 \F<> 开头，并在 < 与 > 字符之间放入你所选 Python 函数替换例程的准确名称（区分大小写）。本例中最终得到的内容是：\F<add_ids_to_first_h1>。

在 Python 函数编辑器内部，你可以选择所需的替换例程，然后使用使用按钮自动填充查找与替换窗口的替换框。

如果所指定的 Python 函数替换例程存在，该编辑器会加载其代码；也可以使用下拉菜单从若干内置 Python 函数替换例程中选择：

也可以使用新建按钮来创建你自己的 Python 替换函数。Python 函数编辑器会自动保存。当你准备好使用所创建的函数时，可以选择使用按钮来填充常规查找与替换窗口中的替换框。

调用查找与替换函数的方式与执行任何其他正则表达式查找与替换完全一样。先填写查找框，把替换框设置为指向你的函数替换例程，将搜索模式指定为正则表达式，选择目标为所有 HTML 文件，然后打开第一个文件并将光标置于顶部，再使用全部替换按钮。对于这个特定的示例电子书，该函数添加了 heading_1、heading_2 等 id，且只统计每个 xhtml 文件中的第一个 h1。

以此类推，为每个文件中的第一个 h1 标签依次处理。

对于懂正则表达式但不懂 Python 的用户，下面这些预置的 Python 函数替换例程也许会让你感兴趣。

replace_uppercase
将匹配到的文本转为大写。如果正则表达式包含分组，则只更改分组内的文本；否则更改整个匹配到的文本。
replace_lowercase
将匹配到的文本转为小写。如果正则表达式包含分组，则只更改分组内的文本；否则更改整个匹配到的文本。
replace_capitalize
将匹配到的文本首字母大写。如果正则表达式包含分组，则只更改分组内的文本；否则更改整个匹配到的文本。
replace_titlecase
将匹配到的文本转为标题格式（各单词首字母大写）。如果正则表达式包含分组，则只更改分组内的文本；否则更改整个匹配到的文本。
replace_swapcase
反转匹配到的文本的大小写。如果正则表达式包含分组，则只更改分组内的文本；否则更改整个匹配到的文本。
replace_uppercase_ignore_tags
将匹配到的文本转为大写，忽略标签定义内的文本。
replace_lowercase_ignore_tags
将匹配到的文本转为小写，忽略标签定义内的文本。
replace_capitalize_ignore_tags
将匹配到的文本首字母大写，忽略标签定义内的文本。
replace_titlecase_ignore_tags
将匹配到的文本转为标题格式（各单词首字母大写），忽略标签定义内的文本。
replace_swapcase_ignore_tags
反转匹配到的文本的大小写，忽略标签定义内的文本。

这些内置函数的完整源代码请参阅 Sigil/src/Resource_files/python3lib/functionrep.py。所有 Python 替换函数以及你自行添加的函数，都存放在 Sigil 首选项文件夹中一个名为 replace_functions.json 的文件里。
