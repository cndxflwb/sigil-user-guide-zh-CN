样式

— 使用样式表 —

编辑 EPUB 的重点就是样式。Sigil 提供了非常易用而又强大的工具，帮助你处理样式表。

样式可以直接插入单个 HTML 文件，但通常的做法是定义包含样式的外部样式表，再将其链接到你的 HTML 文件。

创建样式表

要创建样式表，请转到主菜单栏并选择 文件=>添加=>空白样式表，或者在书籍浏览器中右键单击 Styles（样式）文件夹并选择 添加空白样式表。创建后，输入你想使用的样式定义。

你也可以使用 文件=>添加=>已有文件 添加现有的样式表文件，例如你自己创建的模板，或者右键单击 Styles（样式）文件夹并选择 添加已有文件。

不要在样式表文件名中包含空格。

链接样式表

右键单击书籍浏览器中的 HTML 文件并选择 链接样式表，即可将样式表链接到 HTML 文件。然后选择要链接或取消链接的样式表。

浏览样式

在代码视图中工作时，有时你会想要查看某个标签的样式定义。要从 HTML 文件快速跳转到所涉及的特定样式定义：

  • 按住Ctrl键并单击 HTML 标签。（在 Mac 上按住Cmd键。）
  • 将光标置于某个标签内部，然后选择菜单项 搜索=>跳转到链接或样式，或使用其键盘快捷键。
  • 右键单击该标签选择器，然后从上下文菜单中选择 跳转到链接或样式。

你会立即跳转到当前 HTML 标签所用样式的确切位置（如果存在的话）。

要返回到 HTML 文件中的原位置，请单击 返回 按钮，或选择菜单项 搜索=>返回，或使用其键盘快捷键。

格式化样式表

要整理并格式化样式表，请在代码视图窗口中打开该样式表，然后在样式表窗口内右键单击并选择：

  • 重排 CSS=>样式多行显示
    或
  • 重排 CSS=>样式单行显示

删除未使用的样式

要自动删除样式表中所有未使用的选择器，请选择菜单项 工具=>删除未使用的样式表选择器。Sigil 会列出样式表中在 HTML 文件里没有任何引用的样式。确认删除已标记的样式，或取消。

尽管 Sigil 会进行多项检查以确保样式确实未被使用，但复杂的 CSS 声明可能错误地引用选择器，因此应仔细检查这些样式。

要在 CSS 样式表中查看某个样式，请双击该样式。

你还可以使用 Sigil 的报告工具查看“使用的类”和“CSS 选择器”报告，它们提供了相关使用中样式的有用信息。要查看这些报告，请转到菜单项 工具=>报告。更多信息请参阅报告一章。
