检查拼写错误

Sigil 可以使用标准词典以及你自己创建的词典来检查书中的拼写。

检查书中拼写之前，请先通过 首选项=>拼写检查词典 配置词典。需要选择一个主词典（英语、法语等）。可以直接使用“default”个人用户词典保存想记住的单词，也可以为每本书创建新的用户词典。

拼写检查

要检查书中的拼写，可以点击拼写检查按钮 ，或使用菜单项 工具=>拼写检查=>拼写检查：

这会打开一个对话框，显示 Sigil 识别出的所有拼写错误的单词。

选中一个单词后，Sigil 会在书中定位该单词首次出现的位置，并在代码视图中显示。这有助于查看单词的上下文；如果不熟悉代码视图，可能会感到困惑，但这是确保 Sigil 准确找到拼写错误单词的必要步骤。

选中一个单词之后，你有以下几种选择：

  • 使用 忽略 可跳过将此单词标记为拼写错误，直到你切换到一本新书或重启 Sigil 为止。重启后 Sigil 不会记住要忽略这个单词。
  • 点击 添加到词典 按钮，可将该单词添加到按钮下方列表中所选的词典。如果未在首选项中创建额外的用户词典，列表中一开始只有“default”词典。
  • 使用 将所选单词更改为，可把书中该单词的所有出现都更改为下方输入的单词。下拉列表提供建议的替代词，也可以自行输入。

你还可以使用以下其他选项：

  • 在拼写检查窗口打开期间编辑了书，可使用刷新。如果只是忽略、添加或更改单词，则无需刷新。
  • 显示所有单词：勾选此项可显示书中所有不重复的单词，而不只是拼写错误的单词。
  • 区域感知排序：启用此项后，单词通常会按 AaBbCc 排序，而不是按 ABCabc 排序。

你可能还会注意到，在代码视图中，拼写错误的单词可以选择显示下划线。这是用 Sigil 检查拼写的另一种方式。
