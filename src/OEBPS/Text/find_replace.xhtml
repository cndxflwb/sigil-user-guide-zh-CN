查找与替换

—在代码视图中搜索—

在 Sigil 中，查找并更新文本是最常见的操作之一，可用于查找单词、删除或替换多余文本，或更改格式。需要大量修改文本时，几乎必然要用到查找与替换（及相关的搜索模板功能），借助它可在所有文件中快速批量修改。

参见正则表达式教程，了解高级搜索的相关信息。

要打开查找与替换对话框，可选择菜单项 搜索=>查找与替换 、对应快捷键或工具栏按钮。

打开后，查找与替换对话框始终位于编辑窗口底部，便于使用。高级正则表达式选项另有独立菜单。

所有查找与替换操作都有键盘快捷键，例如Ctrl+F查找、Ctrl+G再次查找（Mac 上使用Cmd代替Ctrl）。快捷键列表请参见 搜索 菜单。

操作按钮

右侧的按钮用于执行搜索命令：查找、重新开始、替换、替换/查找、全部替换和计算全部匹配。

查找（）

查找搜索词的下一个出现位置，并在代码视图中高亮显示。

要查找文本：

  • 在 查找 框中输入要查找的文本。
  • 单击，在代码视图窗口中搜索并高亮显示下一个匹配项。

仅执行查找时，替换 框中的内容不会生效。

先在代码视图中选中文本，再按Ctrl+F（Mac 上：Cmd+F）打开查找与替换窗口，Sigil 会自动将选中的文本放入 查找 框。

执行搜索后，查找 框或 替换 框中输入的文本会自动存入历史列表，供日后使用。单击输入框右侧的下拉箭头，即可打开搜索历史下拉菜单。

状态消息显示在右下角。

重新开始（）

将多文件查找与替换搜索重置到第一个文件的开头，下一次查找从该位置开始。

替换（）

替换 查找 匹配到的一处文本。

要替换文本：

  • 在 查找 框中输入要查找的文本。
  • 在 替换 框中输入要替换成的文本。
  • 单击，搜索并高亮显示下一个匹配项。
  • 单击执行替换。

要撤销更改，可使用Ctrl+Z（Mac 上：Cmd+Z）或 撤销 按钮，也可在代码视图窗口中右键单击，选择 撤销 恢复原文。跨文件替换时，若下一个匹配项位于其他文件，需先切换回包含已替换文本的标签页，再执行撤销。

替换/查找（）

替换下一个匹配项，然后自动查找并高亮显示其后的匹配项。

首次执行 替换/查找 时，第一个匹配项仅高亮显示，不会替换。之后执行 替换/查找 将替换已高亮的匹配文本，并自动查找下一个匹配项。

要替换文本然后自动查找下一个匹配项：

  • 在 查找 框中输入要查找的文本。
  • 在 替换 框中输入要替换成的文本。
  • 单击，搜索并高亮显示第一个匹配项。
  • 单击替换匹配项，然后自动查找并高亮显示下一个匹配项。

如果没有选中文本，可放心使用 替换/查找 代替 查找，因为在高亮显示匹配项之前，两者的行为完全一致。

全部替换（）

按当前设置，将所有匹配搜索词的文本替换为替换词，自动一次性完成。

全部替换 无法撤销——请先保存，或创建检查点

要执行全部替换：

  • 在 查找 框中输入要查找的文本。
  • 在 替换 框中输入要替换成的文本。
  • 单击，一次性替换所有匹配项。

全部替换 始终从文件开头开始替换。

为避免意外，请先用 计算全部匹配 测试查找与替换字符串，确认匹配数量在预期范围内；也可先用简单的 替换 试几次。

从 Sigil-1.9.10 开始，可用 模拟运行替换全部 工具，在实际替换前先在表格中安全预览所有潜在替换结果。

执行 全部替换 前，请先保存书籍或创建检查点，事后再检查是否有问题。

执行 全部替换 前，请确认模式设为 当前文件 还是 所有 HTML 文件。

计算全部匹配（）

统计 查找 文本框中的搜索词在所选文件中出现的次数，结果显示在查找与替换窗口右下角。计算全部匹配 遵循所有 模式 设置（包括 向上/向下）及 循环 选项。

要统计所选文件中的所有匹配项：

  • 在 查找 框中输入要查找的文本。
  • 单击。

执行 全部替换 前，建议先用 全部计数 确认替换数量符合预期。全部替换 之后也应再运行一次，以防替换操作产生了新的匹配项。也可改用新的 模拟运行替换全部 工具（见下文）。

模拟运行替换全部（SHIFT + ）（Sigil 1.9.10 新增）

编写查找与替换的正则表达式时，往往难以判断查找字符串能否准确命中所需内容、排除无关内容。此表格以试运行方式，在上下文中显示当前查找与替换内容的匹配结果，不会实际更改任何内容。匹配项“之前”和“之后”显示的上下文长度（按字符计）可自行调节。按住 Shift 单击 计算全部匹配 按钮即可启动此工具。

模拟运行替换全部 可安全试验搜索词，查看哪些最为有效。双击表格中任意一行，代码视图 会显示该匹配项的确切上下文，便于进一步检查或编辑。借此可确认“查找并全部替换”操作完全符合预期。若底层文本的更改影响了表格内容，可随时单击 刷新 按钮重建表格。

要创建模拟运行替换全部表格：

  • 在 查找 框中输入要查找的文本。
  • 在 替换 框中输入要替换成的文本。
  • 单击SHIFT + 。

过滤替换（SHIFT + ）（Sigil 1.9.10 新增）

此工具可帮助更有效地使用查找与全部替换：在上下文中列出所有匹配项，并在相同上下文中显示每处替换结果。匹配项“之前”和“之后”显示的上下文长度（按字符计）可自行调节。

若发现不需要的匹配项（即不希望执行的替换），可在表格中选中该行，取消勾选，将改行从替换队列中移除。移除所有多余匹配项后，单击 应用更改 按钮，即只执行表格中剩余的更改。

过滤替换 可降低误替换的风险，使 全部替换 更安全。

要创建过滤替换表格：

  • 在 查找 框中输入要查找的文本。
  • 在 替换 框中输入要替换成的文本。
  • 单击SHIFT + 。

搜索模式

Sigil 提供三个下拉菜单，包含不同的搜索模式，便于更精细地控制搜索。

搜索内容

  • 正常：按 查找 框中输入的内容搜索，但忽略大小写，例如“A”和“a”视为同一个字母。

  • 区分大小写：按 查找 框中输入的内容搜索，例如“A”和“a”视为不同的字母。

  • 正则表达式：正则是“正则表达式”的缩写。正则模式可按模式搜索，而不局限于确切的单词或字符。正则功能强大，也是用 Sigil 处理电子书的主要优势之一。例如搜索“Page [0-9]+”，可查找“Page ”后跟一个或多个数字的内容。

    参见正则表达式一章，了解使用正则的更多细节。

在哪里搜索

  • 当前文件：仅在代码视图当前标签页文件中搜索。支持所有文件类型，包括 HTML、XHTML、CSS、OPF、NCX。

    若搜索到达文件末尾且已开启 循环，会自动循环到文件另一端继续搜索。此时屏幕会闪现箭头图标，提示搜索已循环。

    要临时只在当前文件中搜索，可在单击操作按钮时按住Ctrl键（Mac 上：Cmd键）。模式设为 所有 HTML 文件 时，用此法搜索单个样式表很方便。

  • 所有 HTML 文件：在每个 HTML/XHTML 文件中搜索——但不在其他文件类型（如 CSS、OPF 或 NCX）中搜索。

    当搜索到达文件的末尾或开头时，会自动移动到下一个或上一个文件（按书籍浏览器中列出的顺序）。搜索多个文件时，循环不适用。

  • 选中的 HTML 文件：仅搜索在书籍浏览器中选中的 HTML 文件。

    当搜索到达文件的末尾或开头时，会自动移动到下一个或上一个选中的文件（按书籍浏览器中列出的顺序）。搜索多个文件时，循环不适用。

  • 标签页中的 HTML 文件：仅搜索在标签管理器中以标签页形式打开的 HTML 文件。

    当搜索到达文件的末尾或开头时，会自动移动到下一个或上一个选中的文件（按标签管理器中打开的顺序）。搜索多个文件时，循环不适用。

  • 所有 CSS 文件：在每个 CSS 文件中搜索——但不在其他文件类型（如 HTML、OPF 或 NCX）中搜索。

    当搜索到达文件的末尾或开头时，会自动移动到下一个或上一个文件（按书籍浏览器中列出的顺序）。搜索多个文件时，循环不适用。

  • 选中的 CSS 文件：仅搜索在书籍浏览器中选中的 CSS 文件。

    当搜索到达文件的末尾或开头时，会自动移动到下一个或上一个选中的文件（按书籍浏览器中列出的顺序）。搜索多个文件时，循环不适用。

  • 标签页中的 CSS 文件：仅搜索在标签管理器中以标签页形式打开的 CSS 文件。

    当搜索到达文件的末尾或开头时，会自动移动到下一个或上一个选中的文件（按标签管理器中打开的顺序）。搜索多个文件时，循环不适用。

  • OPF File:仅搜索 OPF 文件。

    在 OPF 文件中使用 替换 须格外小心，因为它实际上是 EPUB 的核心，几乎影响所有功能。请务必先创建检查点或保存文件。

  • NCX 文件：仅搜索 EPUB2 和 EPUB3 中的 NCX 文件（如果存在）

  • 标记的文本：这是特殊选项，仅在标记文本后显示。要将搜索范围限定在某段文本内，请先在代码视图中选中部分文本，再选择菜单项 搜索=>标记选中的文本，或使用右键菜单中的 标记选中的文本。

    未选中文本时再次执行该菜单项，即可取消文本标记。使用撤销、输入任意文本或切换标签页，也会取消标记。仅使用 替换 或 全部替换 时，标记保持有效，但标记内容会随替换更新。

  • 选中的 SVG 文件：仅搜索当前在书籍浏览器中选中的 SVG 图像文件。

  • 选中的 javascript 文件：仅搜索当前在书籍浏览器中选中的 javascript 文件。

  • Selected Misc XML files:选中的 Misc XML 文件：仅搜索当前在书籍浏览器 Misc 文件夹内选中的 XML 文件。目前包括下列媒体类型的纯 XML 文件：
    • application/ttml+xml
    • application/smil+xml
    • application/smil
    • application/pls+xml
    • application/oebps-page-map+xml
    • application/vnd.adobe-page-map+xml
    • application/adobe-page-template+xml
    • application/vnd.adobe-page-template+xml
    • application/xml
    • text/xml

搜索方向

  • 向前：从当前文档位置向上搜索，查找搜索词的上一个出现位置。

  • 向后：从当前文档位置向下搜索，查找搜索词的下一个出现位置。

搜索选项

选项 菜单提供正则模式下的实用开关，另有一个复选框，用于控制当前文件的 循环 开启或关闭。

正则表达式搜索选项包括：

  • 覆盖全部：此正则选项会在所有正则搜索前添加 (?s)，使 .* 可匹配任意字符（包括换行）。

  • 懒惰匹配：此正则选项会在所有正则搜索前添加 (?U)，使模式匹配最短结果而非最长结果。

  • 自动转义：使用Ctrl+F（Mac 上：Cmd+F）将选中文本复制到 查找 框时，会把空格转换为 \s 并转义某些字符，使其适合正则搜索。

  • Unicode 属性：启用后，所有正则字符占位符将按其对应的 Unicode 属性处理。标志说明参见正则表达式文档：(*UCP)

其他通用搜索选项

  • 循环：在当前文件模式下启用时，如果搜索到达文件末尾，会自动循环到文件开头继续搜索（向上搜索时则相反）。禁用时，搜索会在文件末尾（向上搜索时是开头）停止。

    使用多文件模式搜索时，搜索到达最后一个文件（按书籍浏览器中的顺序）后，需单击重新开始按钮，否则搜索将停止。搜索多个文件时，循环不适用。

  • 文本：在任何模式下启用时，如果搜索的是 XHTML 文件，只会匹配 <XHTML 标签> 之外的文本。搜索非 XHTML 文件时该选项无效。

    若要查找替换的单词恰好是有效的 XHTML 属性、属性值或标签名，又不想替换这些标签内容，此选项会很有用。

上下文菜单

右键单击 查找 框或 替换 框会弹出包含以下选项的上下文菜单：

  • 搜索模板：上下文菜单顶部列出已保存的搜索模板（详见搜索模板一章）。选择某一项即可加载到查找与替换窗口。

  • 保存搜索：把当前的查找与替换搜索保存到搜索模板中。

  • 分词选中内容：把空格转换为 \s 并转义某些字符。

  • 清除查找替换历史记录：清除所有近期的历史记录及此前使用过的查找与替换值。

在查找与替换中处理特殊字符

某些字符在多数键盘上难以直接输入，因此查找与替换现支持十六进制转义代码，可通过 4 位十六进制数字编码指定字符。

格式为 \x{hhhh}，其中每个“h”代表一个十六进制值——0 到 9 和 A 到 F。

例如：要替换字符编码为 160 的不换行空格（nbsp），可用 \x{00A0} 表示该字符。
