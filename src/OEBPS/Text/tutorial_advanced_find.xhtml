高级查找与替换 – 正则表达式

Sigil 中查找与替换的真正威力来自它对正则表达式（也称 regex）的支持。正则表达式本质上是用模式而非纯文本进行搜索，使文本匹配更加灵活。

你可以在查找与替换中将搜索模式从“正常”改为“正则表达式”来使用正则表达式。

正则表达式参考：正则表达式是 Sigil 中非常重要的工具，但本教程只能作非常简要的介绍。正则表达式的参考列表请参见下一章。

例如，搜索“Page 123”这样非常具体的文本来替换或删除，远不如搜索包含“Page”后跟一个数字的文本有用——这正是正则表达式能做到的。

你可以在“查找”或“替换”框中用特殊的正则代码代替实际文本。因此上面的例子可以搜索“Page \d+”而不是“Page 123”，因为“\d+”是正则代码，表示任意数字（“\d”）至少重复一次（“+”）。

使用正则表达式替换文本

更有用的是，你还可以用正则表达式辅助替换文本。在上面的例子中，你可能想保留页码但替换掉“Page”这个词。你可以这样使用：

  • 查找： 
    Page (\d+)
  • 替换： 
    This is page \1

这会把所有“Page”后跟数字的文本替换为“This is page”后跟相同的数字：

  • 替换前： 
    Page 418
  • 替换后： 
    This is page 418

关于这个替换，首先要注意的是“查找”框中使用了正则代码 (\d+)。\d+ 代码让搜索像上面那样查找数字，而给代码加上括号则让搜索记住匹配到的数字——即记住括号内匹配到的任何内容。另一点要注意的是“替换”框中使用了正则代码 \1，它的作用是在找到 \1 的地方，用“查找”中记住的字符来替换。

使用正则表达式更改格式

再举一个正则表达式的例子，这里演示如何把某些文本的格式改为章节标题。

假设你导入了一个 HTML 文件，其中包含许多章节标题，但没有一个使用 h1 标题元素标记。实际上，它们都标记为如下所示的段落：

<p>CHAPTER 7</p>

假设每一个这样的段落都是章节标题，你可以使用这个正则表达式：

  • 查找 
    <p>\sCHAPTER\s(\d+)\s</p>
  • 替换： 
    <h1>Chapter \1</h1>

这有不少内容需要消化，但如果你仔细看，会发现它与上面的页码例子非常相似，都是记住章节名中的数字并在替换中使用它们。

最有趣的是“查找”部分。它可以这样拆解：

  • <p> 查找起始段落标签。
  • \s – 匹配任意空白（空格、制表符等）的正则代码。
  • CHAPTER – 匹配单词 CHAPTER（正则表达式默认区分大小写）。
  • \s – 匹配任意空白的正则代码。
  • (\d+) – 匹配连续任意多个数字并记住它们的正则代码。
  • \s – 匹配任意空白的正则代码。
  • </p> – 查找结束段落标签。

你也可以用空格代替 \s，但 \s 更灵活，因为它能匹配任意数量的空格和制表符。

因此，该搜索的结果可能是：

  • 替换前： 
    <p>  CHAPTER    14</p>
  • 替换后： 
    <h1>Chapter 14<h1>

如果文件中的格式不一致，使用正则表达式会更困难——这时可能需要多轮查找与替换，甚至不得不手动逐一更新。

这只是对正则表达式非常基础的介绍，但已能展示它的可能性。使用正则表达式的诀窍在于写出正确的查找与替换字符串，而这只能通过阅读、提问和测试来获得。

有用的选项

你可能已经注意到查找与替换中的额外选项：覆盖全部、懒惰匹配、自动转义和 Unicode 属性。使用正则表达式时这些选项都很有用。如果你刚开始使用正则表达式，建议勾选除 Unicode 属性框之外的所有选项框。

下面是每个选项的用途：

  • 覆盖全部：这个正则选项会在所有正则搜索前加上 (?s)，当你想让“.*”模式跨行匹配时使用。

  • 懒惰匹配：这个正则选项会在所有正则搜索前加上 (?U)，当你想让模式匹配最短的出现而不是最长匹配时使用。

  • 自动转义：当对选中的文本使用 Ctrl+F 将文本添加到查找与替换时，此选项会把空格转换为 \s 并转义某些字符，使其适合正则表达式。

  • Unicode 属性：此选项让搜索把 \w 等搜索字符类替换为基于每个字符的 Unicode 属性。使用该选项会大大减慢查找与替换的速度，但在多种语言中使用正则字符占位符搜索时可能非常有用。
