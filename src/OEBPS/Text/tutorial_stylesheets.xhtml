本章假设你熟悉代码视图，因为查看样式细节需要用到代码视图。

什么是样式？

书中的样式用来完成诸如“把这段文字变成蓝色”“把那段文字居中”或“在这段文字上方多留一点空间”之类的事情。样式定义就是一段类似下面这样的文字：

color: blue;

它的意思是让文字的颜色变成蓝色。

不过，样式如果不应用到具体对象上就没什么用处。在 EPUB 中，样式要应用到文档中的 HTML 元素上，比如 p（段落）、h1（一级标题）、div（区块）、span（行内片段）等标签。

在 EPUB 中，样式有 3 种使用方式：

  • 样式属性：直接应用到文档中某个特定 HTML 标签上的样式。
  • 样式元素：位于一个文档内的一组样式，只有所在文档能使用。
  • 样式表：独立的 CSS 或样式表文件，可供多个 HTML 文件使用，因此是最灵活的方式。

推荐使用独立文件来应用样式。下面对每种方式的介绍会帮你理解其中的原因。

样式属性

要把样式直接应用到某个 HTML 标签上，可以在标签中使用 style 属性。例如，要把 color: blue 这个样式应用到某个段落，你需要把

<p>Hello</p>

改成：

<p style="color: blue">Hello</p>

如果你只是想改几处且很少再更新格式，这种做法完全可行。但如果你之后想把某些文字的格式从粗体改成斜体，就必须修改书中每一处设置了这种样式的地方。

样式属性很少使用，除非是由所见即所得软件生成或来自自动转换，应当尽量避免使用。

管理样式有一个更好的办法：使用样式选择器。

样式选择器

样式选择器是给特定样式命名的一种方式，之后只需引用该名称即可在文档中使用这个样式。更具体地说，样式选择器用来挑选文档中哪些元素应当使用你所定义的样式。

例如，如果你想让 EPUB 中所有段落都居中显示，可以这样定义一条样式选择器规则：

p {
    text-align: center;
}

这定义了一个样式选择器 p，它会匹配（即选中）所有段落元素 p。

只使用标签名作为选择器，适合修改所有同类标签，但你也可以选择特定的标签。

选择特定标签最常见的方式之一，是在标签和选择器中使用一个 class 名称。class 只是你自行挑选的一个名字（比如 “firstparagraph” 或 “example”）。

例如，如果你想让章节第一段的样式与其他段落略有不同，可以这样定义样式选择器（“em” 是一个字符的宽度）：

p.first {
    text-indent: 0em;
}

这定义了一个样式选择器，它会匹配（即选中）使用 class 名称 first 的段落标签。然后，你可以像下面这样给段落指定类名 first，从而让这个段落使用此样式：

<p class="first">First paragraph in a chapter</p>

这种抽象的最大好处在于：更新样式的值（比如更改缩进或其他设置）时，不必修改文本。

常见的做法是让类名体现样式的用途，而不是样式的实际效果，以防日后更改样式。例如，使用 span.placename 而不是 span.bold，以防以后想把地名改成斜体。

既然已经了解样式选择器及其在正文中的用法，接下来就需要把样式选择器放到某个地方，让它们真正生效。

在 EPUB 中，你可以把样式表存放在与正文相同的文件里（使用 style 元素），也可以存放在独立的文件中（外部样式表或 CSS 文件）。应当避免把样式存放在 HTML 文件中，但这里仍作说明，以防你在自己的文件中看到这种情况。

样式元素

如果你把样式选择器和规则存放在与正文相同的文件里，它们就只能应用于所在的那个 HTML 文件，其他 HTML 文件无法共享。

使用这些内部样式时，样式定义存放在 HTML 文件顶部的 style 元素内。如果你打开书中的某个文件并切换到代码视图，会看到文件顶部在两个 head 元素之间有一些文字。这部分存放文件的相关信息，你可以放在这里的内容之一就是定义内部样式规则的 style 元素。

下面是内部样式的一个典型用法（它们放在 style 元素之内）：

<?xml version="1.0" encoding="utf-8" standalone="no"?> 
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.1//EN"
 "http://www.w3.org/TR/xhtml11/DTD/xhtml11.dtd"> 
<html > 
<head> 
<title></title> 

<style>
        h1 { text-align: center; }
        p.boldtext { font-weight: bold; }
</style> 

</head>

内部样式是把样式集中在一起并使用样式选择器的一种方式，但当 EPUB 中文件很多时就会变得有些混乱，因为每个文件都得有各自独立的样式规则。

管理样式最好使用独立的样式表文件来存放样式规则。

可以把内联样式和样式元素转换或复制到独立的 CSS 文件中。只要记得把样式表链接到 HTML 文件，并删除旧的样式属性和样式元素即可。

外部样式表——CSS 文件

如果创建一个独立文件来存放所有样式规则，这些规则就能应用到全书，也更容易找到和编辑，增删文件时更方便管理更新。这还有助于保证全书格式一致，因为所有样式都集中在一个地方。

在 Sigil 中，外部样式表存放在书籍浏览器的 Styles（样式） 文件夹中。

把 HTML 文件链接到样式表文件

要指定 HTML 文件使用哪个 CSS 文件，需要把样式表链接到 HTML 文件：

  • 在书籍浏览器中选中一个或多个 HTML 文件。
  • 右键点击所选文件。
  • 从上下文菜单中选择“链接样式表”：
  • 点击要应用到这些文件的样式表，然后选择确定。

你随时可以查看文件的 <head> 部分，确认某个 html 究竟使用了哪个样式表（如果有的话）。

链接多个样式表时会按顺序依次应用，最后一个样式表中的样式会覆盖前面样式表中的样式。

应该使用哪些样式？

为正文使用哪些样式，完全由你自己决定。

学习使用样式的最好办法，是找一本排版效果符合自己喜好的 EPUB，查看其 CSS 文件的内容，以及书中如何使用这些样式。

样式会按照它们在样式表中出现的顺序依次应用。
记住这一点很重要，因为某条样式定义出错会导致其后所有样式失效。
建议仔细检查样式表，因为有些错误要等到在电子书阅读器中查看时才会显现。
可使用菜单项 工具=>使用 W3C 校验样式表 检查错误。
