剪贴板

—保存文本与样式—

剪贴板可保存文本片段，并随时粘贴到文档中，也可在文本前后插入 HTML 样式标签。使用剪贴板编辑器创建剪贴板条目，甚至可把 CSS 样式表中的所有样式自动填充到剪贴板列表。之后通过剪贴板编辑器、剪贴板栏、剪贴板窗口、上下文菜单、键盘快捷键或主菜单栏选择和粘贴剪贴板条目。

创建与编辑剪贴板条目

要创建和编辑剪贴板条目，请先使用菜单项 工具=>剪贴板编辑器 或其键盘快捷键打开剪贴板编辑器。

上下文菜单

虽然可使用剪贴板编辑器窗口中的添加条目或添加组按钮来添加剪贴板条目和组，但完整命令需通过右键上下文菜单访问：

要使用上下文菜单，请先选中一个或多个条目，然后右键单击所选内容，会显示以下选项：

  • 添加条目：在你单击的条目下方添加一个新的空白剪贴板条目。
  • 添加组：在你单击的条目下方添加一个新组。
  • 编辑：编辑该条目。
  • 剪切：删除一个或多个条目，之后可以粘贴。
  • 复制：复制一个或多个条目，之后可以粘贴。
  • 粘贴：粘贴任何已剪切/复制的条目。
  • 删除：删除条目或组。
  • 导入：从文件中读取已导出的条目列表并加入列表。
  • 重新加载：将列表恢复到最后一次保存的状态。
  • 导出：把选中的条目保存到文件中，用于共享或备份。
  • 导出所有：把所有条目保存到文件中。
  • 自动填充：从 CSS 样式表中的样式创建剪贴板条目。
  • 全部折叠：折叠所有组的显示。
  • 全部展开：展开所有组的显示。

可使用方向键或拖放移动条目或组。

要创建剪贴板组，请先创建一个用于存放剪贴板条目的组。

保存

创建和编辑剪贴板条目完成后，请务必单击保存。

若要不保存条目直接退出，请使用关闭按钮或Esc键关闭窗口，然后在提示时确认不保存。也可使用上下文菜单 重新加载 从磁盘重新加载条目，这会删除当前未保存的条目。

使用 导出 和 导入 上下文菜单项保存剪贴板条目的副本，以便与他人共享。

若保存了剪贴板条目，且正在运行多个 Sigil 实例，其他实例会自动重新加载新保存的条目，以保持各实例同步。

过滤器

使用过滤器文本框可以限制显示的条目列表，便于找到想要的剪贴板条目。

自动填充 CSS 条目

A自动填充 上下文菜单项会扫描 CSS 样式表，为找到的每个简单选择器创建一个剪贴板条目。（关于如何使用剪贴板格式化文本，请参见下一节。）

例如，若存在选择器或样式“p.first”，自动填充 会为其创建如下剪贴板条目：

<p class="first">\1</p>

如果选择器是“*.quote”，自动填充 会为“p.quote”“div.quote”和“span.quote”分别创建条目。

所有新的 自动填充 剪贴板条目都存放在“自动填充”组中；若该组不存在，会自动创建。组创建后可重命名，也可将任何条目移动或复制到任何组。

使用剪贴板格式化文本

剪贴板可在选中文本前后粘贴文本，让文本格式化更简单。

首先在剪贴板条目文本中使用“\1”定义文本，剪贴板会将其视为正则替换命令。粘贴该条目时，“\1”将替换为选中的文本。

例如，若剪贴板条目为

<span class="name">\1</span>

而你选中的文本是

Mad Hatter

那么应用该剪贴板条目后，文本会变成

<span class="name">Mad Hatter</span>

可借此建立一套可快速应用的样式和格式库。

也可在剪贴板条目中使用其他正则命令，但复杂正则表达式可能无法生效。

在粘贴格式化剪贴板条目之前，请务必先移除任何已有格式：使用 移除格式 键盘快捷键（Windows 上为Ctrl+Space；Mac 上为Cmd+Space），或单击工具栏上的 移除标签对 按钮。（使用 移除格式 时，选中内容要包含标签；使用 移除标签对 时，把光标放在要移除的标签内部。）

粘贴剪贴板

创建好剪贴板列表后，即可使用剪贴板编辑器、剪贴板栏、剪贴板窗口、上下文菜单、键盘快捷键或主菜单栏，快速轻松地将它们粘贴到代码视图中的当前文件里。也可通过剪贴板编辑器或剪贴板，将剪贴板条目粘贴到“查找与替换”框中的“查找”或“替换”字段里。

剪贴板编辑器

要使用剪贴板编辑器粘贴剪贴板条目，请选择需要的条目（若列表很长，可用 过滤 框缩小显示的条目列表范围），然后单击粘贴按钮。若选择了多个条目或一个分组，粘贴按钮单击一次即可粘贴所有选中条目或该分组的全部条目。

若在打开剪贴板编辑器窗口前先把光标放在相应字段中，还可将剪贴板条目粘贴到“查找与替换”框的“查找”或“替换”字段里。

剪贴板

剪贴板 和 剪贴板2 是可选工具栏，会为不在分组中的前 60 个剪贴板条目（每栏 30 个）显示按钮。可通过选择菜单项 视图=>工具栏=>剪贴板 和 视图=>工具栏=>剪贴板2 来显示剪贴板：

按钮上会显示剪贴板条目的名称，因此保持名称简短会有帮助。可将它们用作自定义样式的快捷方式，甚至用作常用特殊字符的快捷方式。

使用剪贴板，可将剪贴板条目粘贴到代码视图中的当前文件，或粘贴到“查找与替换”框的“查找”或“替换”字段里。

剪贴板窗口

剪贴板窗口以可滚动列表的形式显示你所有的剪贴板条目。单击某个条目即可将其粘贴到书中。该窗口可停靠在用户界面中（此处展示停靠在书籍浏览器下方），也可拖到桌面上作为浮动面板使用。要显示剪贴板窗口，请转到菜单项 视图=>剪贴板。

上下文菜单

在代码视图窗口中，将光标定位到要插入剪贴板条目的位置或选中相应文本，然后右键单击调出上下文菜单，并从下拉列表中选择一个剪贴板条目。

键盘快捷键

可通过 编辑=>首选项=>键盘快捷键，为最多 40 个剪贴板条目分配键盘快捷键。

也可仅用键盘从剪贴板编辑器粘贴条目：先用快捷键打开剪贴板编辑器，在过滤框中输入条目名称，按回车键，然后按Esc（如果想关闭窗口）。

主菜单

也可以通过主菜单中的 插入=>剪贴板 来访问剪贴板。
