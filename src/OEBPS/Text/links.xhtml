链接与 ID

— 链接、注释与 ID —

Sigil 提供了一些实用工具，可用于创建 ID 和链接，使得创建脚注、尾注和交叉引用更轻松。

插入 ID

若要将文本标记为链接目标，需插入锚点 ID 为其命名。

选择要用 ID 标记的文本，然后单击按钮，或选择菜单项 插入=>ID：

输入 ID 名称，例如 footnote-1（须以字母开头）。

要编辑 ID，请选中该词或单击词内任意位置，然后再次单击按钮。

ID 实际通过如下 HTML 代码插入：

<a id="footnote-1">Footnote 1</a>

同一文件中不能使用完全相同的 ID。

单击下拉箭头，可查看该文件中现有 ID 的列表。

要删除 ID，需在代码视图中编辑 HTML 代码，完全移除相应标签。

要找出书中的 ID，可在代码视图中搜索；也可以把以下 CSS 临时加入样式表，在预览中用颜色高亮显示：

[id class!=sigil_index_marker] { color:#00ff00; }

插入链接

要创建指向文档其他位置的链接，请选择要链接的文本，然后单击按钮，或选择菜单项 插入=>链接：

界面列出 EPUB 中可供选择的有效目标（双击其一，或选中后单击确定）。有效目标包括文件名、已创建的锚点 ID，甚至图像。列表经过排序：当前文件中的目标排在最前，其余文件按书籍顺序排列。

要编辑链接，请再次选中文本，或用方向键在文本中移动光标（不要直接单击，否则会跳转到链接），然后单击按钮。若链接有效，列表中会将其高亮显示。

也可以在 目标 框中输入任意 URL 作为链接目标（例如指向网站）。

导航链接

在预览中，单击链接即可前往。

在代码视图中，按住Ctrl键并单击 HTML 起始标签，即可前往链接。

按住 Ctrl 单击文本：若文本是链接，将跳转到该链接；若文本只是标签，将跳转到为该标签定义的 CSS 样式。

要返回单击链接前的位置，单击 返回 按钮，或选择菜单项 返回。
