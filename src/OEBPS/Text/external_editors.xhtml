外部编辑器

— 使用“打开方式”编辑文件 —

Sigil 是一款功能强大的编辑器，但无法编辑图像，也可能缺少您在其他编辑器中使用的某些功能。遇到这种情况时，可使用 Sigil 的“打开方式”功能，在您偏好的外部程序中打开并编辑文件——保存时，Sigil 会立即自动更新其副本。想快速编辑图像或 CSS 样式表，并立即（在预览中）看到更改对图书版式的影响时，这一功能非常有用，且全程可保持某个 HTML 文件在代码视图中打开。

要在外部程序中编辑文件，请在书籍浏览器中右键单击文件名，并从上下文菜单中选择 打开方式：

首次以这种方式打开某种类型的文件时，需要为该文件类型选择一个应用程序。每种文件类型（.html、.css、.jpg、.png、.opf 等）最多可定义并保存五个不同的外部应用程序。

然后您可以为该应用程序起一个易记的名称，下次使用 打开方式 时菜单中将显示该名称：

下次使用 打开方式 时，您将看到为现有应用程序设置的易记名称，以及选择其他应用程序的选项（每种文件类型最多五个）。

文件正在外部程序中编辑时，若同时在 Sigil 中修改该文件，可能会丢失数据。使用外部编辑器时，请始终先在外部应用程序中完成更改、保存并关闭文件，再在 Sigil 中修改该文件。
