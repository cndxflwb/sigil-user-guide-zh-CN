添加封面

— 为你的图书选择一张封面 —

添加封面功能可让您为封面挑选一张图片，Sigil 会自动完成必要的更新，将该图片标记为封面。

选择菜单项 工具=>添加封面 或其键盘快捷键即可添加封面：

您可以从 EPUB 中选择一张图片，也可以使用其他文件从你的计算机中挑选一张。

细节

添加封面后，Sigil 会做以下更改：

  • 如果 cover.xhtml 文件不存在则创建它；如果已存在，则使用该文件。如果存在另一个语义为 Cover（封面）的文件，则使用那个文件。
  • 在 HTML 文件中插入显示和调整图片大小所必需的 HTML 代码。
  • 将 HTML 封面文件标记为 Cover（封面）语义。
  • 将图片文件标记为 Cover（封面）语义。

自定义 HTML 封面文件

Sigil 会在 HTML 封面文件中插入代码，使封面在大多数电子书阅读器上可调整大小并显示，但您可能希望使用不同的代码。文件创建后可编辑代码，也可提供您自己的代码供 Sigil 使用。

以下是 Sigil 默认插入封面文件的 HTML 代码：

<?xml version="1.0" encoding="UTF-8" standalone="no" ?>
<!DOCTYPE html>

<html xmlns="http://www.w3.org/1999/xhtml" xmlns:epub="http://www.idpf.org/2007/ops">
<head>
  <title>Cover</title>
</head>
<body>
  <div style="height: 100vh; text-align: center; padding: 0pt; margin: 0pt;">
    <svg xmlns="http://www.w3.org/2000/svg" height="100%"
    preserveAspectRatio="xMidYMid meet" version="1.1" 
    viewBox="0 0 SGC_IMAGE_WIDTH SGC_IMAGE_HEIGHT" width="100%" 
    xmlns:xlink="http://www.w3.org/1999/xlink">
      <image width="SGC_IMAGE_WIDTH" height="SGC_IMAGE_HEIGHT" 
      xlink:href="SGC_IMAGE_FILENAME"/>
    </svg>
  </div>
</body>
</html>

要修改 Sigil 用于 HTML 封面文件的模板，请在你的首选项文件夹中创建一个名为 cover-template2.xhtml（用于 EPUB2）和 cover-template3.xhtml（用于 EPUB3）的文件。

您可以在文本中使用某些占位符，Sigil 会用相应的值替换它们：

  • SGC_IMAGE_FILENAME：将被替换为 EPUB 中图片的路径。
  • SGC_IMAGE_WIDTH：将被替换为您图片的宽度（像素）。
  • SGC_IMAGE_HEIGHT：将被替换为您图片的高度（像素）。
