元数据

— 编辑图书的详细信息 —

元数据编辑器允许您添加或编辑图书的详细信息——如作者、书名和语言，以及 EPUB 标准定义的其他许多条目。

点击元数据编辑器按钮，或选择菜单项 工具=>元数据编辑器 或其键盘快捷键，即可编辑图书的详细信息：

图书的全部详细信息（称为元数据）都存储在 EPUB 中的 content.opf 文件里。可手动编辑这些信息，但元数据编辑器更安全、更轻松。

必需的元数据

要创建有效的 EPUB，必须填写 3 个必需的元数据条目：

  • 标题（书名）：图书的主标题。
  • 创作者：图书的主要作者，通常采用“Firstname Lastname（名·姓）”的形式。可用下方字段添加更多作者。
  • 语言：图书所使用的语言。
You can also add the optional File-As property to provide the author’s name for sorting purposes, usually of the form “Lastname, Firstname”.|→还可添加可选的 File-As（排序依据）属性，提供用于排序的作者姓名，通常采用“Lastname, Firstname（姓，名）”的形式。←|

附加元数据

可用添加元数据按钮添加元数据条目，或用添加属性按钮为已有的元数据项添加附加属性。

如果您点击添加元数据或添加属性，Sigil 将显示针对 EPUB 类型的元数据/属性对话框条目。

例如，角色元数据属性列表包含数百种人们在这本书创作过程中可能承担的活动，如作者、编辑、校对等：

可多次添加同一类型的字段。

可选中条目，点击 上移或下移按钮重新排列条目顺序（这可能会影响电子书阅读器对信息的显示方式）。
