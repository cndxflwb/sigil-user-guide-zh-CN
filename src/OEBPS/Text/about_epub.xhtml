关于 EPUB

EPUB（electronic publication，电子出版物）格式是最流行的电子书文件格式之一。它是一种开放且免费提供的标准，任何人都可以使用。

EPUB 电子书不过是一组文件的集合，每个文件承担不同功能，并用通用 zip 格式存储在一起。这些文件包括文字、图片、目录（Table of Contents）、样式表、字体，以及作者、书名等图书信息。由于采用标准格式，你的图书可在许多电子书阅读器上阅读，也可轻松转换为其他格式，供不支持 EPUB 的阅读器使用。

EPUB 使用 XHTML 存储书中文字。XHTML 是符合 XML 规范的 HTML（Hyper Text Markup Language，超文本标记语言）格式，与网页显示文字和图片所用的代码相同。简言之，文件由文本和标记标签（如 <h1> 或 <p>）组成，用于指示电子书阅读器如何排版和显示文字——例如哪些文字用粗体或斜体、哪些作为段落或标题等。

除控制版式的 XHTML 标签外，EPUB 图书通常还使用样式表（stylesheet）组织 XHTML 文件所用的样式。样式表是 EPUB 中的另一个文件，包含 XHTML 标签、类和选择器列表，并说明如何显示与相应标签、类或选择器匹配的文本。例如 <h1>（1 级标题）应更大并居中。这样既能将内容与版式分离，又能轻松调整 EPUB 外观。

当然，实际阅读时并不会看到这些 XHTML 文件或样式表。电子书阅读器如同普通图书或网页浏览器一样显示文字和图片，尽可能贴近您定义的格式，即使有数千页或数千个文件也不例外。

不必理解 EPUB 格式的所有细节或 XHTML 排版代码即可开始使用 Sigil。不过，使用一段时间后，就需要熟悉这些知识，才能充分发挥 Sigil 高级功能，最终实现预期的设计效果。

文本文件以 XHTML 格式（一种符合 XML 规范的 HTML 版本）存储，但为使本指南更易阅读，我们几乎不加区分地混用 HTML 和 XHTML 两种说法。

Sigil 的设计目标是完全兼容较旧的 EPUB 2 标准版本和较新的 EPUB 3 标准。

尽管 Sigil 是为处理 EPUB 文件而设计的，但 EPUB 格式可以轻松转换为 MOBI 等其他电子书格式。

无障碍 EPUB

让 EPUB 对有阅读/视觉障碍者更具无障碍性（Accessible），在市场中已变得越来越重要，许多出版商和政府（尤其是欧洲和加拿大的）现在已将其作为强制要求。为此可用的工具之一是添加 Aria Roles（仅限 EPUB3），为屏幕阅读软件补充语义含义，此外还有可被 EPUB 电子书阅读器使用的 epub:type 语义。使用 aria role、aria-label 和 aria-labelledby 属性的规则相当复杂。Sigil 2.6.0 版本新增了 插入 Aria 片段 和 插入角色 工具来帮助简化操作。对无障碍性与语义标记的完整讨论超出了本用户指南的范围，但以下链接可以为您提供更多信息。
