为每个章节创建文件

如果把一个 HTML 文件加载到了 Sigil 中，通常意味着所有文字和章节都在一个大文件里。这样做是允许的，但 EPUB 的标准做法是把书中的每一章都放进单独的 HTML 文件。较小的文件体积是某些电子书阅读器读取书籍所必需的，而且这样还能让 EPUB 显示更快、编辑更方便。

由于大多数电子书阅读器会在 EPUB 中从新页面开始显示新文件，因此章节也会从新页面开始。

每章创建一个文件

把书拆分成多个文件，最简单的方法是在想开始新文件的位置使用 在光标处拆分 按钮 。
