自定义用户界面

— 让它按你想要的方式工作 —

Sigil 的用户界面可深度定制。

Sigil 同时支持深色和浅色主题，它们直接继承自你的系统偏好设置。

在 macOS 上，你可以使用系统偏好设置随时在浅色主题和深色主题之间切换，甚至可以根据一天中的时间自动切换。如今 Windows 和大多数 Linux 发行版也同样如此。在 Sigil 启动时会检测并设置 Windows 和 Linux 上的系统主题。

Sigil 的主界面由一个主窗口组成，其中显示多个面板以及一组工具栏。你可以使用 视图 菜单来配置要显示其中的哪些项目。

你可以在 视图 菜单中自定义要显示的面板。

你可以使用的面板有：

  • 书籍浏览器：用于浏览书中的文件。
  • 剪贴板：你定义的剪贴板条目
  • 预览：动态更新的书籍预览。
  • 目录：目录。
  • 验证结果：验证书籍后的输出信息。

工具栏可以使用 工具栏 菜单来自定义，该菜单通过将鼠标悬停在 视图 菜单顶部的“工具栏”项上来显示。

本章其余部分将讨论三个主题

  • 自定义工具栏
  • 自定义面板
  • 自定义图标

自定义工具栏

打开 视图=>工具栏 菜单，选择你想在界面中看到的工具栏。然后，将它们移动到你觉得最舒服的位置。

要将工具栏移动到其他位置，请将光标悬停在工具栏左侧的抓取栏上。这样操作时，会出现移动光标。

将工具栏拖动到主窗口中的其他位置。某个区域会高亮显示，指示你松开鼠标时工具栏将被放置的位置。

你也可以左右拖动光标来调整工具栏的大小。

如果你把工具栏缩小到无法显示所有图标，工具栏右侧会出现一个箭头。单击该箭头后，会出现一个子菜单，让你可以访问工具栏中的所有按钮。

自定义面板

自定义面板的方式与自定义工具栏类似。如果你把光标移到面板顶部的横幅上并按下鼠标左键，会出现移动光标。然后你可以把面板拖出主窗口，使其与主窗口分离。该面板会变成一个自由浮动窗口。

要将窗口重新停靠回主窗口，请拖动它，直到你想放置的区域高亮显示，然后松开鼠标按键。

你可以将浮动窗口放置到已有面板上，为两个面板创建选项卡式界面。操作方法是将其拖到已有面板上方，使已有面板高亮显示。

放置窗口后，会创建一个选项卡，以便你在两个面板之间切换。

要将窗口重新停靠为紧挨已有面板的独立面板，请将其拖到主窗口上方，直到已有面板的侧面、顶部或底部有区域高亮显示，然后松开鼠标按键。

该窗口会作为一个独立面板重新停靠到主窗口中。

面板之间的相对大小可以通过以下方式调整：将光标悬停在两个面板之间的边界上，然后把边界拖到新位置。

自定义图标

图标可以在 首选项 对话框中自定义。

要自定义图标主题，请使用 编辑=>首选项 菜单打开 首选项 对话框。单击左侧的 外观 标签页，再单击 图标主题 标签页。如果你将光标悬停在每个可选择的主题上，会有一个工具提示显示该主题中图标的缩略图。

单击 主用户界面 标签页并调整滑块，即可调整图标的大小。
