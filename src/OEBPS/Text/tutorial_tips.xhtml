技巧

下面是一些实用建议，帮你检查 EPUB 是否完整：

  • 使用元数据编辑器按钮 设置书名、作者和语言。如有需要，还可以设置版权、出版日期、主题、简介以及 ISBN（如有）。

  • 为封面创建一个 HTML 文件，并把该文件和封面图片都设置为封面类型。

  • 右键点击第一个正文文件，选择 添加语义=>正文（Text）（适用于 EPUB2）或 添加语义=>正文（Body Matter）（适用于 EPUB3），告知电子书阅读器书籍应从此处打开。

  • 如果生成过目录，请使用生成目录按钮 重新生成；如有 HTML 目录，也请重新创建，确保目录是最新内容。

  • 测试目录链接是否按预期工作。

  • 测试链接、脚注或尾注是否按预期工作。

  • 使用拼写检查按钮 检查拼写；如果书中有很多专有词汇，可以为这本书单独创建词典。

  • 使用 EPUBCheck 插件查找 EPUB 错误并修复它们——典型的错误消息及处理方法请参阅验证。

  • 使用 工具=>使用 W3C 校验样式表 检查样式表是否有效。

  • 把样式表链接到所有需要使用它的文件。

  • 使用 工具=>删除未使用文件 ……移除未使用的图像、音频或视频文件，以及未使用的样式类。

  • 运行 工具=>报告，查看报告中是否有任何异常情况（多余文件、损坏的链接、已使用但未定义的类等）。

  • 使用 CSS 文件管理样式时，请搜索内联 CSS 所用的 <style> 标签，或内联样式所用的 style 属性，并将其转换为 CSS 样式表文件。

  • 如需精益求精，可以搜索并替换诸如 &nbsp;、<br />、空段落 <p>&nbsp;</p>、空的 <div></div> 标签、像 src=""、href="" 或 ="" 这样的空属性之类的代码，把 – 改为 &ndash;，把 ' 改为 ’ 等——当然，如需保留则另当别论。

  • 在真实的电子书阅读器上验收。Sigil 只能大致呈现书籍最终的显示效果。尽管 EPUB 是一项标准，但电子书阅读器设备和软件种类繁多，各有各的怪癖和缺陷。

万一没注意到——请务必在真实的设备和电子书阅读器软件上测试书籍！
