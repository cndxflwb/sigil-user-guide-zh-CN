打开与保存文件

— 加载并保存你的图书 —

Sigil 支持打开 EPUB 文件，以及读取 HTML 和文本文件。保存图书时，Sigil 会以 EPUB 格式保存：EPUB 文件会将您所有的 HTML 文件、图像、样式表、字体等打包压缩到一个文件中。

尽早保存、经常保存，并制作备份副本！

在其他程序中打开你的 EPUB 之前，请务必先关闭 Sigil——否则另一个程序会锁定该文件，导致您无法在 Sigil 中保存。

打开与添加文档

打开文件

要打开文件，请点击 Open（打开）按钮，或选择菜单项 文件=>打开 或其键盘快捷键，然后选择要打开的文件：

EPUB 文件

  • EPUB 文件中的所有内容都会自动加载：HTML 文件、图像、样式表、元数据等。
  • Sigil 会将文件解包到指定文件夹中，并通过工具提示显示书籍浏览器中所呈现的确切路径。书籍浏览器本身会按文件在 EPUB 中的类型或功能将文件分组。
  • 如果 EPUB 包含常见错误，Sigil 会尝试修正它们。
  • 根据你的首选项设置，Sigil 会对 HTML 文件进行格式化或清理。
  • 如果清理后 EPUB 中仍然存在无效的 HTML 文件，Sigil 依然会加载该文件，并报告需要修复的错误。

XHTML 文件

  • 若可以，Sigil 会导入 XHTML 文件及其链接的文件和样式表，并放入各自的文件夹。
  • XHTML 文件中的元数据会加载到图书的元数据中。
  • 根据你的首选项设置，Sigil 会格式化或清理文件。
  • 如果清理后 XHTML 文件仍然无效，Sigil 会报告错误，但可能不会加载该文件。您可能需要在 Sigil 之外修复这些错误。

文本文件

  • 文本文件将转换为 XHTML。段落之间须用空行分隔，才能拆分为独立的段落。

添加文件

点击 添加现有文件 按钮、选择菜单项 文件=>添加=>现有文件，或在书籍浏览器中右键单击某个文件并选择 添加现有文件，即可向 EPUB 添加文件：

XHTML 文件

  • 不会从文件中加载元数据（与使用“打开”时不同）。
  • Sigil 会尝试加载引用的文件。
  • 文件将放入相应的文件夹。

图像文件

  • 文件将放入当前的 Images（图像）文件夹。

视频文件

  • 文件将放入当前的 Video（视频）文件夹。

音频文件

  • 文件将放入当前的 Audio（音频）文件夹。

样式表文件

  • 文件将放入当前的 Styles（样式）文件夹。

字体文件

  • 文件将放入当前的 Fonts（字体）文件夹。

其他文件

  • 所有其他文件都显示在书籍浏览器的 Misc（杂项）分组下，因为它们通常不在 EPUB 中使用；不过，Misc 分组中的某些文本文件仍可在 Sigil 中编辑。

添加空白文件

您也可以在 Sigil 中创建新的空文件。选择菜单项 文件=>添加，然后从空白 HTML 文件、空白样式表、空白 JavaScript或空白 SVG 图像（一种特殊图像格式）中选择。您也可以在书籍浏览器中通过右键上下文菜单执行此操作，甚至可以在首选项中为其添加键盘快捷键。

要使用您自己的自定义 HTML 文件或 CSS 样式表，只需创建相应文件并命名：EPUB2 使用 user-template2.xthml 和 user-template2.css，EPUB3 使用 user-template3.xhtml 和 user-template3.css。然后将这些文件放入 Sigil 的首选项文件夹（在 Windows 中：选择 编辑=>首选项；在 Mac 上：选择 Sigil=>首选项，然后点击 打开首选项文件夹 按钮，将文件复制到该文件夹中）。此后，每当您添加空白 HTML 文件或空白样式表时，插入的都将是你的自定义模板。

保存你的 EPUB

点击 保存 按钮，或选择菜单项 文件=>保存 或其快捷键即可保存图书。在进行重大编辑之前，您应当始终保存文档，以防需要撤销这些更改。

您保存的 EPUB 文件包含构成图书的所有文件——文本、图像、样式表、嵌入字体、目录、元数据等。

如果您编辑了文档中的任何文本，标题栏中的文件名后面会添加一个星号（*）。

保存图书时，Sigil 会检查其中的某些错误，并在需要修复时向您发出警告。但您应当始终运行 Sigil 插件版验证器，例如用于 EPUB2 的 FlightCrew 以及用于 EPUB2 和 3 的 EPUBCheck，来检查典型的 EPUB 问题。

Sigil 并不总能保存包含错误的 EPUB，因此频繁保存可以让您更容易识别需要修正的错误。

保存文件时，Sigil 还会按照你的首选项设置清理源代码。

保存副本

您可选择 文件=>保存副本，将 EPUB 的副本保存为不同的文件名。它与 保存 或 另存为 的区别在于，当前正在处理的图书不会改名。因此，可用此功能保存 EPUB，而无需更改图书名称或保存目录。

使用 文件=>保存副本 进行快速备份。

保存单个文件

您还可以在书籍浏览器中右键单击文件名，并从上下文菜单中选择 另存为。随后即可命名该特定文件，并将其保存到计算机上的某个目录中。如果选择了多个文件，所有文件都会保存到您所选的目录中。这是一种无需分享整个 EPUB 就能与他人分享特定文件的快捷方式，也可以用来创建供其他图书使用的模板文件。
