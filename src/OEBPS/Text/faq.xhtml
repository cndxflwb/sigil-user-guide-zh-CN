常见问题

Sigil 支持 EPUB 3 吗？

是的，Sigil 完全支持流式布局的 EPUB2 和 EPUB3。事实上，Sigil 在设计时就致力于轻松创建兼容 EPUB2 的 EPUB3 电子书。编辑完成后，选择 工具=>EPUB3 工具=>为 EPUB2 阅读器生成 NCX/指南 即可。

为什么我的书在 Sigil 中显示正常，在设备上却不正常？

每个显示书籍的设备或程序使用的软件都略有不同。尽管 EPUB 是统一标准，同一本书在不同设备上的显示效果仍可能存在差异。有时书在 Sigil 中显示正常，在特定设备上却异常；有时则相反，在 Sigil 中显示异常，在阅读器上却正常。请尽可能多地在不同设备上测试。

在哪里获取帮助

哪里可以获得 Sigil 帮助？

如果遇到《Sigil 用户指南》未涵盖的问题，请访问 MobileRead 上的 Sigil 论坛，用户和开发者会尽力提供帮助。

哪里可以询问 EPUB 相关问题？

如果问题侧重于 EPUB 的格式与样式设置，而非 Sigil 的操作方法，可以在 MobileRead 上的 EPUB 论坛发帖。

哪里可以报告缺陷或请求新功能？

正式的缺陷报告请通过 https://github.com/Sigil-Ebook/Sigil 的 GitHub 仓库提交。如需，也可以将缺陷报告发布到 MobileRead Sigil 论坛。请附上 Sigil 版本号、操作系统（Windows 10、macOS、Linux Mint）以及复现缺陷的具体步骤，或提供能复现缺陷的示例 EPUB。

使用 Sigil

Sigil 在 MAC OS 10.11 上无法启动？

MAC 上的 Sigil 需要 MAC OS 10.12 或更高版本。

Sigil 有教程或手册吗？

有。在 Sigil 中选择 帮助=>用户指南，即可查看包含教程的 HTML 版《Sigil 用户指南》。也可以访问 Sigil 主页，获取 HTML 版和 EPUB 版的链接。

可以用 Sigil 写书吗？

可以，但 Sigil 主要是编辑程序，用于编辑已在其他文字处理软件中写好的书。建议先用喜欢的编辑器写作，导出为 HTML，再用 Sigil 排版为 EPUB。如果确实想在 Sigil 中写作和编辑，也完全可行——《Sigil 用户指南》就是完全用 Sigil 写成的。

支持 DOC、MOBI、KF8 格式吗？

Sigil 是 EPUB 编辑器，可以打开 EPUB 文件并导入 HTML 文件。其他格式必须先转换为 HTML 才能导入。

文件格式繁多，格式转换并非小事。既然已有出色的格式转换工具，Sigil 将继续专注于做最好的 EPUB 编辑器。

更多信息请参见“准备好 Sigil 可处理的文件”一章。

要将 EPUB 转换为 MOBI 或 KF8，请使用 Kindle 工具。

如何使用正则表达式？

有关使用正则表达式的更多细节和技巧，请参见《Sigil 用户指南》中的“正则表达式”一章。

Sigil 无法导入我的文件？

Sigil 只能导入或打开有效的 HTML 和 EPUB 文件。它会尝试修复文件中的常见问题，但如果存在重大问题（如缺少标准代码或文件），可能无法打开。

如果首选项中的“修复代码”已关闭，请尝试设为“打开时修复”，该选项可以纠正某些错误。有时 Sigil 会给出错误消息，有助于定位文件问题。此时可以用 Zip 或归档程序打开文件，编辑其中的内容来修复。但通常问题原因并不明确。

如果要报告某个无法加载并导致 Sigil 崩溃的文件，请将 EPUB 文件附在缺陷报告中。但大多数情况下，需要自行修复该文件。

拼写检查不能正确处理引号或破折号？

如果安装了自定义的 hunspell 词典，但它无法识别弯引号、长破折号等，可能还需要额外的连字符词典文件。更多细节请参见《Sigil 用户指南》中的“拼写检查词典首选项”。

粘贴到 Sigil 中的文本显示不正常？

直接粘贴富文本到 Sigil 中效果可能不佳。可以尝试先将文本导出（或转换）为 HTML，再直接导入新文件，这样可以保留格式。

如需以纯文本形式粘贴内容，请在代码视图中粘贴，以免保留格式标签。

格式与样式

为什么我的书显示随机的问号？

这可能是因为原始文件包含 软连字符。ADE（许多系统上用于显示 EPUB 的 Adobe 软件）不支持软连字符。从文件中删除软连字符后，问号就会消失。请查找类似 &shy; 或 &#8209; 的内容，即这两个字符之间的任何“奇怪”字符。需要在代码视图中查看原始 HTML，也可以使用报告功能查看文档中使用的字符。

这也可能是因为 ADE 无法执行字体替换。

在 Sigil 中，如果当前字体缺少渲染文本中某个字符所需的 字形，就会改用能够渲染该字符的其他字体的字形，这就是字体递补。因此，只要计算机上有字体能显示这些字符，Sigil 就能显示。

而 ADE 默认只显示一小部分 Unicode 字符，支持的字符列于 Adobe PDF Reference v1.7 附录 D 的表 D.1 和 D.3。

如需在 ADE 中显示上述范围以外的字符，必须嵌入所需的字体。

如何更改文本的样式？

请阅读《Sigil 用户指南》中的“样式表”教程——本节许多答案都需要了解该基础教程。

请注意，各电子书阅读器对格式或样式的支持程度不同，文本在某个阅读器或 Sigil 中的显示效果可能与另一款阅读器略有差异。

什么是样式表和 CSS？

CSS 是层叠样式表（Cascading Stylesheets）的缩写。有关 CSS 的更多细节及为何应使用样式表设置文本格式，请参见《Sigil 用户指南》中的“样式表”教程。

可以用 Sigil 嵌入自己的字体吗？

可以——请参见《Sigil 用户指南》中的“字体”教程。

文档中的 sgc-1 是什么意思？

sgc 表示 Sigil 类，用于为文本的特定部分设置格式样式。Sigil 会自动为某些 span 标签和“style”属性创建 sgc 类。

如何添加空行？

不要这样做。更好的做法是使用样式表，通过样式定义来设定特殊段落上方或下方的空白量。例如，要在段落上方留出 1.5 行的空白，可以使用这个样式类：

p.blankabove { margin-top: 1.5em; }

然后在你的文本中为段落使用该类：

<p class="blankabove">My paragraph</p>

如果你确实想这么做，可以插入一个换行：

<br />

或一个空段落：

<p>&nbsp;</p>

对于多行空白，最好使用样式来定义你想留出的空白量。

如何开始新的一页？

如果你为页面使用单独的文件，那么几乎所有电子书阅读器都会为你的文本开始新的一页。

如何在目录中为章节标题使用图片？

在你想放的位置插入图片——在代码视图中看起来像这样：

<img src="../Images/myimage.png" />

若用该图片作为标题需添加标题元素，并给它一个要在目录中显示的标题，例如：

<h1 title="CHAPTER 1"><img src="../Images/myimage.png" /></h1>

现在目录中会有一个名为“CHAPTER 1”的条目，它链接到你的图片。

如果你只想要一个章节条目，甚至可以在文档中使用不含文本的标题标签：

<h2 title="Chapter Subsection"></h2>

不过，如果图片在文件开头，更简单的做法是直接把目录链接到该文件。

如何为文本添加页边距？

将以下这段文字以你偏好的左右页边距添加到你的 CSS 定义中：

@page {
   margin-left: 5px;
   margin-right: 5px;
}

如何删除段落之间的空白？

要删除所有段落之间的空白，请将以下内容添加到 CSS 定义中：

p {
    margin: 0; 
    padding: 0;
}

这只会影响段落间距（p 表示段落）。要删除各种元素之间的所有空白，让文档看起来更“像书”，请使用这段代码：

body, div, p, h1, h2, h3, h4 { margin: 0; padding: 0; }

如何添加“首字下沉”？

并非所有阅读器都支持首字下沉，但实现首字下沉有几种方法。如果你的书格式恰到好处，仅用 CSS 就能实现。

将这段代码添加到你的 CSS 定义中，它会让使用 dropcap 类（位于 span 标签中）的文本应用特定的值：

span.dropcap {
    float: left;
    font-size: 4.7em;
    line-height: 0.8em;
    margin-right: 3pt;
    margin-bottom: -0.1em;
}

在 Sigil 中，找到你想以首字下沉开头的段落，切换到代码视图。将文本从类似这样：

<p>Hello</p>

改为：

<p><span class="dropcap">H</span>ello</p>

查看预览，你应该就能看到首字下沉效果了。

在所有需要首字下沉段落开头的字母外添加 <span class="dropcap"></span>。

你可能需要调整 font-size、line-height 和 margin-bottom 的值，才能获得想要的效果。Sigil 的预览可能无法精确展示它在所有电子书阅读器上的显示效果，但已经相当接近。

为什么我的字体在 iBooks 中不显示？

如果你在 EPUB 中嵌入了字体，iBooks 需要 EPUB 中有一个非标准文件来告诉它使用你的字体。这在 Sigil 中无法完成。

用文本编辑器创建一个名为 com.apple.ibooks.display-options.xml 的文件，并放入以下内容：

<?xml version="1.0" encoding="UTF-8"?>
<display_options>
<platform name="*">
<option name="specified-fonts">true</option>
</platform>
</display_options>

然后使用归档管理器解压或访问 EPUB 文件。将你创建的 xml 文件添加到 EPUB 的 META-INF 目录中，然后重新压缩你的 EPUB。

为什么我的文件因 plist 而无法通过 EPUBCHECK？

如果你在 iTunes 中打开你的 EPUB，它会自动在 EPUB 顶层添加一个额外的 .plist 文件。这会导致它无法通过 EPUBCHECK。如果你打算在其他地方使用你的 EPUB，请不要在 iTunes 中打开它。你可以解压 EPUB 并删除该文件，然后重新压缩文件。

为什么我的国际键盘 AltGr 键不能按预期工作？

如果你使用带有 AltGr 键的国际键盘，以便在输入国家字符或其他符号时启用键盘快捷键，使用附加参数启动 Sigil 可能会有帮助：

"C:\Program Files\Sigil\Sigil.exe" -platform windows:altgr

要使这一更改持久生效，你可以在启动 Sigil 应用程序的快捷方式中，将其添加到 Windows 属性窗口。

如果你希望直接打开 EPUB 文件时 AltGr 键也能正常工作，你需要以类似下面的方式将附加参数添加到你的 Windows 系统注册表中：

"C:\Program Files\Sigil\Sigil.exe" -platform windows:altgr "%1"
