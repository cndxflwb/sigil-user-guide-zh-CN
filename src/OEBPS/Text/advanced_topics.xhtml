使用 Sigil 的环境变量

Sigil 中一些很少用到的设置由“环境变量”控制。环境变量是一个可由用户定义的值，它可以影响运行中的进程在计算机上的行为。关于如何在你的计算机上设置和使用环境变量，更多信息请参阅相关说明。从 Sigil 2.6.2 开始，我们努力让设置和修改 Sigil 环境变量的过程变得更简单。使用该版本或更高版本时，你只需用任意文本编辑器（记事本、BBedit、emacs、vi、kate 等）在 Sigil 首选项文件夹中创建一个名为 env-vars.txt 的文件，然后按以下格式逐行添加每个环境变量及其值：

ENVIRONMENT_VARIABLE_NAME=VALUE

其中，将 ENVIRONMENT_VARIABLE_NAME 替换为下面列出的某个环境变量名，并将 VALUE 替换为你想设置的值（无论是数字、字符串，还是表示“真”的值 1）。不使用引号。例如：

SIGIL_DISABLE_VERSION_META=1

请记住，如果你通过菜单打开 Sigil 的首选项，可以使用左下角的按钮来显示你的 Sigil 首选项文件夹所在的位置。

然后保存此文件。请注意，Sigil 只在首次启动时读取此文件，因此在对 env-vars.txt 文件做任何修改之前，请记得先关闭并退出 Sigil，并在修改后重新启动 Sigil。

Sigil 使用以下环境变量：

  • SIGIL_DISABLE_VERSION_META 将此环境变量设置为任意值，即可阻止 Sigil 添加用于标识 Sigil 是本 epub 制作工具的元数据。

  • SIGIL_DISABLE_NFC_NORMALIZATION 设置此环境变量可禁止将用户内容转换为 Unicode 规范化形式 C（NFC）。请注意，禁用 NFC 形式意味着许多电子书阅读器将无法正确搜索你的 epub 中包含重音符号的文本。

  • SIGIL_FOCUS_HIGHLIGHT_COLOR 此项允许用户控制启用焦点高亮矩形时所使用的颜色。其值应为标准 CSS 颜色值，以 '#' 开头，后跟 6 位十六进制数字。

  • SIGIL_ALLOW_CODEVIEW_DROP 设置此值后，将启用代码视图内部的拖放编辑。请注意，在某些平台上，使用拖放在代码视图中编辑可能不稳定，会导致 Sigil 崩溃。对于决定启用拖放的用户，我们不会提供支持，因为修复这些问题超出了我们的控制范围（属于 Qt6 的内部问题）。

  • SIGIL_DEBUG_LOGFILE 将此环境变量设置为用户可写位置的完整路径（包括文件名和扩展名），Sigil 就会把所有额外的调试信息输出到该日志文件。调试结束后务必取消设置此环境变量，因为该文件会不断累积输出，最终占满用户的磁盘空间并拖慢 Sigil。

  • SIGIL_FUNCTION_REPLACE_LOGFILE 将此环境变量设置为用户可写位置的完整路径（包括文件名和扩展名），Sigil 就会把所有 Python 函数替换 的日志消息输出到该日志文件。调试结束后务必取消设置此环境变量，因为该文件会不断累积输出，最终占满用户的磁盘空间并拖慢 Sigil。

  • SIGIL_USE_FREETYPE_FONTENGINE 此环境变量仅适用于 Windows。设置此项将让 Sigil 使用 FreeType 字体引擎。这对在 epub 中大量使用 Woff/woff2 字体的 Windows 用户很有用，因为当前 Qt 版本的 Windows 字体引擎尚不支持这些字体类型。

  • SIGIL_PREVIEW_TIMEOUT 将此环境变量设置为一个数值（单位为毫秒），即可决定在代码视图中编辑时，用户停止输入后经过多长时间更新预览。最短延迟为 1000 毫秒，最长延迟可设置为 10000 毫秒。通常没有理由设置此项，除非你正在编辑体积巨大的 xhtml 文件，导致更新预览耗时过长。

  • SIGIL_DRAG_DISTANCE_TWEAK 此环境变量仅适用于 Windows。你可以设置此项来改变系统检测到拖放操作之前所需移动的像素距离。其有效值范围为 -20 到 20 像素。

  • SIGIL_DISABLE_CURSOR_BLINK 许多人对闪烁和闪动敏感。如果你正是这类人群，可以设置此环境变量来禁用代码视图和许多输入对话框中持续闪烁的光标。

  • SIGIL_SKIP_UPDATE_CHECK 设置此项将告诉 Sigil 不要 使用网络查询最新版本。对于那些自行构建并发布 Sigil 版本、并希望用户使用其构建版本的 Linux 发行版来说，这一点可能很重要。

  • SIGIL_PREFS_DIR 你可以设置此项来改变 Sigil 首选项文件夹的位置。请注意，这是唯一一个不能写在 env-vars.txt 文件里的环境变量，因为 Sigil 必须先知道该目录的位置，才能找到那个文件。

  • SIGIL_USE_COLORSCHEME_CHANGED 此环境变量仅适用于 Linux。设置此项将告诉 Sigil，你的 Linux 桌面可以配合 Qt 内置的 QStyleHints::colorSchemeChanged 信号，检测桌面主题在浅色与深色之间的切换。

  • SIGIL_EXTRA_ROOT 此环境变量主要用于 Linux。设置此项将告诉 Sigil 你的 share/sigil 文件夹所在的位置。

  • SIGIL_DICTIONARIES 此环境变量主要用于 Linux。设置此项将告诉 Sigil 到何处查找安装在系统上的 hunspell 词典。

  • SIGIL_NO_CUSTOM_DIRECTORY_ICONS 如果你大量使用存有海量文件的网络驱动器，此环境变量会很有用。它可以避免不断搜索系统级的自定义文件图标，从而大幅提升非原生文件对话框（如“添加现有文件……”）的性能。

  • SIGIL_FORCE_NATIVE_FILE_DIALOG 此环境变量强制 Sigil 使用操作系统的原生文件对话框。不幸的是，在近期版本的 Qt 中，使用原生文件对话框已导致了一些崩溃问题，使用风险自负。

除了 Sigil 特有的环境变量之外，你还可以使用 Qt6 特有的环境变量，包括 QT_QPA_PLATFORM 和 QTWEBENGINE_CHROMIUM_FLAGS。由于这些变量的用法会随新版本发布而变化，你需要借助搜索引擎查找最新的 Qt6 资料，了解如何用这些环境变量来控制 Sigil。

使用 Sigil 的模板文件

许多 Sigil 用户会自行制作起始 xhtml 和 css 文件，比起 Sigil 的默认文件，他们更愿意使用自己的版本。为满足这一需求，Sigil 增加了加载用户自定义起始 xhtml 和 css 文件的功能。要创建这些“模板”，只需按自己的喜好编辑任意空白的 xhtml 或 css 页面，然后用下列特定文件名之一将其保存到 Sigil 首选项文件夹中。当你使用 Sigil 的书籍浏览器添加空白 HTML 或空白 CSS 文件时，Sigil 就会改用你的模板。如果想停用它们，只需重命名或删除这些文件即可。

  • user-template2.xhtml EPUB2 专用 xhtml 文件。

  • user-template3.xhtml EPUB3 专用 xhtml 文件。

  • user-template2.css EPUB2 专用 css 文件。

  • user-template3.css EPUB3 专用 css 文件。

类似地，许多人希望封面图片的 xhtml 页面采用特定的布局。为方便实现这一点，Sigil 允许用户创建 cover-template2.xhtml 或 cover-template3.xhtml 文件，并将其存放在 Sigil 首选项文件夹中。

Sigil 允许这些封面模板使用一组占位符，在创建封面时 Sigil 会自动填入相应的值：

  • SGC_IMAGE_FILENAME —— 所选图像的相对路径。
  • SGC_IMAGE_WIDTH —— 所选图像的宽度（像素）。
  • SGC_IMAGE_HEIGHT —— 所选图像的高度（像素）。

下面是一个使用 SVG 并利用这些占位符的 cover-template3.xhtml 示例：

 <?xml version="1.0" encoding="UTF-8" standalone="no" ?> <!DOCTYPE html> <html xmlns="http://www.w3.org/1999/xhtml" xmlns:epub="http://www.idpf.org/2007/ops" lang="zh-CN" xml:lang="zh-CN"> <head> <title>Cover</title> </head> <body> <div style="height: 100vh; text-align: center; padding: 0pt; margin: 0pt;"> <svg xmlns="http://www.w3.org/2000/svg" height="100%" preserveAspectRatio="xMidYMid meet" viewBox="0 0 SGC_IMAGE_WIDTH SGC_IMAGE_HEIGHT" width="100%" version="1.1" xmlns:xlink="http://www.w3.org/1999/xlink"> <image width="SGC_IMAGE_WIDTH" height="SGC_IMAGE_HEIGHT" xlink:href="SGC_IMAGE_FILENAME\"/> </svg> </div> </body> </html>

在 EPUB3 中嵌入 PDF

许多电子书阅读器采用 Adobe Digital Editions 软件开发工具包作为底层渲染和显示引擎，还有许多采用基于网页浏览器的显示引擎。这些阅读器都具备在 epub 中嵌入 Adobe PDF 文档的能力。

遗憾的是，许多旧款电子书阅读器并不支持 PDF。EPUB3 规范考虑到了这种情况，它提供了“递补”资源（有时是 OPF 绑定），以应对阅读器没有能力显示某种资源类型的情形。

更不巧的是，据 EPUBCheck 的开发者说，几乎没有阅读器真正支持递补资源或 OPF 绑定的用法。这让 EPUB3 开发者陷入了两难境地。幸运的是，可以使用 “object” 标签创建一个基于 xhtml/html 的替补方案，从而使书脊完全由 xhtml 文件构成。

下面是一个示例，展示如何在 xhtml 文件中使用 “object” 标签来显示嵌入的 PDF，或以基于 xhtml 的替代内容作为替补方案——该方案适用于许多无法处理 PDF 格式的旧款电子书阅读器。

 <?xml version="1.0" encoding="utf-8"?> <!DOCTYPE html> <html xmlns="http://www.w3.org/1999/xhtml"> <head> <title>PDF Test Page</title> </head> <body> <object type="application/pdf" data="../Misc/demo.pdf" width="500" height="500"> <!-- The child of the object tag holds the xhtml fallback --> <h3>PDF Fallback text</h3> <p>This text is being displayed, if the reader or reading device doesn't support embedded .pdf files.</p> </object> </body> </html>

此外，也可以直接链接到 PDF，或将链接加载到 iframe 中，但这些方式无法为旧款阅读器提供替补方案，应尽可能避免使用。

使用 Qt QSS 自定义 Sigil

Sigil 所使用的图形用户界面（GUI）库 Qt 支持一种自有的、类似 css 的用户样式，称为 QSS，它允许用户按自己的偏好修改 Sigil 的许多方面。Sigil 首次启动时，会自动加载你的 Sigil 首选项文件夹中名为 qt_styles.qss 的 QSS 样式表，找到的所有 QSS 样式。

下面是一些简单示例，展示如何使用 Qt 的 QSS 样式来自定义 Sigil。

如果想尝试其中任何一个，只需复制下面某个 QSS 代码块，将其保存为名为 qt_styles.qss 的文本文件，放进你的 Sigil 首选项文件夹中即可。

让查找与替换按钮只显示文字

QFrame QToolButton#findNext, QFrame QToolButton#replaceCurrent, QFrame QToolButton#replaceFind, QFrame QToolButton#restart, QFrame QToolButton#replaceAll, QFrame QToolButton#count { qproperty-toolButtonStyle: ToolButtonTextOnly; }

让查找与替换按钮同时显示图标和文字

QFrame QToolButton#findNext, QFrame QToolButton#replaceCurrent, QFrame QToolButton#replaceFind, QFrame QToolButton#restart, QFrame QToolButton#replaceAll, QFrame QToolButton#count { qproperty-toolButtonStyle: ToolButtonTextBesideIcon; }

使用 QSS 隐藏所有工具提示。

QToolTip { max-width:0; max-height:0; margin:0; padding:0; }

隐藏查找与替换历史

QFrame QComboBox QAbstractItemView::item { max-height: 0; } #cbFind, #cbReplace { qproperty-maxCount:0; }

设置查找与替换输入框的字体和字号

#cbFind, #cbReplace { font-family: "Georgia"; font-size: 16px; }

将 关于 对话框中的 Sigil 版本号改为其他颜色

QLabel#lbVersionDisplay { color: #FFA000; }

为 关于 对话框的作者选项卡设置灰色背景

QTextEdit#creditsDisplay { background-color: #323232; }

为书籍浏览器面板设置灰色背景

#bookbrowser { background-color: #323232; }

将书籍浏览器面板的边框设为灰色

#bookbrowser { border: 1px solid #323232; }

将查找与替换栏的边框设为灰色

QFrame { border: 1px solid #323232; }

更改默认的选区颜色

*, *::separator, *::handle, *::tab-bar, *::tab, *::section { selection-background-color: #00404a; selection-color: white; }

更改 QDockWidget 关闭与解除停靠图标的大小。（此项会影响预览、目录、书籍浏览器、剪贴板和验证窗口）

QDockWidget::float-button, QDockWidget::close-button { icon-size: 16px; }

设置插件运行器窗口中的字体

QTextEdit#textEdit { font-family: Consolas; }

以上只是用 Qt 的 QSS 样式修改 Sigil 外观的几个示例。如需了解关于 QSS 与 Sigil 的更多信息，请访问我们的 Mobileread Sigil 用户论坛，并查看以下关于 Qt 样式的网站资源：

  • https://doc.qt.io/qt-6/stylesheet-syntax.html
  • https://doc.qt.io/qt-6/stylesheet-reference.html
