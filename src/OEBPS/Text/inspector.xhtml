使用页面检查器

— 检查页面的 DOM —

在预览窗口的底部有一个按钮，用于显示检查器工具。图标看起来像这样：

当你单击该按钮时，就会显示页面检查器工具。

页面检查器允许你检查和修改预览窗口中正在查看页面的文档对象模型（DOM）。

DOM 是你使用 HTML 构建的页面的内存驻留版本。Sigil 解析 HTML 文件，并在内存中创建一个表示你所输入 HTML 信息的树形结构。预览页面实际显示的就是 DOM 中的内容。

如果你想进一步了解 DOM，可以在以下地址找到相关详情：

https://www.w3schools.com/js/js_htmldom.asp

由于 DOM 是页面的内存驻留版本，你可以即时修改它，并立即在预览中看到结果。

检查器允许你随意检查和修改 DOM。这使得你可以更改页面内容或样式表，并立即在预览中看到这些更改的结果。

由于你修改的只是内存中的 DOM，因此在检查器中所做的任何更改都不会改变你的 HTML 文件。

首次打开检查器时，DOM 树会显示两个带箭头、指向右侧的节点，如前图所示。一个对应 <head> 标签，一个对应 <body> 标签。单击其中一个箭头，树就会展开以显示该节点的内容，如下所示。

在上图中，你可以看到展开的 <body> 标签，显示了 body 的内容。连续单击箭头，可以让你沿节点树逐层深入。

当你在树中选择某个标签时，右侧窗口会显示该节点的样式信息。

你可以看到，应用于该节点的样式显示在样式面板中。特别值得关注的是样式面板右下角的图形，它被称为盒模型（Box Model）。

盒模型显示了节点的位置、外边距（margin）、边框（border）、内边距（padding）以及内容的值。所显示数值的单位是像素。因此，从上图可以看出，所选段落的上、下外边距为 16 像素，无边框，无内边距，宽 288 像素，高 72 像素。

另一种选择节点进行检查的方式是使用元素工具，它允许你在预览面板中选择所需的节点。通过单击检查器窗口左上角的按钮来激活元素工具，如下图所示，鼠标光标即指示该按钮。

激活元素工具后，你可以在预览面板中选择所需的元素。当鼠标光标扫过预览面板中的元素时，这些元素会被高亮显示。

只需单击被高亮的元素。在 DOM 树中选择某个节点后，你可以更改其内容和样式，并立即在预览窗口中看到这些更改的效果。在下图中，我更改了段落标签的样式，添加了 color: red。

你可以立即在预览窗口中看到，所有段落标签的文本都显示为红色。

你还可以更改节点的内容。双击段落的内容即可选中它。

输入新文本，即可看到它立即在预览窗口中发生变化。

请记住，由于你修改的只是内存中的 DOM，因此在检查器中所做的任何更改都不会改变你的 HTML 文件。

检查器的另一个功能是控制台（Console），它可以解释 JavaScript 命令。

在检查器中选中某个节点后，你可以在控制台中使用常规的 JavaScript 命令来访问它。通过切换到 Console（控制台）标签页即可激活控制台。

这样做的结果是，控制台会占据整个检查器窗口。

你也可以通过按下 Esc 键，在元素面板下方放置一个控制台面板。

可以使用 '$0' 来访问元素面板中当前选中的节点。通过 $0 访问的节点会在元素面板中显示出来——该工具已在所选文本行的末尾追加了 '== $0'。

在上一个控制台示例图中，你可以看到我在控制台中输入了 '$0'，它正在显示所选节点的内容。单击控制台中的箭头，可以让你深入查看所显示的节点。

你可以像使用常规 JavaScript 命令那样，用 $0 来访问和遍历 DOM 树。例如，你可以输入 $0.parentElement 来访问所选节点的父元素。在输入命令时，会显示自动补全弹窗来帮助你。

你可以用鼠标从菜单中选择所需的方法，也可以按 Tab 键接受高亮的元素来完成选择。

在下图中可以看到，所选段落节点的父元素是 <body> 节点。

同样，你可以使用控制台输出中的箭头，深入查看正在检查的节点。

使用 JavaScript 控制台的最后一个技巧是：检查器工具会保留所选节点的历史记录。最近选中的节点使用 $0 访问，而当前选择之前所选的节点使用 $1 访问。在下图中，我先选中了段落节点，然后选中了图像节点。因此 $0 指的是图像节点（最近的选择），$1 指的是段落节点（上一次的选择）。

检查器也支持层叠样式表（CSS）。样式面板提供了有关层叠样式的信息。

在上图中，层叠样式连同每个样式的来源信息一起显示。被划线划掉的样式，表示被页面上的其他样式覆盖。
