包含自定义字体

—在你的书中嵌入字体—

本教程教你如何在 EPUB 中使用自定义字体。

电子书阅读器的一大优势是可以自选字体，因此通常最好只用嵌入字体来突出显示特定类型的文字——比如章节标题、引文等——而不要改变全书的字体。

要在 EPUB 中使用某种字体，你需要先把字体加载进 EPUB，为字体定义一个样式，再把这个样式应用到文字上。

嵌入字体需要先了解样式表，因此你应该先通读样式表一章。

向 EPUB 添加字体

要向书中添加字体，请使用添加现有文件按钮 。此时会显示对话框，供你从计算机中选择一个或多个文件。想选多少字体文件就选多少。

许多字体并非免费。在把字体放入进 EPUB 之前，请确认你拥有使用它们的许可或授权。只要上网搜索，就能找到许多免费字体。

EPUB 规范支持多种字体类型，包括 OpenType（.otf）、TrueType（.ttf）和 Web 开放字体格式（.woff 或 .woff2）。几乎所有电子书阅读器都至少支持 TrueType 和 OpenType 格式。

字体会添加到书籍浏览器的 Fonts（字体） 文件夹。不过此时书中还没有实际用到它们——只是处于可用状态。

为字体定义样式

字体放入 EPUB 之后，你必须定义一个使用它们的样式。

添加或打开已链接到 HTML 文件的样式表（详见样式表一章）。

添加字体定义，例如：

@font-face {
    font-family: 'Garamond';
    font-weight: normal;
    font-style: normal;
    src: url('../Fonts/Garamond.ttf');
}

@font-face {
    font-family: 'Garamond';
    font-weight: bold;
    font-style: normal;
    src: url('../Fonts/Garamond Bold.ttf');
}

@font-face {
    font-family: 'Garamond';
    font-weight: normal;
    font-style: italic;
    src: url('../Fonts/Garamond Italic.ttf');
}

字体名称区分大小写！

你必须为每种字体样式（正常、粗体、斜体等）分别定义一条 @font-face 规则。

使用 font-family 名称时，每次都要么带引号、要么不带引号，不能混用。建议始终给字体名称加上引号，这样更统一，也无需检查名称不带引号时是否有效。

此时书中还没有真正使用字体，那是下一步要做的事。

把字体应用到文字

要使用这种字体，你需要再创建一个样式，然后把它分配给文中的各个部分。

例如，要让标题使用新字体，可以这样定义标题元素的样式：

h1 { 
    font-family: 'Garamond', serif;
}

或者应用到某些段落：

p.longhand { 
    font-family: 'Garamond', serif;
    font-style: italic;
}

或者，如果你愿意——虽然不推荐——也可以把字体应用到全书的所有文字上：

body { 
    font-family: 'Garamond', serif;
    font-weight: bold;
}

上面的 font-family 规则会指示电子书阅读器尽可能对文字使用你的字体，如果无法使用，则改用通用的衬线字体。

字体混淆

在 EPUB 中使用字体时，字体文件可能被人提取出来用到别处。如果你的字体受许可协议限制，可能需要防止这种情况。

可使用 Sigil 的字体混淆菜单，通过 Adobe 或 IDPF 这两种标准方法之一打乱字体文件——选哪种由你决定，但应在目标电子书阅读器上测试，确保字体仍可读。混淆不是加密——它只是修改字体文件，使其难以在其他地方使用，而阅读器仍能正常显示字体。

要使用字体混淆，请在书籍浏览器窗口中右键点击你的字体，从菜单中选择 字体混淆，然后选择一种混淆方法。

字体子集化

比字体混淆更好的替代方案，也许是使用字体子集化工具，把字体描述限制为仅包含文中实际用到的字符。字体子集化之后，该文件对其他任何更一般的用途都不再有用。适用于 Sigil 的插件可以子集化字体，例如 ePUB Optimizer 和 Subset Fonts 插件。可使用 Sigil 的字符报告获取 EPUB 中实际用到的字符列表。

测试你的字体

并非所有设备都会显示嵌入的字体。即使是 Sigil，也可能无法显示你所有的嵌入字体。最好在目标设备上测试，检查字体的显示是否符合预期。
