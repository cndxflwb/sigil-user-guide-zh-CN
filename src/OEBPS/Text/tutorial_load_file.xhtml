用 Sigil 打开你的文件

有了 HTML 或 EPUB 文件之后，就可以把它加载到 Sigil 里了。即使已经有 EPUB 文件，也建议按照这些步骤操作，可以快速入门 Sigil 的使用方法。

如果一开始使用的是 EPUB 文件，请先备份一份副本，再用 Sigil 打开。

启动 Sigil

首次启动 Sigil 时，会看到一个包含若干窗口的界面：

左侧的书籍浏览器窗口显示 EPUB 中的所有文件，中间是代码视图编辑窗口。

加载了 EPUB 之后，Sigil 的界面大致是这样：

双击书籍浏览器中的文件名，即可打开书中的各个文件进行编辑。

更多细节请参阅用户界面一章。

加载文件

要把 HTML 或 EPUB 文件加载到 Sigil 中，可点击打开图标 ，或使用菜单项 文件=>打开，或使用键盘快捷键 Ctrl+O

在文件管理器中选择要打开的文件，例如 TestBook.html。

此时会在左侧书籍浏览器窗口的 Text 文件夹下看到 HTML 文件。文件会在中间的代码视图编辑器中打开，标签页标题上显示文件名：

HTML 文件现在已经是 EPUB 的一部分了。从此刻起，编辑的是 EPUB，而不再只是 HTML 文件。你可能已经注意到，在 Sigil 中打开文件时，它还创建了 EPUB 格式所需的另外几个文件，可以在书籍浏览器中看到它们与原始文档并排在一起。

如果文件包含图片或样式表等内容，Sigil 也会尝试加载它们，并保存到书籍浏览器中相应的虚拟文件夹里。

在将文件转换为 EPUB 或加载 EPUB 时，Sigil 可能会添加一些必要的细节，并把你的文件整理到标准名称的文件夹中。
