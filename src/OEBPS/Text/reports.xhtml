报告

— 查看书的详细信息 —

Sigil 提供多个报告，列出书中文件和 CSS 样式的详细信息。

通常双击报告中的条目，即可跳转到所列文件名处。

有些条目带有工具提示。例如在图像报告中，“使用次数”列显示哪些文件使用了该图像。

使用 工具=>报告 生成报告，然后选择要查看的报告：

所有文件

此报告列出 EPUB 中的所有文件，包括文件大小、位置和类型，以及是否应用了 guide 语义类型。

HTML 文件

此报告列出所有 HTML 文件及其详细信息。

在报告界面中，可通过右键单击所选文件并选择 从书中删除，将文件从 EPUB 中删除。

图像文件

此报告列出所有图像，标明是否已在书内使用及使用次数。双击某个条目，即可跳转到该图像在 HTML 文件中的首次出现位置（不含 CSS 文件链接的图像）。

在报告界面中，可通过右键单击所选文件并选择 从书中删除，将文件从 EPUB 中删除。

CSS 文件

此报告列出所有 CSS 样式表，标明是否已被链接及链接次数。

在报告界面中，可通过右键单击所选文件并选择 从书中删除，将文件从 EPUB 中删除。

HTML 文件中已使用的类

此报告扫描书中的 HTML 文件，提取已使用的样式类名列表。对每个类名，列出其是否存在于某个 CSS 样式表或内联样式中。

CSS 选择器

此报告扫描书中的 CSS 样式表，对每个样式选择器列出其是否已在书内用过。

在报告界面中，可通过右键单击所选样式并选择 从样式表中删除，将特定的样式类从样式表中删除。

链接与脚注

此报告列出 HTML 文件中的每个链接（href），即代码里的“<a>”标签，并包含链接是否有 ID、链接目标是什么，以及该目标是否存在。

此外，为便于处理脚注或尾注，报告还会检查反向链接。反向链接是从目标指回原始链接的链接。若按如下方式为脚注创建链接，此报告即可确认两者是否互相链接：

注标: <a id="t1" target="../Text/footfile1.xhtml#f1">跳转到注释</a>
脚注: <a id="f1" target="../Text/file1.xhtml#t1">返回到注标</a>

仅在锚点（“a”）标签内使用 ID 时，此功能才有效。

HTML 文件中的字符

此报告提取 HTML 文件中使用的全部字符。具体而言，它列出预览中显示的所有字符；若某字符存在 HTML 实体编码，会连同其十进制和十六进制编码一并列出。全部字符都列在底部，便于剪切和粘贴。

此报告可用于识别书中是否意外使用了多余字符；若正在对字体做子集化处理，也可能有所帮助。
