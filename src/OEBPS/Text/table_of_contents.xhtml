目录

— 图书的地图 —

EPUB 支持目录（Table of Contents，缩写为 TOC），用于帮助读者在书中导航。通常 EPUB 阅读器会提供一个按钮或菜单项来打开目录。

Sigil 提供多种使用目录的方式。Sigil 中的目录窗口为您提供目录的动态视图——您可以确切地查看目录的样子，并选择条目进行跳转。生成目录功能可以基于文档中的标题创建新的目录。当无法或不想使用生成目录时，编辑目录功能允许您更新现有目录。而创建 HTML 目录则可以在你的文档中创建一个新 HTML 页面，展示 EPUB 目录中的内容。

EPUB 的目录在 EPUB2 中存储于一个名为 NCX 的特殊 XML 文件（通常命名为 toc.ncx）中，在 EPUB3 中则存储于一个名为 NAV 的 XHTML 文档（通常命名为 nav.xhtml）中。这些文件被设计为机器可读，以便阅读器和无障碍软件都能使用它们，让用户快速高效地在整本 EPUB 中导航。

查看目录

如果目录窗口尚未打开，请选择菜单项 视图=>目录 来打开它：

单击某个条目即可跳转到它在书中的位置；如果存在子章节，可以点击章节名称左侧的图标来展开或折叠条目。

使用右键上下文菜单选择 全部折叠或 全部展开，可快速显示或隐藏子章节。

生成目录

要自动创建目录，您首先需要定义书中的标题或章节。

在代码视图中，您可以先选中要设为标题的文本，然后从 格式=>标题 菜单中选择所需的标题级别来创建标题；更简单的方式是直接使用工具栏上的格式按钮。

如果章节名称没有使用如上所述的标题标签（h1、h2 等），您将无法自动生成目录。由于标题标签对无障碍性（Accessibility）非常重要，您应当认真考虑添加它们。

点击 生成目录按钮 ，或选择菜单项 工具=>目录=>生成目录，然后选择要包含在图书目录中的标题，即可开始生成目录：

勾选要包含在目录中的任何名称，取消勾选不想包含的任何条目。

当您使用生成目录时，Sigil 不仅会更新你的目录，还会更新你的 HTML 文档——以确保您输入的信息在下次生成目录时能够再次使用。

您可以使用 仅显示目录项 复选框来显示或隐藏不会包含在目录中的条目。这不会影响你的目录，只会影响您在对话框中看到的内容。您还可以使用 选择要包含在目录中的标题 下拉菜单来快速选中或取消选中某一类型的标题，然后手动微调选择。

点击 重命名即可重命名目录项。这也会修改你的 HTML 代码，以设置标题的 “title” 属性。

您可以使用左右方向键更改标题的级别。这也会更改 HTML 代码中标题的级别。

每个标题的工具提示（只需将鼠标移到标题上并停留几秒）会显示该标题位于哪个文件及其 HTML 代码。

表格中各标题的工具提示会显示每种类型标题的数量：

当您选择 确定时，如果您所选的标题还没有赋予 ID，Sigil 会为它们添加或更新自动生成的 ID。然后它会在 EPUB2 中创建新的 NCX 文件、在 EPUB3 中更新 NAV 文件，其中包含指向各章节的链接。如果某个标题“处于” HTML 文件的开头，Sigil 会直接链接到该文件而不是标题 ID。这是因为在某些电子书阅读器上，直接链接到某个元素会拖慢目录的显示速度。

自动生成目录会覆盖 EPUB2 的 toc.ncx 文件或 EPUB3 的 nav.xhtml 文件中任何已有的目录。

编辑目录

如果无法或不想从文档中的标题生成目录，您可以使用编辑目录来修改现有目录。对目录所做的任何更改都不会影响你的 HTML 文件，而且如果您使用生成目录，所有更改都会丢失。

双击条目即可编辑它。您可以添加新条目或删除现有条目。使用箭头可以提升或降低条目的标题级别。

要更改目录项指向的位置，您可以直接键入目标位置，或使用 插入链接 按钮。这将打开 选择目标 对话框，您可以在其中选择目录项要指向的位置：

右键上下文菜单允许您删除或重命名条目，或者展开/折叠目录。

目录项必须指向有效的目标。如果您只想在目录中显示一个标题，请让它指向下一个有效条目。

生成 HTML 目录

您可以使用菜单 工具=>目录=>生成 HTML 目录 为你的 EPUB 创建一个内联 HTML 目录。这种目录是供人类读者查看和使用的，与 NCX 或 NAV 不同，它不需要机器可读。

内联目录不过是 EPUB 中的另一个 HTML 页面，它以文本形式包含目录，并带有可用于跳转到特定章节的链接。

创建 HTML 目录的另一个原因是，它可以转换为不支持 EPUB2 的 NCX 或 EPUB3 的 NAV 的其他电子书格式。

生成 HTML 目录 菜单项会覆盖任何已有的 HTML 目录文件（如果其语义类型为 TOC）。如果不存在这样的文件，它会创建一个名为 toc.html 的 HTML 文件，并将其语义类型标记为 TOC。如果 toc.html 已存在，它将被替换。

创建内联目录之后，您可以修改它的内容——但请记住，每次重新创建目录时都会覆盖已修改的 HTML 目录。

自定义 HTML 目录样式表

生成的 HTML 目录页面使用一个独立的 CSS 文件（sgc-toc.css）来格式化目录。如果该文件已存在于你的书中，它不会被覆盖（因此您可以自定义它而不会丢失更改）。但如果它不存在，Sigil 会在你的首选项文件夹中查找 sgc-toc.css，并将其用作默认文件。如果首选项文件夹中没有该文件，Sigil 会为目录创建一个默认样式表。

如果您正在生成 EPUB3 目录，Sigil 会在你的首选项文件夹中查找 sgc-nav.css，并将其用作默认文件。

更新 EPUB3 图书中的 NCX 目录

如果您用 Sigil 创建 EPUB3 图书，或打开一本没有 NCX 文件的 EPUB3 图书，则不存在 NCX。如果您希望在编辑完成后添加 NCX 以使你的 EPUB3 具有更好的向后兼容性，请使用菜单项 工具=>EPUB3 工具=>为 EPUB2 用户生成 NCX/Guide 文件 来生成并添加一个旧的仅支持 EPUB2 的设备也能使用的 NCX。
