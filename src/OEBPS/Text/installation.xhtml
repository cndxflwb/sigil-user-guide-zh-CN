安装

— 入门 —

可从 Sigil 官方网站下载最新版，并按操作系统安装。

Windows

Sigil 支持 Windows 10 及更高版本。

  • 下载 Windows 版 Sigil

双击该文件以运行安装程序，例如：

  • Sigil-2.8.5-Windows-x64-Setup.exe

Mac

Sigil 支持 Mac OS 13 x86_64 位 Intel 和 Arm64 及更高版本

  • 下载 Mac 版 Sigil

解压 TXZ 文件，将“Sigil.app”拖入 Applications（应用程序）文件夹，例如：

  • Sigil.app-2.8.5-Mac-arm64.txz
  • Sigil.app-2.8.5-Mac-x86_64.txz

Linux

为了更好地支持 Linux 用户，Sigil 现在发布 AppImage 版本，它应当能在大多数 x86_64 Linux 发行版上运行。与各 Linux 发行版自带打包的 Sigil 版本不同，我们的 AppImage 与 MacOS 和 Windows 版本在功能上一一对应，并包含运行 Sigil 全部功能（包括插件）所需的所有组件。

  • 下载适用于 Linux x86_64 的 Sigil AppImage

只需下载该 AppImage 并赋予其执行权限，启动后即可正常使用。

  • Sigil-2.8.5-x86_64.AppImage
  • Sigil-2.8.5-x86_64.AppImage.zsync

当然，由于源代码免费提供，你仍然可以针对自己的 Linux 版本或 CPU 从源码构建。
