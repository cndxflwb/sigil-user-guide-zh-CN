安装

— 入门 —

可从 Sigil 官方网站下载最新版，并按操作系统安装。

Windows

Sigil 支持 Windows 10 及更高版本。

  • 下载 Windows 版 Sigil

双击该文件以运行安装程序，例如：

  • Sigil-2.3.0-Windows-x64-Setup.exe

Mac

Sigil 支持 Mac OS 11 x86_64 位 Intel 和 Arm64 及更高版本

  • 下载 Mac 版 Sigil

解压 TXZ 文件，将“Sigil.app”拖入 Applications（应用程序）文件夹，例如：

  • Sigil.app-2.3.0-Mac-arm64.txz
  • Sigil.app-2.3.0-Mac-x86_64.txz

Linux

由于 Linux 发行版众多，Sigil 不提供二进制版本。

不过，源代码免费提供，可针对你的 Linux 版本从源码构建。此外，在众多志愿者的努力下，很可能已有针对你的 Linux 发行版预先打包的 Sigil 版本可供在线获取：

  • 在 Linux 上构建 Sigil
