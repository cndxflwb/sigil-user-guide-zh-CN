HTML 基础

完整介绍 HTML 超出了本教程的范围，但了解基础知识有助于编辑文字。[1]

在代码视图中查看文件的 HTML 版本时，会看到大量诸如 <p> 或 <h1> 之类的字样。这些就是 HTML 标签，用来指示电子书阅读器如何处理文字。

例如，下面的 HTML 代码指示电子书阅读器：文字 Chapter 8 是一级标题：

<h1>Chapter 8</h1>

<h1> 标签表示标题文本的起始位置，</h1> 标签则表示标题文本的结束位置。点击 图标时，Sigil 插入文档的正是这段代码。电子书阅读器通常会把标题文字放大并在屏幕上居中显示。

下面的 HTML 代码指示电子书阅读器：文字 This is a paragraph 是正文段落。因为是段落，电子书阅读器会应用某种格式，例如首行缩进。

<p>This is a paragraph.</p>

HTML 中还有更多的标签。需要记住的关键一点是：HTML 标签指示电子书阅读器如何排版并显示内容。它们使内容与格式相互分离，从而更容易更改书籍外观。

HTML 标签还可以更复杂，因为可以包含属性来修改自身的解释方式。例如，下面是一个段落，其中的标签定义了上一章展示的、用于链接的 ID：

<p><span id="note1">This is a note</span> for linking.</p>

span 标签用于包裹需要不同格式或需要包含额外信息的一小段文字。在本例中，这个信息就是文字“This is a note”拥有 ID“note1”。带有 ID 属性的 span 标签，正是使用插入 ID 功能时 Sigil 插入的代码。

这些只是 HTML 代码的几个例子，但足以让你大致了解 HTML 的主要内容。

需要记住的重点是：在代码视图中，既能访问正文文字，也能访问控制书籍外观的格式代码——因此可以找到并修改它们。

更多细节请参阅简介、代码视图和样式表章节。

在代码视图中编辑

试着修改几个字词（暂时不要动 HTML 标签），然后观察预览中的变化。

编辑时务必小心谨慎。需确保所使用的标签全部有效，并且正确开启和闭合——否则预览中会出现粉色的错误警告，在修复这些错误之前无法保存 EPUB。

预览

要真正看到修改代码的效果，可使用 视图=>预览打开预览窗口（随时可再次使用 视图=>预览或其快捷键将其关闭）。可能需要把窗口放大，或者拖到桌面的其他位置。

在代码视图中输入后，预览会在短暂延迟后更新，显示修改结果。

请经常保存，以便尽早发现代码中的错误。
