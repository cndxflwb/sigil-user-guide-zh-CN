首选项

— 自定义 Sigil —

首选项对话框可控制 Sigil 的许多设置，分为七个部分：

  • 外观
  • 一般设定
  • 键盘快捷键
  • 语言
  • 拼写检查词典
  • HTML 实体符号保留
  • 插件

要打开首选项，请转到屏幕顶部的主菜单栏，选择 编辑=>首选项（在 Mac 上：Sigil=>首选项）：

首选项窗口打开后，从左侧列表选择所需部分；某些部分进一步细分为窗口顶部排列的多个选项卡。设置完毕后，点击确定或关闭窗口，保存当前设置。

将鼠标悬停在各个首选项上，查看是否有工具提示。

外观

Sigil 提供了许多关于屏幕显示效果的选项。外观首选项于对话框窗口顶部排列四个可点击选项卡：源码视图、预览、图标主题和主用户界面。

源码视图

  • Monospaced Code Font: Select the font size and font family used for text in the Code View window.|→等宽代码字体：选择源码视图窗口中文本所用的字号和字体。←|
    • Sigil 的源码视图使用你计算机上安装的等宽系统字体。如果有你想使用但未出现在下拉窗口中的等宽字体，请确认它已安装在你的计算机上。
  • 插入特殊字符：选择“插入特殊字符”窗口中所用的字号和字体。
  • Colors:|→颜色：←|
    • 选择 HTML 与 CSS 条目的颜色。
    • 选择文本高亮、拼写错误单词下划线等的颜色。
    • 选择光标位于标签内时是否高亮匹配的标签。

预览

  • 字体：选择 CSS 样式表未指定字体时预览窗口中文本的默认字号和字体。（“标准”设置总体默认字体。）
  • 使预览在深色模式下模拟一个深色的外观：选择计算机处于深色模式时，预览窗口是否模拟深色外观。

图标主题

  • Select your icon theme: Sigil offers three different icon themes: Default, Fluent, and Material. Hover your mouse over the theme name to see a sample.|→选择你的图标主题：Sigil 提供三种不同的图标主题：默认图标、Fluent 图标和 Material图标。将鼠标悬停在主题名称上可预览图标主题。←|
    • Sigil 还支持通过自定义 .rcc 文件提供的用户自定义图标主题。更多信息请查看该链接。
    • 更改图标主题后需重启 Sigil 才能生效。

主用户界面

  • 主菜单图标大小：使用滑块调整工具栏按钮的大小。
  • 深色主题样式（仅 Windows）：选择使用经典的 Sigil 深色样式，而不是内置的 Qt 深色样式。
  • 用户界面字体：选择 Sigil 菜单、按钮等所用的字体和字号。
  • 控制书籍浏览器外观：选择书籍浏览器显示完整文件路径还是仅文件名。
  • 调整拖拽距离（仅 Windows）：调整触发移动事件前需要拖动的距离（单位：像素）。若轻微抖动鼠标就误移动选项卡，可调大该值。
  • 全部重置：将所有主界面外观首选项重置为默认值。

外观设置只影响书籍在 Sigil 中的显示，不影响它在电子书阅读器上的显示！

一般设定

一般设定分为窗口顶部排列的四个可点击选项卡：基本、安全、有效性和高级。

基本

  • 选择何种标准新建空白EPUB：选择在 Sigil 中创建新书时使用的 EPUB 版本（2 或 3）。
  • 在以下位置修复格式不正确的HTML源代码：勾选后，每次打开或保存书时，Sigil 会自动修复非良好结构或缺少 DOCTYPE、html、head 或 body 元素的 HTML 源代码。修复由 Google gumbo 自动修复解析器完成。检测到不良代码时，会弹出确认窗口，询问是否继续修复。
  • 要保存的剪贴板历史记录项目数：指定保存到列表中以供以后调用的剪贴板片段数量；指定 0 则禁用剪贴板历史。
  • 设置首选的外部 xhtml 编辑器：设置首选外部 xhtml 编辑器后，点击工具栏“启动外部 Xhtml 编辑器”按钮即可启动该编辑器。只需一键，即可快速用外部编辑器（如 PageEdit、notepad++ 或 BBEdit）打开并编辑选中的 html 文件。

安全

  • 控制EPUB对非多媒体远程资源的访问：选择是否允许 EPUB 访问非多媒体远程资源
  • 控制EPUB使用JavaScript：选择是否允许 EPUB 使用 JavaScript。

有效性

  • 针对EPUB2文件，W3C样式表校验器应依据：选择 W3C 样式表验证工具用于 EPUB2 书的 CSS 级别。
  • 针对EPUB3文件，W3C样式表校验器应依据：选择 W3C 样式表验证工具用于 EPUB3 书的 CSS 级别。

高级

  • 备用临时文件夹 设置 Sigil 存放临时 EPUB 工作文件的备用文件夹。保留 <SIGIL_DEFAULT_TEMP_HOME> 时，默认使用 Sigil 首选项文件夹内的 "workspace" 文件夹。
  • 在 QtWebEngine/Preview 中禁用GPU加速如果你看到伪影，或预览无法正常显示你的 epub，请勾选此项；在显卡驱动不是最新时尤其有用。
  • “打印预览”设置勾选“跳过打印预览”框可加快多个项目的打印速度；从预览打印时可设置打印 DPI

键盘快捷键

Sigil 提供了各种键盘快捷键，你可以按自己的喜好自定义。例如，如果你想让 F12 始终打开“查找与替换”，可以在这里更改。

如果需要在短时间内更方便地访问某个功能，可以临时指定或重新指定快捷键。

要指定或移除快捷键：

  • 从命令列表中选择一个条目。
  • 点击“快捷键”文本框。
  • 按下你想使用的组合键——不要用字母拼出来，直接按下组合键即可。
  • 点击指定设置快捷键。如果该组合键已被另一个命令使用，会弹出显示冲突的警告消息。
  • 要移除快捷键，选择一个条目并点击移除。
  • 使用全部重置将所有快捷键恢复为默认值。

使用“过滤”文本框可以轻松搜索快捷键。

Mac 用户注意：Sigil 中提到的 Ctrl 键对应 Macintosh 键盘上的 Cmd 键，提到的 Meta 键对应 Mac 上的 Ctrl 键。

这是由于 Qt 的自动重映射，它让每个平台最常用的快捷键序列按预期工作。例如，Windows/Linux 用户按 Ctrl+C 时会得到预期的复制命令；多亏 Qt 在 MacOS 上将 Ctrl 自动重映射为 Cmd，Mac 用户按 Cmd+C 时也会得到预期的复制命令。

语言

Sigil 已被翻译成多种语言。

  • 用户界面语言：为 Sigil 的用户界面选择你偏好的语言。如果某些词语没有可用的翻译，将以英文显示。
  • 元数据默认语言：设置元数据编辑器用于新书或该书尚未设置语言的默认语言。

必须重启 Sigil 才能使新的用户界面语言生效。

试着把界面设为另一种语言并重启 Sigil，看看志愿者们创建的翻译。

拼写检查词典

Sigil 支持拼写检查，并提供多种拼写检查选项，包括选择标准词典和使用个人用户词典。

  • 首选语言词典：从下拉菜单中选择你的主语言词典。
    • 要添加新的标准词典（必须是 hunspell 格式），点击打开首选项文件夹，进入 "hunspell_dictionaries" 目录。把新的词典文件放入 "hunspell_dictionaries" 目录，然后重启 Sigil。
    • 额外词典的一个来源是 OpenOffice Dictionaries 网站。要添加这些词典，请下载、解压并把文件（如 en_GB.aff、en_GB.dic、hyph_en_GB.dic）复制到 “hunspell_dictionaries” 目录，然后重启 Sigil。
  • 第二语言词典：选择你的次语言词典。
  • 突出拼错的单词：选择是否在代码视图中用红色波浪下划线高亮拼写错误的单词。之后你就可以右键点击该单词，选择建议的更正或将其添加到词典中。
  • 核对数字：启用此选项后，含数字的单词（如 32nd 或 HTML5）也会进行拼写检查。
  • User Dictionaries:|→用户词典：←|
    • 你可以创建自己的个人用户词典，甚至可以为不同的书和不同类型的词（如地名、人名等）使用不同的词典。
    • 如果你没有创建过任何用户词典，Sigil 会为你创建并启用一个 "default" 用户词典，你可以重命名或删除它。
    • 要创建新的用户词典，点击“用户词典”选项卡，点击添加，然后为新词典输入名称：
    • 在“用户词典”选项卡下选择某个词典，然后点击“用户词典单词列表”选项卡，即可查看该词典中的单词。列表中显示该词典的所有单词，可添加、编辑或移除。
    • 要直接向用户词典添加单词，在“用户词典”选项卡中选择词典，点击“用户词典单词列表”，然后点击添加。输入任意多个单词，或从文件粘贴。单词可以用逗号、空格分隔，或每行一个。
    • 也可使用“拼写检查”向词典添加单词，或在代码视图中右键点击拼写错误的单词，选择 添加到词典 选项之一。
    • 可使用复制复制整个词典，然后根据需要重命名。
    • 勾选词典名称旁的复选框，即可选择启用哪些用户词典。可同时启用多个词典。检查单词拼写时，会使用所有已启用的词典。

默认词典即选中并高亮显示的那个，也会在首选项窗口“用户词典”部分的左下角标出。使用“添加拼写错误的单词”快捷键或上下文菜单项 添加到默认词典 添加单词时，使用的就是默认词典。

已启用的词典左侧有一个对勾。虽然一次只能选中一个用户词典并将其设为默认，但可以启用多个词典。运行拼写检查时会使用所有已启用的词典。

保留实体

当你运行“修复”（工具=>HTML 重新格式化=>修复所有 HTML 文档）时，除非实体被包含在“要保留的实体”列表中，否则 Sigil 会自动把所有字符实体转换为 Unicode 字符。

  • 要保留特定实体、防止“修复”把它们转换为 Unicode 字符，请点击添加，把它们加入“要保留的实体”列表。用空格、换行或逗号分隔，可以一次输入多个实体。
  • 使用移除或全部移除从列表中移除实体。不在列表中的实体在“修复”时会被转换为 Unicode 字符。

请注意，EPUB3 书中不能使用命名实体（如 &nsbp;），必须改用数字实体（如 &#160;）。

如果你在打开或保存时开启了“修复非良好结构的 HTML 源代码”，且源代码是良好的，实体将不会被自动转换（因为实体是完全有效的代码）。要在代码良好的 html 文件中转换实体，必须手动调用 工具=>HTML 重新格式化=>修复所有 HTML 文档。

插件

Sigil 支持各种各样能增强其编辑能力的实用插件。

  • 使用捆绑的 Python 解释器：启用此选项用于选择随 Sigil 捆绑的 Python 解释器（推荐）。若禁用此选项，则需选择一个外部 Python 3 解释器。
  • 设置运行环境：此选项面向插件开发者；如果“使用捆绑的 Python”被禁用（或无法选择），你也需要设置它。点击自动或设置以选择外部 Python 3 解释器。
  • Add/Remove|→添加/移除←|
    • 添加插件：点击此按钮安装插件。
    • 移除插件：点击此按钮卸载当前选中的插件。
    • 移除全部插件：点击此按钮卸载所有插件。
  • Shortcuts|→快捷方式←|
    • 把插件指定给工具栏上的 10 个插件按钮。点击某个插件按钮时，指定的插件会自动启动。

工具栏按钮：

打开首选项文件夹

所有首选项界面左下角的打开首选项文件夹按钮，会打开包含全部首选项文件的目录。可复制这些文件用于备份或与他人共享。

首选项文件夹很可能在以下路径：

Windows：

…\Local Settings\Application Data\sigil-ebook\sigil

Mac：

/Users/[Username]/Library/Application\ Support/sigil-ebook/sigil/

Linux：

$HOME/.local/share/sigil-ebook/sigil

可能看到的文件/文件夹包括：

  • automate01.txt, automate02.txt, automate03.txt：可选的用户自动化任务列表，供运行自动化列表工具栏按钮使用。
  • cover-template2.xhtml, cover-template3.xhtml：分别用于 EPUB2 和 EPUB3 的可选封面 xhtml 模板。
  • custom_preview_style.css：用于 Sigil 预览窗口的可选用户 CSS。
  • custom_preview_style_alt.css：预览的可选备用 CSS。
  • hunspell_dictionaries：存放你添加的所有标准词典的位置。
  • env-vars.txt：用户创建的用于设置 Sigil 环境变量的文本文件。自 Sigil 2.6.2 起。
  • local-devtools：存放预览检查器数据的位置。
  • local-storage：存放 JavaScript 本地存储数据的位置。
  • plugins：存放你安装的所有插件的位置。
  • plugins_prefs：存放插件首选项文件的位置。
  • qt_styles.qss：用于 Sigil 界面元素的可选自定义 Qt 样式。
  • QtWebEngine：存放预览数据的位置。
  • repo：存放检查点 git 仓库的位置。
  • sgc-toc.css：用于 EPUB2 书的可选自定义目录样式表。
  • sgc-nav.css：用于 EPUB3 书的可选自定义目录样式表。
  • sigil_clips_v6.ini：你保存的剪贴板。
  • sigil_index_v6.ini：你的索引条目。
  • sigil_searches_v6.ini：你已保存的搜索模板。
  • sigil_v6.ini：Sigil 的常规配置设置文件信息。
  • user_dictionaries：存放所有个人用户词典的位置。
  • user-template2.css, user-template3.css：供“添加空白样式表”命令使用的可选用户 CSS 模板。
  • user-template2.xhtml, user-template3.xhtml：供“添加空白 HTML 文件”命令使用的可选用户 XHTML 模板。
  • workspace：默认位置，Sigil 把当前正在处理的 epub 文件存放在各自独立的 epub 专用子文件夹中，并存放所需的临时文件。

更改 GUI 控件的字号

由于 Sigil 是一个 Qt 应用，你可以通过创建 qt_styles.qss 样式表文件并把它放入 Sigil 首选项文件夹，来自定义某些 GUI 控件的字号。（qt_styles.qss 需要包含有效的 Qt 样式表声明。）

例如，以下样式将增大“查找与替换”窗口中各输入框的字号：

QLabel { font-size: 16pt }
QLineEdit { font-size: 16pt }
QComboBox { font-size: 16pt }

自定义预览的背景

预览从技术上讲是显示渲染后 (x)html/CSS 的浏览器，改变字体或背景颜色的唯一方法是借助样式指定：要么内联，要么通过 EPUB 内的 CSS。

唯一的例外是，如果 Sigil 首选项文件夹中存在名为 custom_preview_style.css 的文件且包含有效 CSS，这个用户自定义的 CSS 文件会应用于预览（无论打开的是哪个 EPUB）。

例如，以下样式会让预览显示浅灰色背景和蓝色文字：

body {
  background-color: #D3D3D3;
  color: blue;
}

注意：应用此类 CSS 可能影响 EPUB 中某些已设样式元素的可见性，具体取决于 EPUB 中已应用的 CSS 及其应用方式。
