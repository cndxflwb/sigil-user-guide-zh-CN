创建链接与注释

—为你的正文建立链接—

使用 Sigil 可以轻松把文字链接到书中的其他位置（例如章节名称和注释），读者选中链接后即可跳转到指定文字处。

ID

要让 Sigil 将书中的某些文字链接到其他位置，首先要为链接的目标文字设置 ID（本质上是一个唯一名称）。

如果你的链接目标只是某个文件的开头，那么什么都不用做，因为可直接用文件名作为目标 ID。

但如果你想指向书中的具体文字，就需要给这段文字分配一个 ID。

ID 就是一个唯一名称，比如 note1，你把它分配给某段文字以便引用。ID 名称在一个 HTML 文件内必须唯一（且以字母开头），但最好让它在整个 EPUB 中都保持唯一，以防你之后移动文字位置。

ID 和链接通常是用 HTML 锚标签（“a”）创建的——因此 ID 常被视为链接的锚 ID，插入 ID 所用的按钮也因此得名。

链接

链接是一种指向你的 ID 的方式，读者选中它后会“跳转”到该 ID 所在的位置。

要在 Sigil 中创建链接，请选中要用作链接的文字，然后点击插入链接按钮 ：

此时会打开“选择目标”对话框，列出书中可链接的 ID：

列表中有许多不同的 ID。起初可能找不到你的目标，先了解链接的格式会有所帮助：

  • Filename.html：以文件名作为链接目标，跳转到该文件的开头。生成目录的链接用的就是这种形式。

  • Filename.html#ID1：指向某个文件中的具体 ID。用它作为链接目标时，读者会跳转到该文件中该 ID 对应文字的准确位置。

  • #ID1：只有 ID 名称，这表示它与你的链接在同一个文件中，因此不需要文件名。

选中一个链接时，你会看到“目标”文本框中显示将要使用的实际链接。点击确定或双击某个条目，即可为你的文字创建链接。

点击文中刚创建的链接，你就会跳转到该 ID 所在的位置。之后可以点击返回按钮 回到你点击链接的地方。

反向链接

大多数电子书阅读器都有返回按钮，跟随链接跳转后点击即可回到原始链接文字处。但对于没有返回按钮的阅读器，可从目标位置创建一个链接指回来源文字。这通常称为反向链接。

反向链接与其他类型的链接并无不同——只是既要从来源文字创建链接指向目标注释，又要从目标注释创建链接指回来源文字——因此来源和目标都需要 ID 和链接，二者互为镜像：

例如，在创建尾注的典型情形下：

  • 选中位于全书（或章节）末尾的注释，并为它分配一个 ID，例如 note1。
  • 选中书中的文字，并为它分配一个 ID，例如 text1。
  • 再次选中同一段文字，创建一个链接指向该注释的 ID。
  • 再次选中你的注释（点击链接跳转到注释处并测试链接），然后创建一个链接指回你那段文字的 ID。
  • 点击注释，跳转回你的文字以测试链接。
